# 发布说明（2026 年 8 月下旬）

> 本期覆盖近两周（2026-08-09 至 2026-08-23）的更新，面向平台 API 客户。
> 可用模型、价格与素材能力一律以 `GET /v1/models` 及模型详情的实时返回为准；仍在验证中的新线路
> 将按目录逐步开放。

## 1. 本期亮点

1. **Seedance 视频生成服务上线**：统一视频任务 API，支持文生视频与图生视频；多条线路已完成真实
   生成与计费核验，移动云线路验证中。
2. **图片生成新增模型**：新增 Seedream 5、nano-banana 2、Seedream 5.0 等多个图片模型；图片生成
   统一为一次请求、同步返回结果。
3. **模型合同定价（面向企业客户）**：可为账户开通模型合同，按约定折扣计费，全部 API Key 即时
   生效。
4. **账户通知**：新增账户创建、密码修改、API Key 创建的邮件通知（由平台按需开启）。

## 2. Seedance 视频生成

### 2.1 统一任务 API

Seedance 系列视频模型统一使用以下接口创建和管理视频任务：

| 操作 | 接口 |
| --- | --- |
| 创建视频任务 | `POST /api/v3/contents/generations/tasks` |
| 查询单个任务 | `GET /api/v3/contents/generations/tasks/{task_id}` |
| 查询任务列表 | `GET /api/v3/contents/generations/tasks` |
| 删除任务 | `DELETE /api/v3/contents/generations/tasks/{task_id}` |

支持纯文本生成视频，以及通过图片 URL / Data URL 提供参考图或首帧；分辨率、时长等以各模型目录
说明为准。

### 2.2 计费与重试语义

- **一个模型一条线路**：你选择的客户模型固定对应一条服务线路，不会在任务中途切换，价格稳定
  可预期。
- **创建只执行一次**：每次创建请求只向服务方发送一次。网络异常或结果不明时，平台不会自动重发，
  也不会自动退款；请确认任务状态后再决定是否重新发起。这样可避免重复生成和重复计费。
- **失败不额外扣费**：任务明确失败时按失败退款语义处理；成功任务按实际生成结果计费。
- **在途任务不受调价影响**：任务按创建时刻的价格和配置结算，之后的调价不影响已创建任务。

### 2.3 素材库（部分模型支持）

- 部分视频模型支持素材与素材组：可上传图片 / 视频 / 音频素材并在生成时引用，个别模型支持真人
  认证素材。你的模型是否支持、支持哪些操作，以模型详情中 `api.assets` 的返回为准。
- 素材接口为单资源操作：创建、查询、更新、删除均需携带所用的 `model`。
- 请自行保存素材的 `model + id + reference`；生成视频时以 `asset://<素材ID>` 引用。
- 不提供素材列表接口；平台不保存你的媒体文件，素材 source URL 仅用于当次上传调用。

## 3. 图片生成

- 图片生成统一使用 `POST /v1/images/generations`（图片编辑使用 `POST /v1/images/edits`），一次
  请求内等待并直接返回图片 URL，无需再查询任务状态。
- 本期新增 / 更新的图片模型（以模型目录实时返回为准）：

| 模型 | 说明 |
| --- | --- |
| `seedream-5.0-lite` | 文生图，2K，支持多种画幅 |
| `seedream-5.0-pro` | 文生图，1K，支持多种画幅 |
| `nano-banana-2` | 文生图，1K，支持多种画幅与 jpg/png 输出 |
| `nano-banana-2-lite` | 文生图，单分辨率，支持 15 种画幅（含 auto） |
| Seedream 5 Lite / Pro（新线路） | 固定 2K 单图 URL 输出，验证通过后开放 |

- 当前图片请求统一要求 `n=1`、`response_format=url`；更高分辨率、参考图、组图等能力在计费规则
  验证完成后逐步开放。
- 返回的图片 URL 有一定有效期，请及时下载到你自己的存储。

## 4. 模型合同定价（企业客户）

- 开通模型合同后，你的账户将按约定的模型清单和成交折扣计费：**折后价 = 模型原价 × 分组倍率 ×
  合同折扣**。
- 合同对账户下**全部现有和未来 API Key 即时生效**；清单外的模型不可见、不可调用。
- 你可以在控制台 API Key 页面查看自己的合同模型、折扣和当前折后价格；`/v1/models` 与价格页展示
  的也是同一合同口径。
- 合同停用后账户恢复标准价格和标准模型范围。

## 5. 接口行为变更（请排查你的集成）

| 变更 | 说明 | 你需要做什么 |
| --- | --- | --- |
| 图片任务接口移除 | `/v1/images/tasks/:task_id` 不再存在；图片生成不再有异步任务、任务查询或幂等回放 | 移除相关调用，统一按同步图片请求处理 |
| 图片请求校验收紧 | 合同外字段会直接返回 `400`，包括 `b64_json`、显式 `stream`（含 `false`）、`callbackUrl`、参考图字段、未知字段 | 仅提交模型目录声明的字段；收到 `400` 请对照返回的错误说明修改请求 |
| 素材列表接口不提供 | 素材仅支持单资源的创建 / 查询 / 更新 / 删除，且必须携带 `model` | 自行保存素材 `model + id + reference`；不要依赖平台列出你的素材 |
| 旧素材 ID 失效 | 历史平台素材 ID（`ast_*`、`astgrp_*` 开头）不再被平台解析 | 使用新素材接口返回的 ID 与 `asset://` 引用 |
| 视频入口区分 | `/v1/video/generations` 不再承载 Seedance 模型 | Seedance 模型请使用 `/api/v3/contents/generations/tasks` |

## 6. 超时与重试建议

- 图片 / 视频请求收到 `504`（超时）时，不要自动重发：服务方可能已受理并计费。请先查询任务状态
  或联系平台支持，由业务决定是否重新发起。
- 视频任务建议以查询接口的终态为准；单次查询返回异常不代表任务失败，请重试查询确认。
