两个地区的 Seedance 2.x 视频价格均由 Token 单价和 Token 用量共同决定。官方估算公式为：

`Token 用量 = (输入视频时长 + 输出视频时长) × 输出宽 × 输出高 × 帧率 ÷ 1024`

因此，表中是每百万 Token 原价，不是固定的每条视频或每输出秒价格。对 Seedance 2.0 系列和
Seedance 2.5，输入包含视频时还可能适用官方最低 Token 用量限制；实际用量以 API 返回的
`usage.completion_tokens` 为准。只对成功生成的视频计费。

每秒价格的计算口径：

1. 表中“每计费视频秒”是 `Token 单价 × 单秒 Token 用量`的估算值，保留 6 位小数。
2. 输入不含视频时，一个计费视频秒就是一个输出视频秒，因此可直接视为每输出秒原价。
3. 输入包含视频时，一个计费视频秒指一个 `输入视频秒 + 输出视频秒`；单个输出秒的实际摊销价为
   `表中每计费视频秒价 × (输入视频时长 + 输出视频时长) ÷ 输出视频时长`，并受最低 Token 用量限制，
   所以不存在一个脱离请求参数的固定“每输出秒”价格。
4. 按官方 16:9、24fps 价格示例与 Token 公式折算：Seedance 2.5 采用的单秒 Token 用量为 480p `9,607.5`、
   720p `21,600`；Seedance 2.0 / Fast / Mini 采用 480p `864×496`、720p `1280×720`、1080p `1920×1080`、
   4K `3840×2160`；Seedance 1.5 Pro 采用 480p `864×480`、720p `1280×720`、1080p `1920×1080`；
   Seedance 1.0 Pro / Fast 采用官方示例的 480p `864×480`、720p `1248×704`、1080p `1920×1088`。
