# 音视频证据评审修复记录

## 问题与目标

修复任务日志详情与音视频 HTTP 证据一期评审中发现的采集位置、正文覆盖、脱敏、完整性、
配置故障、关闭功能崩溃及查询入口缺口。保留现有 Task/attempt/计费事实源，不增加付费重放。

## 当前实际情况

- ModelArk 在认证后、正文转换前建立证据；后续入口重复调用不会重新采集转换后的正文。
- 创建、响应和轮询共用数据库事件 ID 构造唯一对象键。事件先以 unavailable 持久化，正文提交后
  更新为真实阶段；对象存储禁止覆盖，文件和目录同步完成后才确认写入。
- 响应捕获记录 EOF、错误、截断与实际捕获长度；关闭只完成一次。脱敏前后长度差异不再用于
  判断传输完整性。结构化正文不完整且无法安全脱敏时保留 unavailable 事件，不保存可泄露凭据的片段。
- Seedance 在 HTTP 返回后、adapter 归一化前包装原始响应；通用轮询避免为同一观察重复记录。
- JSON、multipart、表单和 SSE 按类型脱敏；管理员预览在截取前遮盖 URL 查询参数。凭据占位符
  不可逆；Root 下载也不恢复凭据。下载和预览核对正文哈希。
- 配置错误保持启用但拒绝请求；文件写入有等待上限和并发上限。底层文件系统调用不能强制取消，
  超时后的迟到对象可能成为无引用对象，不会恢复发送资格或把事件改成 complete。
- 南向写入后重新检查既有 attempt；若恢复程序已改变状态或无法查询，停止发送并保留资金，
  不按旧请求内存状态自动释放。仍为 sending 的发送前证据失败走既有释放路径。
- 两套视频代理关闭证据时安全返回；计费摘要读取真实 `_task` 探针结构。
- 任务详情及带请求 ID 的消费日志详情新增按需加载的证据入口，支持空、失败、过期和不完整状态；Root 可下载正文。
  后端支持平台请求 ID、任务 ID、上游请求 ID 查询，创建响应头及 Task 冻结事实用于关联上游 ID。
- 外层响应呈现完成后记录客户 JSON 响应；二进制交付记录写出统计，避免重复归档媒体。

### 原生文件接线与同步影响

| 文件 | 必要性与最小接线 | 上游同步影响 |
| --- | --- | --- |
| `controller/relay.go` | Relay/RelayTask 增加 defer，覆盖最终响应与错误呈现 | 两个入口各一行，保留原生错误/计费顺序 |
| `relay/channel/api_request.go` | 传输失败时追加无正文事件 | HTTP 错误分支增加一行，不改变重试决策 |
| `relay/audio_handler.go` | 证据错误显式 skip retry，防止无 attempt 音频换渠重试 | DoRequest 错误分支的窄判断 |
| `service/task_polling.go` | 对已在 adapter 取证的轮询跳过重复采集 | 三个证据调用点，不修改任务状态判断 |
| `relay/channel/task/seedance/adaptor.go` | HTTP 返回边界接入原始轮询证据 | 一个调用及标记方法，归一化语义不变 |
| `middleware/modelark_video.go` | 转换前建立证据、退出时完成客户响应记录 | Link 专属中间件中的窄调用 |

主体实现、类型和回归测试均在证据专属文件中。未改写用户已有的图片/对象存储实现。

## 优化方案与验证

已验证本地 SQLite、加密目录和假 Provider HTTP 回环；未进行真实 Provider 付费调用、生产灰度、
MySQL/PostgreSQL 外部数据库验证。本地检查结果：

- service、controller 全包回归通过（分别 426、474 个测试/子测试记录）；middleware、relay、
  Seedance、system_setting 全包回归通过。随后新增的并发与资金恢复用例通过定向回归。
- Moxing 所在 thirdparty 包全量测试通过，保留显式 `generate_audio=false → with_audio=false`。
- 前端日志模块 6 个测试文件、18 项测试通过；类型检查及变更文件 lint 通过。
- 文档检查与 AI 入口检查通过。
- 覆盖：关闭证据后视频代理、真实 ModelArk 中间件转换前取证、真实 FunCloud HTTP 原始轮询、
  创建/轮询对象不覆盖、并发写入、EOF/提前关闭/读错误/超限、multipart 凭据、Admin 预览、
  配置错误、存储不可用及 attempt 已恢复时不发送不退款、客户最终 JSON 响应。

二期 WS/Realtime、独立 WebSocket TTS、Chat/Responses/Gemini 媒体入口仍不在本次一期修复范围。
本地目录须持久化挂载；多实例须共享可用的目录与密钥。历史缺失或已覆盖正文不能回填。
