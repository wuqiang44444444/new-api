# 未签入图片与证据代码评审修复记录

## 问题与目标

修复本次全部未签入代码评审确认的七项问题，保持 NEWAPI 原生文件最小接线，
不引入第二套 Task、账本、请求头解析或保留期限规则。

## 当前实际情况

- 已取得 FunCloud 任务 ID 后的查询错误与空结果保留待核实，不按创建拒绝触发退款。
- 同步 Google 标准图片发送链路返回传输错误时禁止重试，覆盖上游收到 POST 后断连窗口。
- 证据正文裁剪后判空，纯空白非结构化正文不再引发越界；非法 JSON 仍标记不可用。
- 自定义请求头由现有解析器在受理时解析，加密绑定到任务；Google、FunCloud 创建/轮询及
  Moxing 执行应用冻结结果，缺少快照不回读当前配置。
- 恢复查询按更新时间、ID 排序与分页，已尝试但不可恢复任务不会持续占据最老的一批。
- 图片编辑投影明确 JSON 数组、元素类型与互斥输入；复用创建 DTO，删除重复编辑 DTO。
- 存量任务补建证据索引统一写入保留期限。

当前事实见[图片架构](../20-architecture/图片服务与异步Provider适配架构.md)、
[证据架构](../20-architecture/音视频请求证据架构.md)及
[公开投影架构](../20-architecture/公开模型元数据投影架构.md)。

## 优化方案与验证

原生文件改动必要性与冲突面：

| 文件 | 必要接线 | 上游同步影响 |
| --- | --- | --- |
| `relay/image_handler.go` | 图片请求错误交给新增文件分类，避免重复生成 | 仅替换错误出口的一次调用 |
| `relay/helper/valid_request.go` | 将新增 multipart 字段解析委托同包新增文件 | 撤出大段扩展字段解析，只保留错误处理窄分支 |
| `task-details-dialog.tsx` | 视频参数交给新增专用组件 | 撤出大段 JSX，保留 props 接线；原版权声明保留 |
| `relaykit/dto/public_model_api.go` | 编辑复用创建 DTO，增加数组元素及互斥输入元数据 | 仅公开合同字段；独立模块构建验证 |

新增回归使用本机模拟 Provider、SQLite 及确定输入验证网络断连、查询错误、冻结头、
资金占用、恢复公平性、空白正文、晚建索引到期及元数据与解析器一致性。
本机验证已通过：涉及的后端包及全部 Relay 包共 36 个有测试包、relaykit 独立构建、
前端类型检查、定向 lint、证据界面 4 项测试、`task docs:check`、`task ai:check`、
公共 API 文档校验（20 页、30 个操作）。新增边界测试均通过。

真实 Provider、真实账单、S3/Azure 服务、外部数据库、
双节点与生产灰度不在本次本机验证证据内，继续保留原方案验收门槛。
