# Link 视频结果 OSS 真实渠道验收

## 1. 问题与目标

按用户授权，使用本地项目已启用的真实视频渠道、已有测试 Key 和真实对象存储配置，对
Vidu、FunCloud、Synlink、墨行各提交一条 mini 视频请求，验证生成与本站 OSS 托管交付。
本次执行于北京时间 2026-10-14 23:51 至 2026-10-15 00:28，使用当前修复后的后端、
本地主数据库 PostgreSQL 和真实 Azure Blob；没有使用 SQLite 测试库或模拟 Provider。

统一请求：文本生成、`duration: 4`、最低公开分辨率档位 `resolution: "480p"`、
`ratio: "16:9"`、`generate_audio: true`、`return_last_frame: true`。提示词为清晨树枝上的
小鸟鸣叫与风声，无人物、字幕或标志。每条线路只提交一次生成 POST，后续均为查询或文件读取。

### 2.2 已通过的主视频合同

三条成功结果均从配置的本站 Azure Blob 下载，实际 MIME 为 `video/mp4`。

| 项目 | Vidu | FunCloud | Synlink |
| --- | --- | --- | --- |
| 完整对象字节数 | 1,295,123 | 991,425 | 1,222,599 |
| 文件时长 | 4.096 秒 | 4.096 秒 | 4.096 秒 |
| 编码尺寸 | 864×496 | 864×496 | 864×496 |
| 音频 | 一条 AAC，非静音 | 一条 AAC，非静音 | 一条 AAC，非静音 |
| 主视频累计转存领取次数 | 1 | 2 | 1 |

- 完整 GET 返回 200；下载字节数与对象 HEAD 的 Content-Length 一致，ffprobe 可解析。
- `Range: bytes=0-1023` 返回 206 和 1024 字节；重复读取相同范围字节一致。
- 平台 HEAD 内容入口返回 302，方法专用签名对真实 OSS HEAD 返回 200。
- 签发后即时测得剩余有效期约 86399 秒；再次授权查询签发新地址，仍指向同一对象。
- 带本地前端 Origin 的真实 Range 请求收到允许的 CORS 响应头；未进行浏览器播放验收。
- 去掉签名的对象 HEAD 返回 409，匿名读取未获成功；签名读取返回 200。
- 所有成功主视频及已就绪尾帧的对象登记均为 ready；续签后没有新增成功对象或生成尝试。

请求的 480p 表示最低公开档位；实际编码尺寸与时长如上记录，不按像素高恰好 480 或媒体
容器时长恰好 4.000 秒作不实断言。非静音音轨通过 ffmpeg 音量分析验证，未做人工听感验收。
首次 Python 下载出现客户端截断/读取失败；改用 curl 完整下载后，三条结果长度与 HEAD 相符，
均可解析。该现象没有被记为 OSS 对象损坏。
