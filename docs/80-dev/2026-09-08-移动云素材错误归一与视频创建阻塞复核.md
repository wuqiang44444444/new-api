# 移动云素材错误归一与视频创建阻塞复核

## 问题与目标

渠道 92 删除素材成功后，查询和重复删除均被平台返回为 502。用户要求优化错误语义，然后重新分析无法创建视频的原因。

只修复移动云单素材操作已经真实验证的错误组合，不改通用错误层、视频协议、渠道配置或价格，不建立本地删除状态、重试或查询补偿。

## 当前实际情况

使用此前已删除的同一个测试素材进行真实复核，移动云返回：

| 操作 | HTTP | state | errorCode | errorMessage |
| --- | --- | --- | --- | --- |
| GET 单素材 | 500 | ERROR | C500999 | NotFound.asset_id |
| DELETE 单素材 | 400 | ERROR | C400999 | 素材不存在或无权限访问 |

原适配器在非 2xx 分支直接返回 HTTP 错误，未解析业务错误，因此统一映射为 502。原有业务错误识别只匹配错误码中的 NOT_FOUND/NOTFOUND，即使直接放开响应体解析也不能识别上述两个通用错误码。

## 优化方案与实现

新增移动云专属 `cmccAssetHTTPError`，仅在 `/asset/{id}` 的 GET/DELETE 操作、HTTP 状态、ERROR 状态、业务错误码和错误信息全部精确匹配时，返回既有 `ErrAssetResourceNotFound`。服务层和控制器沿用既有映射返回 `404 asset_not_found`。

重复删除中的“无权限访问”不被解释为删除成功；统一 404 不泄露该资源是否存在。不匹配的错误、素材组操作及无效 JSON 继续走原 HTTP 错误路径。

现有移动云适配文件仅替换非 2xx 分支的一行调用，新增逻辑和回归测试放在两个独立文件。没有修改 NEWAPI 原生文件或 relaykit 模块。

## 验证结果

- 两项真实响应回归先在旧实现失败，修复后通过。
- 覆盖同业务码不同错误、不同状态码、不同操作、素材组、无效 JSON 等不应被转成 404 的边界。
- 相关 assets/service/controller 的 CMCC 与素材错误测试通过。
- 用重新构建的适配器再次请求真实移动云：原 GET 500 与 DELETE 400 的业务字段一致，两项 `IsUpstreamNotFound` 均从 false 变为 true。
- 本地运行中的后端未替用户重启；管理/客户 API 生效需要重新构建并重启后端，不能把独立适配器复验写成在线 HTTP 404 已验收。

## 视频创建阻塞复核

渠道 92 当前启用，客户模型 `seedance-2.0-cmcc` 映射到 `doubao-seedance-2.0`，视频协议 `modelark_v3_cmcc`，素材协议 `cmcc_aicc_assets_v2`。

1. **本地计费配置缺失。** 该客户模型没有 tiered_expr 模式、表达式及预扣 Token 配置。实际提交一条 4 秒、480p、带既有素材引用的请求，HTTP 400、`model_price_error`，明确要求 tiered_expr。没有创建 attempt 或 Task，临时 Key 扣费为 0。
2. **视频凭据被上游拒绝。** 使用当前 Channel 的视频 Key，对视频任务列表执行一次只读请求，真实返回 HTTP 403，错误信息精确为 `api key is invalid`。此次没有绕过平台计费配置提交上游视频创建。

素材接口使用独立 AK/SK 签名，视频使用 Channel Key 的 Bearer 鉴权。素材查询/删除可调用，不能证明视频 Key 有效。这两个视频阻塞独立于本次素材 404 修复。

后续应按已确认价格补齐该客户模型的计费配置，并更换或修正与当前视频接入地址匹配的 API Key，先验证视频鉴权，再复测创建。本轮没有修改上述配置，没有重新创建用户已删除的 106 副本；临时测试 Key 已禁用。尚未进入视频生成阶段，不能据此判断移动云视频对该素材的最终兼容性。
