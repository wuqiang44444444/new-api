GPT-image-2 的渠道 15、29、57 已验证同步生成/编辑与异步查询交付（57 同步编辑首次限流，复测成功）；渠道 102 同步成功、两个异步任务待核实；渠道 48 停用，未触达上游。不能据此宣布所有 GPT-image-2 渠道均已完成真实验收。

渠道 34 的两个 Seedream 模型、渠道 99 的 nano-banana-2 全链路通过。渠道 103 的三个模型均取得同步与异步成功样本，但两项异步首次失败、复测成功，稳定性仍需观察。渠道 88 参数错误，渠道 89 同步触发月度消费上限、异步被上游拒绝；渠道 93 停用；randy 未配置价格。

测试账本核对一致：已结算 1,005,260 quota（$2.010520），待核实占用 10,420 quota（$0.020840），合计钱包和测试 Key 净减少 1,015,680 quota（$2.031360）。以上为测试客户额度，不是 Provider 实际成本。

## 1. 问题与目标

按用户要求实测当前配置的全部图片相关渠道，逐项记录渠道、模型、请求参数、响应、Token 用量与图片地址。同步和 Prefer: respond-async 分开验证；不把模拟测试或历史实测混入本轮。

本轮 18 个渠道/模型组合、11 个渠道，主矩阵 72 项、定向复测 3 项；完成 75 项，成功交付并可读取图片 38 项。

### 2.2 账本核对与验收边界

- 测试 Key 对应消费日志合计：1005260 quota；未匹配日志：0 条。
- 额外后台探测：27 条消费日志、13927 quota，token_id=0，单独列出，不计入图片用例消费合计；这些日志未扣测试钱包，但上游实际费用仍需供应商核对。
- quota / 500000 为测试客户美元金额；上游真实现金成本需供应商账单核实。
- GET /v1/tasks 的本轮公开响应不包含 usage；异步输入/输出 Token 来自后台任务快照及消费日志，不能伪称客户查询响应返回了 Token。
- 异步消费日志主列 prompt_tokens 固定为 0 的样本，实际输入量保存在任务 usage 和日志 other.prompt_tokens；下方逐项保留三份证据。本轮不修改计费代码。
- 只覆盖单图 n=1 的生成/编辑与非流式异步；mask、多图、流式、幂等重放、重启恢复、512 MiB 边界与最低版本外部数据库未在本轮验收。
- HTTP 403 的停用渠道未触达上游，不能据此认定 Provider 功能失败或成功。名称不等于启用状态，报告以状态字段为准。
