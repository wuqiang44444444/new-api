# 硬约束

## Technology
- 后端使用 Go 1.22+、Gin、GORM v2。
- 前端默认实现位于 `web/default/`，使用 React 19、TypeScript、Rsbuild、Base UI、Tailwind CSS。
- 数据库代码必须同时兼容 SQLite、MySQL >= 5.7.8、PostgreSQL >= 9.6。
- 前端包管理和脚本优先使用 Bun。

## Security
- 绝不提交密钥、Token、Cookie、真实支付凭据或生产环境配置。
- 认证、计费、额度、限流、审计相关改动必须保留可验证的行为边界。
- 受保护的项目名称、组织/作者身份、授权、署名和元数据不得删除、替换或弱化。

## Architecture
- 代码按 Router -> Controller -> Service -> Model 的分层边界推进。
- Provider relay 请求 DTO 的可选标量字段必须使用指针类型并配合 `omitempty`，保留显式零值。
- Go 业务代码的 JSON marshal/unmarshal 必须使用 `common/json.go` 中的封装。
- 涉及表达式计费前必须先读 `pkg/billingexpr/expr.md`。
