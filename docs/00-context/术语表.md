# 术语表

## 1. 客户入口与模型

### NEWAPI 原生能力

由上游代码完整提供的 Router、DTO、Relay、Provider adapter、模型发现和计费语义。原生能力不因本地
Link 设计被重新分类、包装或收紧。

### Link 扩展

项目新增的客户入口、代码化 Provider adapter、异步执行和素材代理。Link 复用 NEWAPI 的 Token、
Group、Channel、价格、Task、计费和日志，不建立 publication、Link SKU、implementation 或
execution binding 等平行身份。

### 客户接入合同

客户直接依赖的路径、鉴权、请求字段、响应、错误和生命周期，例如 Seedance 使用的 ModelArk V3。
它不等同于南向 Provider 协议。

### 客户模型

客户在请求、`/v1/models`、价格、日志和账单中使用的模型名。Seedance 的一个已启用客户模型只对应
一个 `ChannelTypeSeedanceLink` Channel。

### Provider 模型

通过 Channel 的 `model_mapping` 发送给 Provider 的真实模型名或 Endpoint ID。它不向客户公开。

## 2. 渠道与协议

### Channel

Channel 保存 Provider 连接、凭据、客户模型列表、协议和账号作用域。Seedance 根据客户模型定位唯一
已启用专用 Channel，不写入 NEWAPI 原生 Ability 或通用分发缓存，也不参与 Priority、Weight、Affinity
或候选分发。

### ChannelTypeSeedanceLink

管理员可理解的 Seedance 专用渠道类型。国内火山、海外 BytePlus 和经技术确认的第三方 Seedance 线路
都使用该类型，具体南向差异由协议字段表示。

### video_upstream_protocol

代码登记的视频上游协议枚举。adapter 负责路径、鉴权、请求转换、状态、错误和任务行为；管理员只选择
协议，不编写 JSON 映射。

### asset_upstream_protocol

代码登记的素材上游协议枚举。一个 Seedance Channel 只能选择官方、第三方或 `none` 三种形态之一，
素材不会在运行时切换渠道或协议。

## 3. 异步执行与资金

### create attempt

高成本异步 Provider POST 在发送前建立的耐久事实。它与资金 hold 和 `sending` 状态一同提交，用于处理
“Provider 可能已创建，但本地尚未取得 task ID”的窗口。

### Task

取得可信 Provider task ID 后建立的异步业务事实。Task 冻结客户模型、Channel、Provider 模型、上游
协议、连接、素材和计费快照，后续查询、删除和结算不重新选渠。

### unknown

视频创建请求已可能到达 Provider、但平台未取得可信结果的状态。unknown 不自动重发、换渠道或退款。

### exposure

客户资金已经释放、但 Provider 可能仍产生成本时记录的平台风险事实。Provider 金额未知时保持未知，
不以客户 quota 代替。

## 4. Link 素材与真人素材组

### Asset

以 `ast_*` 表示的平台素材身份。它一对一固定到 `user_id + app_id`、客户模型、Channel、协议、凭据
身份和一个 Provider Asset；客户在视频媒体字段中使用 `asset://ast_*`。

### Public Asset Reference

以 `asset://pubref_<Provider公共AssetID>` 表示的调用方声明型官方公共预置素材引用。它不是 Asset，
不进入 `/v1/assets`、主数据库或租户配额；Resolver 仅校验格式并去掉 `pubref_` 后转发，公共资格和
可用性由 Provider 判断。

### AssetSource

创建 Asset 时提交的临时 HTTP/HTTPS URL 或 Data URL。它只存在于当前请求和 Provider 创建调用中，
不写入 Asset、Task 或日志，也不是对象存储。

### AssetGroup

以 `astgrp_*` 表示的一对一 Provider 素材组。`general` 表示普通素材组；`real_person` 承载上游真人
认证链接和状态。平台不保存人脸、证件、活体或授权表单。

### Resolver

`asset://` 到 Provider 资源引用的唯一转换点。它对 `ast_*` 校验所有权、应用、ready 状态、客户模型、
Channel、协议和凭据身份；对官方 `pubref_*` 仅校验格式并去命名空间。它不参与选渠、迁移或 fallback。

### 请求级媒体

当前视频请求直接提交的 HTTP/HTTPS URL 或 Data URL。它不创建 Asset，也不获得素材库或真人认证语义。

## 5. 计费与文档

### 预扣与结算

预扣在 Provider 调用前保留客户额度；结算在可信结果或终态后按冻结价格确认消费、补扣或退款。所有
计算必须幂等且不能因溢出产生负费用。

### OpenAPI operation 白名单

公开 API 的发布清单。OpenAPI 定义机器合同，Manifest 定义文档导航，Markdown 提供人类说明；三者必须
在 Web 构建时一致校验。
