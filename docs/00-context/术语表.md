# 术语表

## 1. 合同与模型身份

### NEWAPI 原生能力

由上游代码已经完整提供的 Router、DTO、Relay、Provider adapter、模型发现和计费语义。原生能力
不因本地 Link 设计被重新分类、包装或收紧。

### Link 服务合同

通过本地代码扩展、显式注册并获准发布的端到端客户合同。它由客户接入合同、客户模型 publication、
Link SKU 能力、任务与计费、Link 资源和上游调用合同共同组成。

配置 Channel、Ability、模型映射、价格或 profile 不会自动产生 Link 服务合同。

### 客户接入合同

客户直接依赖的路径、鉴权、请求字段、响应信封、错误和生命周期，例如 ModelArk、Kling 或即梦的
类型化视频协议。它不等同于 Provider 的真实调用协议。

### 客户模型

客户在请求、模型发现、价格、日志和账单中使用的模型名。管理员可以自定义该名称；它不要求与
Link SKU 或 Provider 模型同名。

### 客户模型发布事实（publication）

以下稳定映射的持久化权威：

```text
contract namespace + route family + customer model
  -> Link SKU + publication version
```

publication 独立于当前渠道、Ability 和缓存。普通保存只能创建或核对；显式改绑必须校验版本、记录
操作人和原因，并追加不可变审计。

### Link SKU

平台内部稳定的产品能力身份。它承载字段、值域、媒体组合、生命周期、Link 资源支持和计费语义，
但不作为客户必须使用的模型名。

### SKU capability

Link SKU 的版本化能力声明，是客户可观察能力的权威。Provider、渠道、profile、Base URL 和真实
模型不进入 capability 身份。

### Provider 模型

通过渠道 `model_mapping` 发送给 Provider 的真实模型名或 Endpoint ID。它只参与上游调用和审计，
不能反向决定客户合同或价格键。

## 2. 实现与配置

### Link implementation

代码注册的 Provider 履约实现，以不可变 `implementation ID + version + content hash` 标识。它声明
可履约 SKU、渠道类型、profile、adapter、资源解析模式、任务、计费和 exposure 要求。

### Link 接入方案

管理端对一个精确 implementation ID/version 的只读配置投影。选择方案后，Provider、profile、路径、
adapter 和资源解析方式被确定；管理员仍使用既有 `models` 与 `model_mapping` 配置客户模型和
Provider 模型。

### Channel / Ability

Channel 描述 Provider 连接、凭据和运行配置；Ability 表示某客户模型、分组和渠道当前可以参与
分发。二者只决定当前可履约性，不创建或改写 publication、Link SKU 和 implementation。

### execution binding

implementation 内的代码注册关系，按 route family、action、profile 和 Provider 模型精确解析 Link
SKU。它用于 publication 推导和发送前复检，不是管理员维护的第二张模型映射表。

### profile

渠道适配协议的形状标识，描述请求路径、鉴权、转换和查询方式。profile 不是 Provider 身份，也不能
单独授予 Link 资格。

### 上游调用合同

网关实际调用 Provider、反代或中转所使用的路径、鉴权、请求转换、状态归一化和上游资源标识。
它只说明“如何履约”，不能扩张客户能力。

## 3. 异步执行与资金

### create attempt

可能创建持久化 Provider 任务的请求在发送前建立的耐久事实。它冻结合同、实现、连接、资金 hold
和对账信息，用于处理“Provider 可能已创建，但本地尚未取得 task ID”的窗口。

### Task

取得可信 Provider task ID 后建立的异步业务事实。Task 使用创建时冻结的客户合同、publication、
implementation、连接、素材和计费快照完成轮询、终态与结算。

### reconciliation

创建结果或轮询响应不可采信时的有界对账过程。进入对账不等于业务失败，也不自动触发重发、换
渠道或退款。

### exposure

客户资金已经释放，但 Provider 可能仍产生成本时记录的平台风险事实。exposure 与客户账本分离；
未知 Provider 金额保持未知。

## 4. Link 资源与真人授权

### Link 资源

以 `ast_*` 表示的平台逻辑媒体身份，客户在媒体字段中使用 `asset://ast_*`。平台不保存媒体二进制，
资源可以通过 Provider binding 或受保护 source URL 解析。

### AssetSource

Asset 的不可变、作用域加密 source URL 与客户声明过期时间。它不是独立客户资源、内容指纹或长期
对象存储。

### AssetBinding

Asset 在精确 implementation、channel、profile 和凭据作用域下的 Provider 托管引用。binding 不向
普通客户暴露 Provider 资源 ID。

### Resolver

`asset://ast_*` 到 Provider binding 或 source URL 的唯一转换权威。它在选渠前和每次 Provider 尝试
前校验所有权、应用、publication、状态、授权、实现、凭据和 TTL。

### 请求级媒体

模型公开合同允许客户在当前请求中直接提交的 HTTP/HTTPS URL 或 Data URL。它不创建 Asset，也不
获得平台资源的复用、迁移、授权和撤回语义。

### 真人授权

固定到应用、匿名最终用户、客户模型 publication 和 Provider 账号的技术授权事实。Provider H5
认证成功不等于平台保存自然人专项同意；应用负责其业务和法律同意证据。

### authorization reservation

真人素材任务在发送前写入的可索引使用关系。它与撤回锁定同一 authorization 行，用于明确“撤回
先发生”或“平台已接受本次使用”两种并发结果。

## 5. 兼容字段

以下名称因持久化兼容保留，不再作为新文档的概念分类：

| 字段 | 当前语义 |
| --- | --- |
| `northbound_contract_id/version` | 客户接入合同 ID/version |
| `southbound_adapter_version` | 上游调用合同 adapter version |
| `video_upstream_profile` | 视频渠道适配 profile |
| `asset_upstream_profile` | 素材渠道适配 profile |

修改这些字段必须作为独立数据迁移和兼容项目评估，不能在术语整理中顺带改名。
