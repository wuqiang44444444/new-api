# 项目简报

## 1. 项目定位

new-api 是一个统一 AI API 网关与治理平台，聚合多家文本、图片、音频和视频 Provider，并提供用户、
API Key、渠道路由、限流、额度、计费、异步任务、Link 资源、审计和管理控制面。

TokenAI 是当前面向客户的服务定位：通过统一入口降低模型接入与切换成本，并让团队能够管理调用
权限、稳定性、费用和运行证据。

## 2. 目标用户

| 用户 | 主要诉求 |
| --- | --- |
| API 开发者 | 使用一个 API Key 和清晰合同调用已开放模型 |
| 应用团队 | 管理模型能力、异步任务、媒体资源、用量和成本 |
| 平台管理员 | 配置渠道、客户模型、协议、价格、分组、启停和回滚 |
| 运维与审计人员 | 验证 Provider、处理异常任务、核对账单与风险暴露 |

## 3. 核心价值

- **统一接入：** 复用 NEWAPI 原生协议或本地代码化 Link 入口，不要求客户理解 Provider 私有实现。
- **受控路由：** 原生能力沿用上游分发；Seedance 按客户模型确定唯一专用 Channel。
- **耐久执行：** 对适用的异步请求保存创建、任务、连接和计费事实，支持轮询、补偿和对账。
- **素材兼容：** 通过带客户模型的无状态单资源代理转发 Provider 素材与真人认证流程，调用方自行保存
  Provider opaque ID；视频素材引用由 Provider 最终判断兼容性。
- **费用透明：** 统一预扣、结算、退款和日志，按 API Key 与客户模型提供可核对账单。
- **安全可审计：** 隔离客户身份、Provider 凭据和敏感数据，为合同、计费和异常处置保留证据。

## 4. 产品边界

平台同时承载两类能力：

1. **NEWAPI 原生能力：** 沿用上游现有 Router、DTO、Relay、Provider adapter、模型发现和计费语义。
2. **Link 扩展：** 仅用于本地新增客户入口和代码化 Provider adapter，不建立平行模型身份系统。

两类能力可以共享鉴权、渠道、Task、计费、资源和日志底座，但不能互相推断、包装或兼容降级。
客户只依赖其调用入口、客户模型和公开字段，不接触 Provider 模型、渠道账号或凭据；素材 API 返回的
opaque 资源 ID 是例外，它没有 Provider 命名空间或账号信息。

## 5. 主要产品能力

### 5.1 模型调用

- 文本、图片、音频和视频按各自已发布合同调用；
- 图片同步与异步结果在同一客户合同中投影；
- NEWAPI 原生 OpenAI Videos 与显式 Link 视频合同保持隔离；
- Seedance 客户模型直接定位唯一专用 Channel，再经 `model_mapping` 转成 Provider 模型；不写入原生 Ability。

### 5.2 异步任务

- 适用的 Provider POST 在发送前建立耐久创建事实和资金 hold；
- 取得可信 Provider task ID 后才创建正式 Task；
- 在途任务按创建时客户模型、Channel、协议、连接和计费快照完成生命周期；
- 创建结果或轮询响应不可确定时进入对账，不自动重发、换渠道或提前退款。

### 5.3 Link 素材与真人素材组

- `/v1/assets` 和 `/v1/asset-groups` 是调用方自管、带客户模型的无状态单资源代理，不提供列表；
- 创建和查询返回 Provider opaque ID，可同时返回 `asset://<opaque-id>`；调用方保存模型和 ID 的对应关系；
- 平台不保存素材、素材组、source URL 或媒体二进制，也不建立租户绑定、跨 Provider 探测或 fallback；
- 视频中的 `asset://<opaque-id>` 不做本地可用性校验，由客户模型选中的 Provider 最终判断；
- 真人认证直接使用上游页面，平台不自建表单、授权域或撤回状态机。

### 5.4 计费、账单与公开文档

- 客户资金复用统一 quota、预扣、结算、退款和消费日志；
- Provider 潜在成本使用独立 exposure 事实，不污染客户账本；
- 自助账单按周期、API Key 和客户模型聚合已结算日志；
- 公开 API 文档由 OpenAPI、operation 白名单、Manifest 和 Markdown 在同一 Web 构建中交付。

## 6. 非目标

- 不把平台建设为对象存储、媒体内容审核机构或自然人同意证据系统；
- 不向客户公开 Provider 凭据、真实模型、上游任务 ID 或内部执行快照；素材 opaque 资源 ID 按无状态
  代理合同直接返回，但不附带 Provider、Channel 或账号信息；
- 不为 NEWAPI 原生能力建立平行的 Link Router、任务体系或计费账本；
- 不把账单描述为税务发票、会计总账或任意历史余额快照；
- 不承诺未经真实 Provider、账单、外部数据库和灰度验证的能力已经生产可用。
