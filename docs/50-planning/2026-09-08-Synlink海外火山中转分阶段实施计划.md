# Synlink 海外火山中转分阶段实施计划

## 1. 目标与范围

依据[已评审接入分析](../80-dev/2026-09-08-Synlink海外火山中转协议与托管素材接入分析.md)，
新增 `synlink_video_v1` 南向协议，复用 Seedance 专用渠道、ModelArk V3 北向、Task 与资金底座。
本站托管图片与直接 URL 两条路径共存；保留 FunCloud 现有行为与已保存素材。
用户已授权建立计划并实施代码与相应合同更新，后续追加授权真实渠道配置及 Mini 实测。
已完成 [Mini 四图 URL 测试](../80-dev/2026-09-08-Synlink渠道Mini四秒四图真实测试.md)与
[四图托管 asset 测试](../80-dev/2026-09-08-Synlink托管素材四图引用真实测试.md)，客户结算退款已核对。
供应商货币账单及其它模型仍待验收，不把自动测试或单个模型实测通过扩大为整渠道生产发布。

## 3. 实施决策与约束

- 新增南向协议，不新增 ChannelType，不修改 NEWAPI 原生视频入口。两家供应商同时运营时使用
  两条同类型 Channel 和不同客户模型名，一条 Synlink Channel 可配置四个已登记 Provider 模型。
- 列表继续读取本站 Task；取消与终态删除在没有供应商支持证据时不登记支持，沿用既有 409 错误。
- 素材复用现有 `funcloud_material_hosted` 配置标识、存储与记录；界面显示“平台托管图片库”。
  不新增素材表、不迁移对象、不更改现有不透明素材 ID。
- Synlink 的本站 asset 预扣前校验并冻结，发送时转换为临时 URL；非本站 opaque 引用在该协议内
  明确拒绝，其他协议保持原有语义。直接 URL 不自动存储，不发送 FunCloud 私有字段。
- 尾帧路径登记与北向交付分开核对；已发布字段不能静默忽略。未知状态或不可信响应不制造业务失败，
  创建 unknown 不重发、不换渠道、不退款。
- 模型允许集合与参数限制分开核验；只使用供应商文档、适用的官方文档或实测支持的语义。
- 原生文件若需要接线，仅保留必需常量转出或单行调用，并记录必要性及上游同步冲突面。
  不覆盖工作区中已有的其他任务改动。

## 4. 验证与剩余事项

实现验证应覆盖：创建可信 ID、状态/ID/结果异常、嵌套用量、显式 false/0、冻结连接、
托管图片与 URL 混合、用户隔离、非本站引用、模型允许集合、管理配对及元数据。
相关 Go 包测试与 `cd relaykit && GOWORK=off go build ./...` 必须通过；前端遵循 web/AGENTS.md。
文档执行 `task docs:check`、`task ai:check`，如改公开 API 文档另跑 `bun run docs:validate`。

真实 Provider 参数完整性、处理中/失败/不存在响应、尾帧和回调交付、供应商价格与真实账单
尚待核实；P5 不得以本地模拟测试替代。不登记未经证明的终态失败和 HTTP 拒绝分类，避免错误退款。

### 已实施范围与接线影响

- 视频协议、传输 profile 与 adapter v1 已登记。四模型 exact allowlist 共用代码来源；北向仍为
  ModelArk V3，列表读取本站任务，取消／删除不支持且不清理本地任务。
- 创建解析 `task.id + pending`，查询解析 `pending/completed`、单个 HTTPS output、嵌套 usage、
  文档中的秒数与时间格式。创建不明确结果进入 attempt `unknown`；查询非 2xx、未知状态、
  ID 不匹配等不可采信观察使未成功任务持久化为 `RECONCILIATION_REQUIRED`，不会按单次观察失败退款。
  已成功任务保持成功与已接受的计费事实；之后可信查询可恢复活动任务或补齐成功任务用量。
  既有本地超时与人工核查规则继续适用，不把“本次不退款”表述为永久取消生命周期处置。
- 托管图片沿用同一表、对象、`fhas_*` ID 和用户共享域；预扣前校验并冻结，发送阶段复用签发函数。
  普通 URL 保持原值，FunCloud 私有真人字段仅由 FunCloud adapter 发送。
- 尾帧已完成本地交付适配：请求布尔值随正常创建及 unknown 人工恢复模板冻结，返回本站内容地址，
  只向冻结连接构造的尾帧路径附加密钥，禁止重定向。供应商实际二进制响应仍待 P5 验证。
- 新逻辑放入 Synlink 独立文件。必要接线局限于既有 Link 注册表、Seedance adapter、素材预检、
  内容代理与 Task JSON 快照；共享表达式预扣仅扩大已登记协议条件。没有修改原生视频 Router、
  原生 Provider adapter、表达式引擎或数据库结构；以后同步的冲突面集中于这些局部注册与调用点。
- NEWAPI 协议核对：本地及上游 `router/video-router.go` 的原生路径为 `/v1/video/generations`，
  与供应商文档 `/v1/video/generate`、`task.outputs` 不一致。“NEWAPI 标准协议”尚不能替代
  该线路证据。未修改供应商原文，也未使用其它 NEWAPI 协议补猜失败状态。

### 剩余验收与发布门槛

1. 获取四模型各自的时长、分辨率、媒体数量限制与默认值。当前仅发布已登记参数形状，使用公共
   正时长安全上限；`duration=-1` 缺乏预扣上界，不发布。默认 5 秒、720p、无音频与探针一致。
2. 获取 processing／failed／不存在／鉴权失败与配额失败的精确响应，登记有证据的状态与创建拒绝分类。
3. 验证四模型生成、托管与直接 URL 混合、删除后在途任务、签名有效期与尾帧鉴权交付。
   回调及其它未登记字段暂未发布；需确认回调内容和身份隔离后再实现。
4. 配置该线路自身价格；核对真实 Token、成功缺用量、unknown 人工处置与供应商账单。
5. 完成对象存储与 MySQL/PostgreSQL 部署验证、灰度和回滚演练后，才进入生产分组。

### 评审修复与回归（2026-09-08）

- 查询 HTTP 边界：Synlink 非 2xx 查询响应在 adapter 内归为不可采信观察，先于通用 HTTP 分类处理；
  404/410 不再直接触发任务失败与退款。原生及其它协议的通用轮询行为保持不变。
- 回归先通过真实 ModelArk HTTP 创建建立 Task 与资金 hold，再调用真实 Synlink adapter 和持久化
  轮询。修复前 404 稳定复现 `FAILURE`；修复后 404/410/401/403/429/500 与未知状态进入待核查，
  保留 700 quota，后续 pending 恢复 queued；成功缺用量进入 awaiting_usage，成功后的 404 不逆转
  终态，补齐 100 Token 后结算为 100 quota，重复查询不重复结算。数字为测试固定值，不代表价格。
- 复用既有托管集成夹具覆盖 Synlink：实际南向正文的托管 URL 签发、直接 URL 原值、私有字段隔离、
  发送时 durable attempt/hold、成功时资金转移、删除后已接受素材，以及 unknown 人工恢复不重发、
  素材与尾帧快照保留、恢复模板清理。FunCloud 原有场景一并回归。
- Synlink 已加入现有计费恢复协议集合，覆盖缺用量自动恢复、纯参数结算、债务、人工用量复核与零用量。
- 尾帧通过实际内容入口验证二进制与 Content-Type 交付、冻结地址和凭据、跨应用拒绝、未请求尾帧拒绝，
  以及重定向目标零访问；不以仅验证 helper 生成地址代替内容交付测试。
