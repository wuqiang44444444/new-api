# 路线图

本文只记录尚未完成、仍会影响发布或后续开发的事项。已经落地的产品和架构事实进入 `10-product/`
与 `20-architecture/`，正式变化进入[变更记录](变更记录.md)。

1. 移动云素材库需要从 HK 出口，美国站不支持
2. seedance 渠道保存的时候有问题
3. Seedance Channel 默认素材组的真实 Provider 与生产灰度验收尚未完成。代码、公开元数据与
   本地回归已完成；发布前须对每个准备开放的 `default_fallback` 协议验证管理员创建或复用、
   未传/空/空白组 ID 使用 Channel 默认组、显式非空 ID 原样优先且 Provider 拒绝后不回退、
   默认组缺失返回稳定 409、敏感输出脱敏，并记录重启持久化与单 Channel 灰度结果。验收完成前
   不得宣称所有线路已生产可用。
4. 统一图片服务（2026-09-05 实施 + 同日审计修复轮）未完成项分两类。待实现：Google quality/
   格式压缩/透明背景/moderation/input_fidelity 的南向映射与后处理、mask 真实遮罩编辑、同步 SSE
   partial_images、file_id 解析授权、部分成功逐图错误归因、精确像素输出转换表（依赖 G4 实测）、
   图片中转 edits/参考图（依赖输入图计费证据）。生产取证：真实 99/103 验证 URL 直传/MIME/区域与
   14 张 URL（G2）、20/50 MiB 与 Vertex inline 实测（G3）、参数真实效果（G4）、file_id（G5）、
   B1—B10 业务闭环（G11）、两节点容量/背压实测与默认值冻结（G12）、Azure S3 网关 presign 灰度
   （G9）。完成度口径本条清单与
   [图片服务架构](../20-architecture/图片服务与异步Provider适配架构.md) §0 为准（历史三分表见
   [归档的实施计划](../99-archive/2026/09/2026-09-05-统一图片服务实施计划.md) §5）；
   全部完成前异步模式与 gemini_image 族不得宣称生产可用。
5. 图片计费闭环修复（真实验收 2026-09-06 发现的未通过项）：FunCloud 图片渠道 `writeImageResponse`
   返回空 usage，按 `img_o` 收费的表达式实际扣款为 0，须按已核实的 Provider 计量配置可履约价格；
   账单 `statement_snapshot` 在表达式信息注入前形成、模式只记 token，须改用结算时冻结的计费模式与
   表达式；图片用量日志须保存 `img_o` 等图片分项，使表达式费用可独立复算。修复后须经日志实际
   复算验证，不得用假 Token 或静默按次降级冒充通过。
6. `generate_audio=false` 的成品仍含非静音音轨（2026-09-06 实测）。网关北向/南向证据均确认按
   `false` 传递，须携带内部证据向对应 Provider 核查该参数的支持语义与实现；核查完成前不得对外
   承诺静音效果，也不自动转码去音频或改变统一北向协议。
7. 渠道补验：官方 Google 图片账户月度额度（当前 429）补齐后复验；Vertex 渠道发布 imagine 图片
   模型后复验；JD 渠道（库内仍启用但 Provider 对标准请求返回 400）由配置负责人核对映射与状态；
   S3 真实云调用与音频生成/转写真实证据待配置后补验。各项完成前对应模型不得标为生产可用。
8. 音视频证据二期未接入：Realtime/WebSocket 双向流、Volcengine TTS 与讯飞独立 WebSocket、
   Midjourney 自有发送路径、Chat/Responses/Gemini 媒体入口按需开启。二期完成并通过覆盖矩阵验收前，
   不得宣称全量音视频请求记录。
9. 模型广场未展示 Seedance 性能指标：异步视频任务的耗时/成功率/用量指标未接入采集，平台不得
   把视频任务耗时伪装成文本 TPS，也不得用模拟或无指标数据填充模型广场；如需展示须先定义视频
   任务指标合同（受理到完成耗时、成功率等）并完成真实采集验证。
