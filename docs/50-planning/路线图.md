# 路线图

## Moxing 视频任务协议适配

目标：在保留现有下游视频任务接口的前提下，对接 [Moxing 视频模型 API](https://moxing.pro/docs/api/video)，首个目标模型为 `doubao-seedance-2-0-260128`。客户端继续调用 `/v1/video/generations` 或 `/v1/videos`，由渠道适配器转换为 Moxing 的统一异步媒体协议。

### 接口与模型

- [ ] 增加独立的 Moxing 视频任务渠道/适配器，不通过 `DoubaoVideo` 硬编码的火山方舟 `/api/v3/contents/generations/tasks` 路径发送请求。
- [ ] 创建任务调用上游 `POST /v1/media/generations`，查询任务调用上游 `GET /v1/media/tasks/:task_id`。
- [ ] 支持将对外模型别名映射为上游逻辑模型 `doubao-seedance-2-0-260128`；模型映射必须发生在发送上游请求前。
- [ ] 渠道 Base URL 使用站点根地址，例如 `https://www.moxing.pro`，由适配器统一拼接 `/v1/media/*`，避免重复 `/v1`。

### 请求转换

- [ ] 支持文生视频：转换为 `capability=video_generation`、`input_mode=text`、`control_mode=none`，并传递 `prompt`。
- [ ] 支持图生视频与首尾帧：转换为 `input_mode=single_image`，映射 `image`、`end_image` 和对应的 `control_mode`。
- [ ] 支持参考生视频：转换为 `input_mode=multi_image`、`control_mode=reference`，映射 `reference_images`、`reference_videos` 和 `reference_audios`。
- [ ] 将通用字段转换为 Moxing 字段：时长使用 `duration_seconds`，画幅使用 `aspect_ratio`，音频开关使用 `with_audio`，分辨率使用 `resolution`。
- [ ] 按上游约束验证时长、分辨率、画幅、参考素材数量和输入组合；任何可参与计费的数量在进入额度计算前必须完成边界校验。

### 异步任务与结果

- [ ] 从创建响应读取上游 `task_id`，同时保留本系统公开任务 ID 与上游任务 ID 的映射。
- [ ] 将上游 `queued`、`running`、`succeeded`、`failed` 状态转换为本系统任务状态。
- [ ] 成功任务优先从 `result.primary_url` 提取视频地址，回退到 `result.urls[0]`；失败任务记录 `error_message`。
- [ ] 将 Moxing 查询接入现有后台任务轮询、任务日志、视频代理和 OpenAI Video 响应转换链路。

### 计费与可靠性

- [ ] 复用已确认的 Seedance 2.0 模型定价策略，核对分辨率、视频输入和任务时长对最终费用的影响。
- [ ] 明确上游任务响应是否提供可结算 token；提供时按实际用量结算差额，不提供时采用经过验证的规格/时长计费规则。
- [ ] 验证预扣费、成功结算、失败退款、超时、重试和重复轮询不会产生重复扣费或负数额度。
- [ ] 保留请求 ID、公开任务 ID、上游任务 ID 和最终渠道信息，保证运行日志可以完成上下游对账。

### 验收标准

- [ ] 文生视频、图生视频、首尾帧和参考生视频至少各完成一条真实上游任务。
- [ ] 创建接口返回本系统任务 ID，查询接口最终返回可访问的视频 URL。
- [ ] 上游创建失败、查询失败、任务失败和任务超时均能返回稳定错误，并完成正确退款或结算。
- [ ] 模型别名、渠道模型和定价模型使用完全一致的配置；模型价格未配置和模型映射失败均有明确错误。
- [ ] 增加请求转换、创建响应、状态解析、结果 URL 提取、轮询和计费边界的后端回归测试。
