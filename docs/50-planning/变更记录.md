# 变更记录

> TODO: 在此补充面向项目维护的变更记录、版本说明来源和重要行为变化。

## 2026-08-02

- 通过 ADR-0013 正式建立 Link 合同的单一概念模型，将客户 API、SKU 能力、任务与计费、Link 资源和渠道适配协议统一归为其子合同。
- 新增 `00-context/术语表.md`，区分「Link 合同」与素材对象「Link 资源」，并明确「渠道适配协议」是 Provider 实现差异的子概念，不能反向定义公开能力。
- 同步更新硬约束、架构、ADR、工程对接、运维、路线图、调研、开发现场与 OpenAPI 说明；历史归档内容不改写。
- 保留 `northbound_contract_id`、`southbound_adapter_version` 等已持久化兼容名称，文档分别解释为 Link 合同 ID 和渠道适配协议版本；本轮不引入数据迁移或公共 API 改名。

## 2026-07-29

- 评审并收紧内置 API 文档中心架构：把文本、图片、ModelArk/Kling/即梦视频、素材和各自任务查询纳入合同审计候选，要求以 operationId 白名单而不是路径前缀决定公开范围。
- 新增当前有效的内置 API 文档中心实施计划；旧 `99-archive` 方案继续保留历史背景，但不再承担当前实施顺序和发布门禁。
- 将 OpenAPI 审计、公开目录全量清单、raw HTML 拒绝、dist 审计和测试运行器提升为 P0；manifest 只作为导航与运行时加载白名单，不再被视为静态发布边界。
- 固化受控 token 渲染、上下文安全动态变量、Shiki token 高亮、构建期 heading 搜索索引、统一 `docs_link`/Base URL 解析和 manifest no-cache 合同。
- 完成内置 API 文档中心首期实现：冻结 28 个公开 operation，发布 16 篇中文内容，落地 `/docs` 公开路由、受控 Markdown 渲染、三栏/移动布局、搜索、复制、缓存规则以及源内容和最终构建产物审计。
- 接入 Docs 专属 Vitest/RTL 测试和 Go 深层刷新/缓存回归测试；功能范围的 typecheck、lint、format、测试和生产构建已通过，真实视口、主题、纯键盘与部署缓存仍列为上线人工验收项。

## 2026-07-28

- 新增 ADR-0007，固化 Seedance、Kling、即梦 Link 合同中的官方协议与共享 Task/渠道适配协议的解耦；新增 ADR-0008 统一视频与异步图片的持久化计费状态机，并取代仅覆盖表达式视频任务的 ADR-0002。
- 将 `80-dev` 中六份已完成方案移入 `99-archive`，补齐 `historical`、`superseded-by` 和归档索引；`80-dev` 仅保留开发现场规则。
- 将统一图片多渠道、图片异步 Task、视频官方客户端、统一素材库、API Key 用量账单和内置 API 文档中心的长期结论从 `80-dev` 抽取到 `20-architecture`，并以当前代码区分“已实现”“配置/灰度待验证”和“已接受但尚未实现”。
- 固化媒体总边界：图片使用统一 NEWAPI 合同，视频按 Seedance/ModelArk、Kling、即梦官方合同，素材库使用平台 `/v1/assets` 与 `asset://ast_xxx`；Provider、反代和中转差异只存在于渠道适配协议。
- 新增统一图片生成与异步任务架构，明确三个公开 SKU、同步/异步联合响应、共享 Task、幂等责任转移、按结果数结算和 `gpt-image-2` 隔离。
- 新增 API Key 用量账单架构和用户指南，明确结算日志事实、异步调整行口径、非负净费用、31 天周期和非账务流水边界。
- 按当前 Advanced Custom 模板重写 TokenSave / Moxing 图片渠道配置指南，公开模型改为 `seedream-5-moxing` 与 `nano-banana-2`；Qihang 保持独立同步渠道，Seedream 4.5 保持未发布。
- 内置 API 文档中心仍是已接受的目标架构：当前只有 `docs_link` 和 `/docs` 导航回退，尚无页面、manifest、Markdown 安全渲染或搜索实现。

## 2026-07-27

- 将素材库与视频生成的五份开发现场文档收口：架构结论并入视频/素材架构，提炼开发者 API 对接指南、BytePlus 官方双凭据渠道配置指南和素材库验收操作手册，原始分析与实施记录移入 `99-archive/`。
- 对照 TokenSave 当前文档校正本地渠道 `#27/#28`：分别启用 `relay_assets` 与 `ark_assets`，修正 `#28` 的 `/v1/ark/media/*` 视频路径和 dreamina 模型映射；新增 `/assets/list`、`/v1/ark/assets/list` 只读素材连通性测试、稳定错误码及全语言界面状态。`/v1/asset/*` 明确为尚未并入 `#27/#28` 的独立 JoyCreator management facade；未确认精确合同的 Ark 素材组删除继续 fail closed。

## 2026-07-26

- BytePlus `official_action_assets` 改为视频 API Key 与素材 AK/SK 双凭据渠道：新增独立凭据表、v2 素材账号指纹、事务写入、生命周期栅栏、脱敏管理合同和只读素材 Action 测试；平台 `/v1/assets` 与 `asset://ast_xxx` Link 合同不变。
- BytePlus 双凭据渠道补齐只读视频任务列表测试、视频/素材并列持久状态、稳定连通性错误码、全语言界面文案、显式素材凭据清除保护，以及带只读账号校验和唯一索引回滚的存量 v2 指纹迁移命令。
