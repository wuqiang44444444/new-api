# API Key 用量账单使用指南

## 1. 选择账单或用量

| 要核对什么 | 入口 |
| --- | --- |
| 哪个月实际扣款、退回多少 | 控制台「我的账单」 `/billing` |
| 按日、周或月核对调用次数、Token 和净费用 | 控制台「我的用量」 `/usage` |
| 查看已入库的单次调用、请求状态或计费解释 | 控制台「使用日志」 |

三者均按当前登录身份授权。产品口径见[使用日志与报表产品设计](../10-product/使用日志与报表产品设计.md)。

## 2. 核对月账单

1. 登录控制台，打开「我的账单」，选择北京时间自然月，默认是当月。
2. 查看扣款、退款、净额和数据覆盖提示。已确认月份读取正式版本，其余月份读取已发布日报。
3. 按 API Key 和客户模型定位差异，打开对应费用明细。默认按发生日与可核实的请求或任务归并，
   展开后可查看逐笔扣款或退款。退款记入实际入账日，净退回可以显示为负数。
4. 需要离线复核时提交 CSV 导出，完成后从导出记录下载。下载权限在服务端重新校验。
   正式月账单可从版本历史查看已确认版本和确认说明。

已发布的无调用日、未发布和数据覆盖不完整分别显示。日报更新可能改变未确认账期的结果。
需要复现差异时记录账期、版本、API Key ID、客户模型、平台 Request ID 或任务 ID。

## 3. 调用账单接口

使用控制台登录访问令牌。服务端从鉴权身份取得当前用户，无需传入用户 ID。

| 方法与路径 | 用途 |
| --- | --- |
| `GET /api/billing/statement/self` | 读取自然月账单 |
| `GET /api/billing/statement/self/logs` | 查看账单费用明细 |
| `GET /api/billing/statement/self/logs/stat` | 读取同范围金额统计 |
| `POST /api/billing/exports` | 提交本人账单的异步导出 |

月账单接口使用 `start_timestamp` 和 `end_timestamp`（Unix 秒），表示北京时间自然月的开始
及月末最后一秒，两端都包含。可用 `token_id` 和 `model_name` 缩小查询范围。日报下钻和导出保留页面所用版本，正式版本按相应版本入口读取。
筛选、版本及导出合同见[客户与上游对账架构](../20-architecture/账单计费-客户与上游对账架构.md)。

## 4. 已接入旧用量接口的调用方

`GET /api/billing/self` 和 `GET /api/billing/self/breakdown` 保留周期查询。二者使用
`start_timestamp`、`end_timestamp`（Unix 秒，跨度最长 31 天），可按 `token_id` 和
`model_name` 筛选。该接口的基础金额口径和日志构成适用于原调用方，详见
[API Key 用量账单架构](../20-architecture/账单计费-APIKEY用量账单架构.md)。

## 5. 数据边界

当前余额、已入账费用和供应商对账是独立事实。尚未结算、历史日志缺失或日报覆盖不足时，按页面
提供的状态核对。CSV 不包含 API Key 密钥、请求正文或 Provider 凭据。
