# 命令清单

## Backend

- `go test ./...`
- `go run main.go`

涉及 Seedance Channel、Task、无状态素材代理或 Provider relay 时，至少执行：

```bash
go test ./model ./middleware ./controller ./service ./relay/...
go vet ./model ./middleware ./controller ./service ./relay/...
```

涉及 `relaykit/` 或其公开 API 时，根模块测试不能替代独立构建：

```bash
cd relaykit && GOWORK=off go build ./...
```

Channel 保存、Task/attempt、素材代理和计费结构必须同时验证 SQLite、MySQL 与 PostgreSQL。CI 在
`.github/workflows/ci.yml` 提供 disposable MySQL/PostgreSQL 服务；本地只跑 SQLite 不能作为三数据库
通过结论。

## Frontend

- `cd web && bun install`
- `cd web && bun run dev`
- `cd web && bun run typecheck`
- `cd web && bun run lint`
- `cd web && bun run format:check`
- `cd web && bun run test`
- `cd web && bun run build`
- `cd web && bun run i18n:sync`

项目测试脚本使用 Vitest，必须运行 `bun run test`；不要用 `bun test` 代替项目脚本。

## Docs

- `task docs:check`
- `task ai:check`
- `task docs:new-adr -- title=决策标题`

文档收敛或归档前必须同时执行 `task docs:check` 与 `task ai:check`。归档只允许新增目标不存在的
历史文件；执行前后用 `git status --short -- docs/99-archive` 确认没有任何既有归档文件被修改、删除
或重命名。
