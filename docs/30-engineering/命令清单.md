# 命令清单

## Backend
- `go test ./...`
- `go run main.go`

## Frontend
- `cd web/default && bun install`
- `cd web/default && bun run dev`
- `cd web/default && bun run build`
- `cd web/default && bun run i18n:sync`

## Docs
- `task docs:check`
- `task ai:check`
- `task docs:new-adr -- title=决策标题`
