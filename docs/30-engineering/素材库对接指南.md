# 无状态素材代理对接指南

## 1. 调用方职责

调用方自行维护应用内最终用户权限，并持久化素材返回的 `model + id + reference`。中转站不提供素材或
素材组列表。普通代理模式不保存素材映射；本站托管图片是已登记例外，会持久化素材组、素材与对象位置。
所有后续单项操作必须携带客户模型名，通常使用创建时的模型；跨模型使用前先比较复用域，不能从模型名
推断素材兼容性。

调用前查询 `GET /v1/models/{customer_model}` 的 `api.assets`：

- `supported=false`：不要调用素材接口；调用会返回 `unsupported_asset_operation`；
- `management_mode`：`caller_managed_stateless` 为普通代理，`platform_hosted` 为本站托管图片；
- `operations[].supported`：逐项确认 create/get/update/delete/group 操作；
- `media[].asset_group_requirement`：确认素材组必填、可选或不支持；
- `creation.source`：确认 URL 有效期、长度、MIME、大小和重定向限制。
- `reuse_scope`：仅两个非空值完全相同时才可尝试跨模型复用；代理模式来自冻结的素材租户边界，
  托管模式使用固定托管复用域，不按上游凭据轮换。不同或缺失时不得复用。

部署方可以把相同 `reuse_scope` 的客户模型命名为相同业务后缀，但客户端不能用后缀替代 scope 比较。
scope 相同不是 Provider 真实租户的独立证明，也不保证素材所有权、ready 状态或生成成功。托管引用
须通过本站账号与资源校验，Provider 仍对实际生成结果作最终裁决。

## 2. 创建和保存素材

```json
{
  "name": "产品正面图",
  "asset_kind": "general",
  "media_type": "image",
  "model": "customer-seedance-model",
  "source": {
    "type": "url",
    "url": "https://cdn.example.com/product.png?signature=...",
    "expires_at": 1786300000
  }
}
```

普通 AIGC 素材推荐直接创建，不必先建组。`asset_group_id` 是合法可选字段：代理模式按模型策略使用
默认组或不发送组字段；托管模式未填时创建无组素材，提供时校验当前账号组归属。需要自定义分组时，
先创建普通组，再填写响应的 `id`。真人素材仍须使用认证完成后的专用组。

源只接受符合模型元数据限制的公网 HTTPS URL。普通代理只在当次 Provider 调用中使用源 URL；托管
模式在创建调用内复制源图到本站私有对象存储。两种模式都不持久化、记录或返回源 URL。
普通代理成功响应示例：

```json
{
  "object": "asset",
  "id": "provider-resource-id",
  "model": "customer-seedance-model",
  "reference": "asset://provider-reference-id",
  "status": "ready"
}
```

`id` 和 `reference` 可能不同。创建时状态为 `processing` 且没有 `reference` 时，按 `model + id` 调用
单项查询，直到 ready/failed。POST 不支持幂等键；客户端超时后不得自动换模型或渠道重试。

## 3. 单项操作

```text
GET    /v1/assets/{asset_id}?model={customer_model}
PATCH  /v1/assets/{asset_id}        body: {"model":"...","name":"..."}
DELETE /v1/assets/{asset_id}?model={customer_model}

GET    /v1/asset-groups/{group_id}?model={customer_model}
```

普通代理只把 ID 发送到该客户模型的唯一 Channel，不识别 ID 属于哪个 Provider。另一个 Provider 的 ID、
过期 ID 或错误 ID 由当前上游拒绝；不得依赖错误文本推断 Provider，也不要自动 fallback。
托管模式的单项操作读取本站持久化资源并按账号隔离；同账号 Key 共享素材，跨账号操作失败。
平台不注册素材组删除路由，不主动删除 Provider 素材组；确需清理时由 Provider 管理员在确认影响范围后
执行。

## 4. 素材组和真人认证

普通组：

```json
{"name":"产品素材","group_kind":"general","model":"customer-seedance-model"}
```

真人认证：

```json
{
  "name": "演员认证",
  "group_kind": "real_person",
  "model": "customer-seedance-model",
  "redirect_url": "https://client.example.com/verified"
}
```

真人认证响应的 `id` 是 Provider 会话 ID，`verification_url` 直接交给本人打开。查询状态使用：

```text
GET /v1/asset-groups/{session_id}?model={customer_model}&verification_session=true
```

完成后响应的 `group_id` 才是创建真人素材需要的 Provider 素材组 ID。平台不保存人脸、证件、活体或
授权表单，也不提供认证会话撤回。

## 5. 在视频中引用

```json
{"type":"image_url","image_url":{"url":"asset://provider-reference-id"},"role":"reference_image"}
```

普通代理引用不在生成前查询或验证，由当前 Provider 对存在性、账号权限、ready 状态、模型兼容性和
审核作最终裁决。本站托管图片遵守以下例外；单项查询成功也不保证随后生成成功。

### 本站托管图片例外

以模型公开的 `management_mode=platform_hosted` 识别托管模式，不解析素材 ID 前缀选择流程。

- 托管素材与素材组按 `user_id` 隔离，同账号 API Key 共享；视频任务仍按 `user_id + app_id` 隔离。
- 创建调用内复制并验证图片后返回 ready；源 URL 后续失效不影响复制件。支持的格式、编码大小和
  像素上限读取 `creation.source`，不能套用普通代理的 URL 有效期策略。
- 每次创建生成独立素材与对象，不去重、不提供幂等键。平台不返回内部签名 URL。
- 图片 reference 只放入视频请求的 `image_url.url`。预扣前校验账号归属、删除状态、存储位置与
  对象可访问性，接受后冻结对象事实；发送时签发内部临时 URL，不把该地址作为客户资源。
- 删除只阻止新引用，已受理任务继续使用冻结事实；不删除对象、不做自动清理或迁移。
- 部分模型不支持普通代理 opaque 引用，只能使用媒体 URL 或本站托管图片；无法履约时预扣前
  拒绝，不 fallback，也不从其它模型探测素材。

托管路径须完成真实 Provider、对象存储与账单验收后才能作为生产能力启用。

## 6. adapter 接入要求

新协议必须实现代码 adapter，并以真实文档或测试确认每个公开操作。模型元数据不得因为模型名相似、
同供应商或共享账号而推断支持。没有证据的操作保持 `supported=false`，运行时返回
`unsupported_asset_operation`，不得静默降级。

统一北向协议是 adapter 接入的第一优先级。adapter 必须把同一北向请求转换为 Provider 所需字段、路径
和必填组合，不能把 Provider 是否存在同名字段变成客户请求条件。已发布的条件生效字段在南向不使用时
可以按合同忽略；合同外 Provider 私有参数仍必须拒绝，不得借统一之名透传或改义。

`asset_group_id` 在北向是合法可选字段：使用默认组的 adapter 接收
Service 解析后的调用方 ID 或 Channel 默认 ID；不使用组的 adapter 必须保证南向请求不携带组字段。
真人素材仍使用认证产生的专用组，不得落入普通默认组。

普通素材组行为只能登记在唯一 `GeneralAssetGroupPolicy` 中：当前能创建普通素材组的普通代理协议使用
`default_fallback`，不使用普通组的协议使用 `none`，本站托管图片使用 `hosted`，按账号解析可选组。
其中代理协议能创建普通组不表示调用方必须先建组。运行时解析和公开元数据必须读取同一注册；不得用
`GroupAdapter`、`AssetGroupRequirementAdapter`、模型名或另一份 catalog switch 重复表达。`default_fallback`
只用调用方组 ID 的裁剪结果判断是否为空：非空原值交 Provider，空值使用默认组；任何北向结构错误都返回
`invalid_request`，不得静默回退。

`GroupAdapter` 只作为管理端创建能力门槛。可选查询能力必须返回组名并能证明完整分页已经耗尽；名称缺失、
查询失败或分页不完整时不得推断“不存在”并创建。Channel 默认组清理必须接入统一 Channel 删除链；上游
合并新增删除入口时同步检查该接线。

adapter 返回的 `ResourceID` 用于 CRUD，`ReferenceValue` 用于视频 `asset://`。Provider 错误必须脱敏，
不得返回上游原始模型名、Provider 名称、ChannelID、账号、凭据或原始响应。
