## 验收路径

1. 根目录运行 `go test ./...` 和路由、计费、任务、授权专项回归。
2. `relaykit/` 关闭 workspace 后运行 `GOWORK=off go test ./...` 和 `GOWORK=off go build ./...`。
3. 三库验证空库初始化及现有版本升级，涵盖上游令牌字段、SystemTask 索引、敏感词迁移和本地账务数据。
4. `web/` 使用 Bun 执行类型检查、Lint、测试、构建和公开文档校验。浏览器检查所有可访问页面及主要交互。
5. 根目录用 `./start.sh` 启动本地验收环境，使用隔离数据与本地渠道。文本、单张图片、Seedance Mini 4 秒
   视频的实际调用总预算为 100 美元。正确性失败用非上游测试或在参数校验前拒绝的请求复验。
6. 对照每笔请求、返回、扣费、余额、任务、账单、用量、普通日志和错误日志。只记脱敏证据、额度和结果。
7. 根目录运行 `task docs:check` 与 `task ai:check`。
