# Seedance 国内火山与海外 BytePlus 官方价格基准

## 1. 范围与权威口径

本文集中记录 Seedance 国内火山方舟与海外 BytePlus ModelArk 的官方按量价格，供客户模型定价、
Provider 成本对账和价格审批使用。表内只使用官方无折扣在线推理刊例价，不包含免费额度、资源包、
节省计划、商务折扣、限时活动价或第三方 Provider 报价。

- 国内火山方舟以人民币元/百万 Tokens 计价；
- 海外 BytePlus 以美元/百万 Tokens 计价；
- 国内 `doubao-*` 与海外 `dreamina-*` 是不同地域的模型身份，不得只按模型家族名互换；
- 官方价格的权威单位是每百万 Tokens。下文每秒金额只是按官方 Token 公式计算的固定规格投影，
  不能替代 Provider 终态实际用量。

官方来源：

- [火山方舟模型价格](https://www.volcengine.com/docs/82379/1544106?lang=zh)
- [BytePlus ModelArk Pricing](https://docs.byteplus.com/en/docs/ModelArk/1544106?redirect=1)

价格核对日期：2026-08-13。

## 5. 系统定价不变量

1. 官方 Token 单价、客户零售价、Provider 实际成本和渠道折扣是四类不同事实，不得互相覆盖。
2. 客户模型价格必须按地域、Provider 模型、分辨率和是否含视频输入选择；不得把国内价格套到海外
   模型，也不得把无视频输入固定秒价用于含视频输入的动态任务。
3. 按秒或按次价格只能作为已审批客户合同；它不把 Provider 官方 Token 计费改写为固定成本。
4. 新价格只影响之后创建的 Task。历史 Task 始终使用创建时冻结的价格、表达式、汇率投影和计费探针。
5. 价格变更前必须重新核对官方页面、目标账号控制台和真实 Provider 账单；文档中的核对日期不是
   永久有效证明。
