# Seedance 国内火山与海外 BytePlus 官方价格基准

## 1. 范围与权威口径

本文只记录火山方舟与 BytePlus ModelArk 的官方在线推理 Pay-as-you-go 无折扣刊例价，以及由官方
Token 公式推导的固定规格每计费视频秒价格。表内不记录第三方 Provider 报价、客户零售价、渠道折扣、
资源包、节省计划、免费额度、限时活动价或实证账单。

- 火山方舟官方价格以 `RMB / 1M tokens` 发布；海外 BytePlus 官方价格以 `USD / 1M tokens` 发布。
- 国内 `doubao-*` 与海外 `dreamina-*` / `seedance-*` 是不同地域的 Provider 模型身份，不得只按模型
  家族名互换。
- “每计费视频秒”是按官方 Token 公式和固定分辨率、16:9、24fps 推导的参考值，不是 Provider 另行发布
  的固定单价。输入包含视频时，它也包含输入视频时长，不能直接当作每输出秒价格。
- 表中跨币种金额均按项目对账固定汇率 `1 USD = 6.82 RMB` 换算，仅作参考，不代表对应 Provider 的
  官方报价。官方价格以 Provider 原币种列为准。

官方来源：

- [火山方舟模型价格](https://www.volcengine.com/docs/82379/1544106?lang=zh)
- [BytePlus ModelArk Pricing](https://docs.byteplus.com/en/docs/ModelArk/1544106?redirect=1)

价格核对日期：2026-08-13。火山页面中的 Seedance 2.0 Mini `4 折`和 Seedance 2.0 Fast `7.5 折`属于
2026-08-07 14:00 至 2026-09-07 14:00（UTC+8）的限时价，本文只保留页面明示的原价。

## 4. 每计费视频秒的计算口径

官方视频 Token 估算公式为：

`Token 用量 = (输入视频时长 + 输出视频时长) × 输出宽 × 输出高 × 帧率 ÷ 1024`

表中每计费视频秒为 `官方 Token 单价 × 单秒 Token 用量`，金额保留 6 位小数。固定规格采用以下
官方示例参数：

- Seedance 2.5：480p 使用 `9,607.5` Token/秒，720p 使用 `21,600` Token/秒；
- Seedance 2.0、Fast、Mini：480p 使用 `864×496`，720p 使用 `1280×720`，1080p 使用 `1920×1080`，
  4K 使用 `3840×2160`；
- Seedance 1.5 Pro：480p 使用 `864×480`，720p 使用 `1280×720`，1080p 使用 `1920×1080`；
- Seedance 1.0 Pro / Fast：480p 使用 `864×480`，720p 使用 `1248×704`，1080p 使用 `1920×1088`；
- 上述规格均按 16:9、24fps 计算。

使用和解释规则：

1. 输入不含视频时，一个计费视频秒等于一个输出视频秒，表内每秒值可作为该固定规格的输出秒参考价。
2. 输入包含视频时，一个计费视频秒等于一个输入视频秒加一个输出视频秒；单个输出秒的实际摊销价还要
   乘以 `(输入视频时长 + 输出视频时长) ÷ 输出视频时长`，并可能受官方最低 Token 用量限制。
3. Seedance 2.x 的官方计费以成功生成的视频为对象；正式结算优先使用 Provider 成功终态返回的可信
   `usage.completion_tokens`，不能用表内估算值替代实际用量。
4. Fast 和 Mini 当前官方价格表只列 480p、720p；不能据此推断其支持 1080p 或 4K。
