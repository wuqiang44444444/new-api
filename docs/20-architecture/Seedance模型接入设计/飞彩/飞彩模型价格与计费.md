# 飞彩模型价格与计费

## 1. Provider 报价与官方对比

飞彩原始资料按人民币/秒报价；对照火山国内官方无输入视频的参考每秒价，当前实测比例如下。官网每秒值是 Token 公式推导的参考，不是飞彩结算输入。

| 飞彩档位 | 飞彩 ¥/s | 火山对应官方参考 ¥/s | 飞彩/官方 |
| --- | ---: | ---: | ---: |
| VIP 720p | 0.6643 | 0.9936 | 66.9% |
| VIP 1080p | 1.56585 | 2.4786 | 63.2% |
| VIP 4K | 3.796 | 5.0544 | 75.1% |
| VIP Fast 720p | 0.6424 | 0.7992 | 80.4% |
| VIP Mini 720p | 0.44968 | 0.4968 | 90.5% |
| 933 720p / SD2 / Pro PI | 0.5621 | 0.9936 | 56.6% |
| 933 1080p | 1.32495 | 2.4786 | 53.5% |
| 933 4K | 3.212 | 5.0544 | 63.5% |

对比仅说明供应商报价相对官方参考的数量级，不证明飞彩在所有输入类型、失败任务或账期上都按该价结算。

## 2. 平台客户计费

十个客户模型均按秒计费，价格表达式读取创建时冻结的 `duration_seconds`；比例不参与价格，`size_multiplier` 仅为历史 probe 兼容且必须恒为 1。表达式使用审批后的客户价格，不读取当前 Provider 报价：

```text
v1:tier("base", param("_task.duration_seconds") * <USD/秒 × 1,000,000>)
```

预扣和结算使用同一冻结表达式、模型、分辨率和分组倍率；quota 转换必须经过统一 checked 饱和函数。Pro PI 虽固定 15 秒，仍按冻结秒数计算，不另建按次账本。

## 3. 账单证据与状态

飞彩 `/v1/tasks` 在目标地址 404，subscription/usage 只能用于账户趋势。Provider 成本未知时保持未知，不以客户 quota 冒充；失败明确时按共享退款，创建 unknown 保留 hold 和 exposure。价格更新只影响新 Task，历史 Task 按创建时快照结算。

## 4. 与官方口径的差异

- 火山/BytePlus 官方按 Token，飞彩按输出秒；不能把官方每百万 Token 价直接写入飞彩表达式。
- 官方价格按是否含视频输入分档，飞彩当前模型合同只有按秒档位，不能自行引入视频输入折扣。
- 供应商人民币报价与官方人民币 Token 价不可用汇率直接互换；对账需同时保留币种、单位、模型和快照。
