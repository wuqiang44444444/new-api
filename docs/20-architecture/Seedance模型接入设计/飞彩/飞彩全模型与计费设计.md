## 4. 客户计费

每个客户模型使用自己审批的 NEWAPI 价格和表达式：

- 九个按秒模型：冻结 duration、分辨率/size class、输入类型和分组倍率；
- Pro PI：冻结每次请求价格和已批准倍率，固定 15 秒只用于请求合同；
- Provider 预期成本和实际账单只供管理员对账，不覆盖客户结算；
- 预扣与终态使用同一冻结 probe；
- 所有乘数先校验上界，quota 使用 checked 饱和函数；
- 失败、退款和视频 unknown 按共享异步事实处理。

飞彩 `/v1/tasks` 在目标生产 HTTPS Base URL 实测 404，不能作为任务级对账源。subscription/usage 只
能作为账户趋势，不能按相近时间或模型猜测单任务成本。历史账户 usage 增量与研究报价存在不一致，
因此生产价格必须单独审批。

## 5. 不变量

1. 十个 Provider 模型分别配置客户模型、价格和证据，不合并档位。
2. v2/v3 的客户模型和证据完全分离。
3. 固定分辨率不能在请求期切到另一价格档。
4. 未验证 size、默认值、媒体或账单不由相邻模型推导。
5. 客户账单读取冻结 NEWAPI 计费和结算日志，不按当前 Provider 报价回算。
