# 飞彩模型与素材能力元数据

本文是公开目录投影的输入记录，不是第二套运行时 capability 注册表。客户模型名可自定义，Provider 身份不公开。

## 1. 公开模型元数据

| 字段 | 当前值 |
| --- | --- |
| video.protocol | `modelark_v3` |
| video.create | `POST /api/v3/contents/generations/tasks` |
| video.query/list/delete | ModelArk V3 对应任务接口；删除能力按 adapter 诚实返回 |
| assets.supported | `false` |
| assets.management_mode | `caller_managed_stateless` |
| assets.requires_model | `true` |
| assets.reference_format | `asset://{opaque_upstream_asset_id}` |
| assets.reuse_scope | 空字符串 |
| assets.media | 空；不发布素材创建能力 |

## 2. 逐模型记录

| Provider 模型 | 分辨率 | 时长 | 图片 | 音频 | 视频 | 比例 |

## 3. 能力生成规则

元数据来自 `feicai_videos_v1 + model_mapping` 的精确模型表；不根据客户模型后缀、价格或素材 URL 推断。任何未登记模型或字段均应显示为不支持并在请求前拒绝。`asset://` 只代表调用方保存的 opaque 引用，平台不宣称存在性、所有权、审核或跨模型兼容。

## 4. 对外隐藏字段

不返回 Provider 模型名、Channel ID、Base URL、账号、Region/Project、原始 task ID、凭据或 Provider 原始响应。实现依据：`model/channel_seedance_public_catalog.go`、`relaykit/dto/public_model_api.go` 和飞彩 model spec。
