# 飞彩供应商原始技术文档整理

本文把飞彩公开接口资料、账户查询实测和代码已验证约束收敛为一份可检索的供应商原始资料摘要。它是证据整理，不把飞彩资料直接当作平台公开合同；平台只发布下一份“模型与素材库对接设计”中明确列出的能力。

- 余额、用量和任务查询：`docs/70-research/飞彩/飞彩-账单与查询.md`。
- 当前实现合同：`relay/channel/task/seedance/thirdparty/feicai/`。

## Provider 接口摘要

| 项目 | 原始资料事实 |
| --- | --- |
| 鉴权 | `Authorization: Bearer <API Key>` |
| 创建 | `POST /v1/videos`，异步返回 `task_id` |
| 查询 | `GET /v1/videos/{task_id}`；资料还列出 `/v1/tasks` 列表 |
| 结果 | 成功状态返回 `video_url`，下载需要携带鉴权 |
| 输入 | `prompt`、`seconds`/`duration`、`size`、`images[]`、`audios[]`、`videos[]` |
| URL | 图片可 HTTP/HTTPS 或图片 Data URL；音频、视频要求 HTTPS URL |
| 典型状态 | `queued` → `processing` → `completed` / `failed` |

Provider 文档中的 `seconds` 字符串、兼容字段 `image`/`input_reference`、本地路径错误和内网 URL 错误均属于飞彩原始接口行为；平台统一北向不透传这些兼容字段。

## 原始账单资料的限制

飞彩资料同时出现人民币、积分、quota 和账户 usage 四种口径：历史查询文档给出 `¥1 = 500,000 quota`，账户 usage 接口又以“分”返回。`/v1/tasks` 在目标生产地址曾返回 404，因此不能用账户总量增量反推出单任务成本。正式客户计费以平台冻结的表达式和结算日志为准，Provider 账单只作为管理员对账证据。

## 证据等级

- 已有代码合同：异步创建/查询、十个精确模型、固定分辨率、比例集合、URL/Data URL 校验。
- 供应商资料：模型价格、状态字段、下载方式和任务查询字段。
- 待补证据：真实凭据下逐模型终态、失败扣费、4K/Pro PI 内容兼容性及生产灰度。

## 原始资料的安全处理

本摘要不复制 API Key、真实地址中的签名参数、完整视频 URL 或 Provider 原始响应；示例中的凭据和资源地址均视为脱敏占位。
