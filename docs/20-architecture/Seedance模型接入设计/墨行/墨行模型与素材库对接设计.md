# 墨行模型与素材库对接设计

## 1. 三条视频协议

| 线路 | 协议 | Provider 模型范围 | 公开状态 |
| --- | --- | --- | --- |
| TokenSave 海外 2.0 | `tokensave_media_task_v1` | `doubao-seedance-2-0-260128` | 可配置，待完整账单验收 |
| 墨行国内 2.0 | `moxing_media_task_v1` | `doubao-seedance-2-0-260128` | 可配置，按秒 |
| 墨行国内 Fast/Mini/2.5 | `moxing_modelark_media_v1` | `doubao-seedance-2-0-fast-260128`、`...mini...`、`...2-5...` | Fast 有实证；Mini/2.5 未发布 |

客户模型名、Channel、Provider 模型和协议分离；`model_mapping` 是唯一模型转换。一个 Channel 可以包含
多个管理员命名的客户模型，保存时逐项解析到所选协议登记的最终 Provider 模型；映射链、额外管理员条目
和客户名称不决定协议资格。显式提供未支持字段（例如 Fast/Mini 的 `seed`、任一模型的
`camera_fixed`）必须在预扣、hold 和 Provider POST 前返回 `invalid_video_parameter`。

## 2. 视频参数合同

共同北向为 ModelArk V3 `content`。2.0 当前开放 4–15 秒、480p/720p；Fast/Mini 同时接受图/视频/音频参考但不接受 `seed`；2.5 开放 4–30 秒或 `-1`、480p/720p、图片≤30/视频≤10/音频≤10，接受 `seed`。图片或音频输入不等同“含视频输入”。

## 3. 素材协议

| 代码协议 | 关键操作 | 平台边界 |
| --- | --- | --- |
| `tokensave_assets_v1` | `/v1/asset` 组创建/查询、素材创建/查询/更新/删除 | 创建素材必须使用组创建返回的资源 `id`；不再调用 `/assets` 默认组代理 |
| `moxing_joycreator_assets_v1` | 组创建/查询、素材创建/查询/更新/删除 | 创建素材必须使用组创建返回的资源 `id`；组删除明确不支持 |
| `moxing_volc_assets_v1` | 组创建/查询、素材 CRUD、真人认证会话/结果 | 创建素材组不传 `ProjectName`；创建素材必须携带 `GroupId`；其它已登记操作沿用各自 Provider 合同 |

平台统一要求每次操作携带客户模型；不提供列表；Provider opaque ID 由调用方保存。JoyCreator 与 Moxing
Volc 的公开元数据均把普通素材的素材组标记为 `required`，运行时在发起 Provider 请求前执行同一校验；
TokenSave 同样标记为 `required`。视频中的 `asset://<opaque-id>` 不查询本地、不验证所有权或模型，原样进入当前视频 adapter。source URL 不持久化，失败不跨协议 fallback。

JoyCreator 与 TokenSave `/v1/asset` 的真实创建响应将 `id`、`groupId` 或 `assetId` 直接放在 `result` 下，详情响应则放在
`result.group` 或 `result.asset` 下。adapter 按操作支持这两种已验证形状，创建成功不得因套用详情响应
结构而误判为上游失败。

使用相同 Moxing ModelArk 视频协议、Volc 素材协议和连接配置的 Fast/Mini/2.5 可以位于同一多模型
Channel。TokenSave、Moxing Media Task 和 CMCC 即使当前只登记一个 Provider 模型，也不限制管理员只能
配置一个客户模型；每个 Channel Model 的最终映射目标仍必须属于对应协议登记表。

## 4. 异步与状态

创建只发送一次 Provider POST，TaskCreateAttempt、hold、sending 和可信 task ID 原子提交。查询无效、ID 不匹配或状态未知时只能标记不可采信，不得直接退款。Task 冻结协议、Provider 模型、连接和计费事实，后续配置变化不重新选渠。

## 5. 代码事实

协议注册在 `relaykit/dto/upstream_protocol.go`；模型校验在 `relay/channel/task/seedance/provider_model_specs.go`；素材 adapter 在 `relay/channel/task/seedance/assets/moxing_*.go` 与 TokenSave adapter 中。共同素材公开矩阵见上位文档。
