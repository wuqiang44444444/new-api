# 墨行 Seedance 模型线路与合同边界

## 1. 确定性线路

```text
customer_model_oversea -> Channel A -> seedance-2-0-oversea -> /v1/media/*
customer_model_doubao  -> Channel B -> doubao-seedance-2-0-260128 -> /v1/media/*
```

两个 Provider 模型同属 Moxing 的 TokenSave 模型体系并共享协议形状，但客户模型、Channel、Key、
Base URL、价格、素材账号和历史 Task 必须隔离。相同协议不表示可互相重试或 fallback。

| 线路 | 视频协议 | 素材协议 | 结论 |
| --- | --- | --- | --- |
| oversea | `media_task_v1` | `relay_assets_v1`（待重新验收） | 当前模型，按量计费 |
| doubao | `media_task_v1` | `relay_assets_v1`（待重新验收） | 当前模型，按秒计费 |
| 历史 Ark | 历史 `/v1/ark/*` | 未重新取证 | 只解释存量 Task，不新建 |
| JoyCreator | 无视频协议 | management-only | 不参与视频或素材 Resolver |

## 2. 路由

两条线路分别使用独立客户模型和 `ChannelTypeSeedanceLink`。Group 只控制访问，客户模型直接定位唯一
Seedance Channel；Priority、Weight、Affinity、随机分发、跨线路重试均无效，也不写入原生 Ability。

管理员分别配置 Base URL、模型 Key、`model_mapping`、视频协议、素材协议和价格。技术人员确认协议
兼容；不再维护 publication、SKU、implementation 或 execution binding。

## 3. 历史隔离

`dreamina-seedance-2-0-260128` 与旧 Ark 素材/H5 资料已失去完整证据。迁移期可按旧 Task 冻结快照
查询历史任务，但不能用于新 Channel、新 Asset 或新视频创建。JoyCreator 的 group/asset/vendor URL
也不能拼接成当前 relay asset。

## 4. 不变量

1. 两个当前 Provider 模型使用不同客户模型和不同 Channel。
2. 相同 `/v1/media/*` 协议不产生渠道等价性。
3. 历史 Ark 与 JoyCreator 不参与当前请求路由或素材解析。
4. 代码存在不等于生产开放；各线路按自己的真实证据启用。
5. NEWAPI 原生视频入口不受本设计影响。
