# 墨行模型与素材能力元数据

## 1. 公开投影

| 素材协议 | `assets.supported` | 组 | 真人 | `reuse_scope` |
| --- | --- | --- | --- | --- |
| `tokensave_assets_v1` | true | optional（Channel 默认组回退） | false | 按 Channel 素材租户身份派生 |
| `moxing_volc_assets_v1` | true | optional（Channel 默认组回退） | image | 按 Channel 素材租户身份派生 |
| `none` | false | unsupported | false | 空 |

共同字段：`management_mode=caller_managed_stateless`、`requires_model=true`、`reference_format=asset://{opaque_upstream_asset_id}`；列表操作 `supported=false`。普通素材组策略由 `GeneralAssetGroupPolicy` 统一发布；真人认证仅返回 Provider 会话/链接，不建立平台授权域。

## 2. 视频模型元数据

四个精确 Provider 模型由 `plugins/seedance-link/plugin.js` 的 `MOXING_MODEL_METADATA` 登记。
运行时使用请求冻结的插件版本校验，公开目录由已激活插件配置经
`pkg/publicmodel/seedance_plugin.go` 投影；`relaykit/dto/moxing_video_models.go` 是迁移回归测试的
Go 参考定义，不是当前运行时事实源。

| Provider 模型 | 分辨率元数据 | 时长（本站合同） | `output_format` |
| --- | --- | --- | --- |
| `doubao-seedance-2-0-260128-0818` | `enum=[480p,720p,1080p,4k]` | 4–15 或 -1（预算 15 秒） | 不发布，显式传入拒绝 |
| `doubao-seedance-2-0-fast-260128` | `suggested_values=[480p,720p]`，无 enum | 4–15 或 -1（预算 15 秒） | 未取得该字段支持证据，不发布，显式传入拒绝 |
| `doubao-seedance-2-0-mini-260615` | 同 Fast | 同 Fast | 同 Fast |
| `doubao-seedance-2-5-260628` | `enum=[480p,720p]` | 4–30 或 -1（预算 30 秒） | `enum=[mp4,mov]` |

四模型的 `resolution` 缺省值均为 `720p`。0818 与 2.5 的穷举范围由同一插件元数据同时驱动
公开投影、映射后请求校验与预扣前计费探针；2.5 的 1080p/4k 和 0818 的 8k 不会进入 Provider POST。
Fast/Mini 页面仅给常用推荐值，`suggested_values` 不是白名单，也不是其它值已获支持的证明；
运行时不依据推荐列表拒绝其它非空值，由 Provider 判定。

`omitOutputFormat` 阻止通用 `fullModelArk` 参数集再次发布或接受无依据的格式参数。
2.5 的 `output_format` 仅发布一次；0818 不再将上游明确不支持的字段原样发送。

2.5 的图片≤30、视频≤10、音频≤10、总数≤50 在本地校验；纯音频参考有文档支持。
Fast/Mini 文档要求音频配合图片或视频，并注明不建议仅传音频；本地继续接受原有音频传输形状，
不能把这一接受行为宣称为纯音频生成已经验证。0818 页面未禁止纯音频，也不代表已验证。

2.5 的首帧/首尾帧/延长仅可使用 `ratio=adaptive`，首帧/首尾帧与多模态参考互斥；
参考视频、参考音频各自总时长≤30 秒。当前平面枚举与逐类型数量不能表达这些完整条件，
调用方还必须遵守 API 文档的场景说明，Provider 判断实际媒体与任务意图；网关不按提示词猜任务类型。

本站缺省时长保持 5 秒；这与 2.5 上游缺省 -1 不同，adapter 显式发送本站默认值。
0818 页面仅明确 4–15 秒，Fast/Mini 仅示例 5 秒；本站既有 -1 与 Fast/Mini 时长范围不是由这三页
新近证实的供应商能力。其真实履约仍需验证，不能写成生产已发布。

## 3. 元数据生成与隐藏

能力由 `video_upstream_protocol + Provider 模型` 的代码表生成，不由客户模型后缀或价格推断。公开响应不返回 Provider 名称、模型 ID、Channel、账号、Region/Project、Task 私有 ID 或原始 URL；`reuse_scope` 只表示同一非空作用域可尝试复用，不是存在性或权限证明。
