# 墨行模型价格与计费

## 1. 客户计价矩阵

人民币资料按固定汇率 `1 USD = 6.82 CNY` 换算；价格表达式保存美元系数，历史 Task 不随汇率变化。

| 线路/模型 | 无视频输入 | 含视频输入 | 单位 | 官方对照 |
| --- | ---: | ---: | --- | --- |
| TokenSave 海外 2.0，480p/720p/1080p | 0.0679 / 0.1462 / 0.3647 | 0.1653 / 0.3559 / 0.3647 | USD/输出秒 | BytePlus 2.0 官方按 Token，不能直接等价 |
| 墨行国内 2.0，480p/720p | 0.067741935484 / 0.145747800587 | 0.164809384164 / 0.354838709677 | USD/输出秒 | 火山官方推导约 0.067745 / 0.145689、含视频约 0.041236 / 0.088680；单位不同，仅作量级对比 |

“含视频”只在请求存在视频输入时命中；图像/音频不切换到该档。TokenSave 海外和墨行国内同名模型必须分别保存价格。

## 2. 结算规则

- 2.0 两条线路按冻结 `duration_seconds × USD/秒` 结算，终态 usage 只作为 Provider 证据。
- Fast/Mini/2.5 按成功终态合法 `completion_tokens` 结算；缺失合法用量时保留预扣估算。
- Fast 已核验 `40,594` completion tokens 与 Provider 账单一致；不把该证据外推为 Mini/2.5 已生产。
- 使用 billingexpr 的 tiered expression；quota 通过 checked 饱和转换，预扣、差额、退款幂等。

## 3. 与官方的差异与解释

国内官方按 Token；TokenSave/墨行 2.0 按秒是第三方商务计价，不可把官方每百万 Token 价直接替换。Fast/Mini/2.5 的第三方价格恰好与火山国内无折扣官方换算值一致，但 Provider、凭据、失败收费和资源包仍不同，不能合并渠道。

## 4. 资金与异常

价格只影响新 Task；Task 按创建时冻结客户模型、协议、价格和预扣。明确失败按共享退款；unknown 保留 hold 与 Provider exposure，不自动重发、换渠或退款。Provider 金额未知保持未知，不能用客户 quota 代替。
