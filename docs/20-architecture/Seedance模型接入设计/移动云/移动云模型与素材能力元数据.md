# 移动云模型与素材能力元数据

## 1. 状态与身份

本文件定义移动云 Seedance 客户模型的统一目录投影。已配置但停用的 Standard 可以返回目标元数据，
并以 `availability=disabled` 明确表示不可调用；这不表示生产渠道、真实素材链路或账单已经验收。
能力只能由 `modelark_v3_cmcc + cmcc_aicc_assets_v2` 的代码注册与 Channel 明确配置产生，不得从模型
名称、价格、域名或凭据形状推断。

| 客户模型 | Provider mapping | 当前状态 | 可否进入公开目录 |
| --- | --- | --- | --- |
| `seedance-2.0-cmcc` | `doubao-seedance-2.0` | Standard 代码已实现，生产素材与账单未验收 | 可以，但验收前必须为 disabled |
| `seedance-2.0-fast-cmcc` | 未确认 | Fast 候选 | 不可以 |
| `seedance-2.0-mini-cmcc` | 未确认 | Mini 候选 | 不可以 |
| `seedance-2.5-cmcc` | 未确认 | 条件候选；当前无移动云公开存在证据 | 不可以 |

“候选”只保留客户命名和未来验收位置，不产生模型发现、计费、路由或素材资格。火山/BytePlus 的同名
模型 ID 不能填入移动云 mapping。

| 字段 | 目标值 |
| --- | --- |
| 客户模型 | 当前可继续实现的目标为 `seedance-2.0-cmcc` |
| Provider 模型映射 | Standard 内部为 `doubao-seedance-2.0`，公开响应不返回 |
| `video.protocol` | `modelark_v3` |
| `assets.supported` | `true`（表示已配置代码注册的素材协议；是否可调用另看 `availability`） |
| `assets.management_mode` | `caller_managed_stateless` |
| `assets.requires_model` | `true` |
| `assets.reference_format` | `asset://{opaque_upstream_asset_id}` |
| `assets.reuse_scope` | 由 Channel 随机稳定 identity 与统一格式版本生成；与其它素材协议使用同一公式 |

## 2. 视频能力

| 操作 | 目标支持 | 说明 |
| --- | --- | --- |
| 创建 Task | 是 | `POST /api/v3/contents/generations/tasks` |
| 查询单项 | 是 | 使用平台 Task ID 和冻结移动云连接 |
| 查询列表 | 是 | 只列平台内 `user_id + app_id` Task，不透传上游列表 |
| 删除/取消 | 是 | 按移动云真实语义映射，不伪造删除成功 |
| 内容下载 | 是 | 短期回源，不承诺 Provider 长期保存 |

首版南向使用非加密 REST。Standard 当前已经完成 text、参考视频和三档分辨率的目标 API Key 探测；
其余字段只有在移动云文档与目标账号共同验证后才进入公开 creation 元数据：

| 能力 | 当前设计结论 |
| --- | --- |
| text content | 已验证 |
| video content | `video_url/reference_video` 已验证；adapter 必须发送 `Input-Has-Video: true` |
| image/audio content | 移动云非加密 REST 已正式列出；目标账号真实任务仍待生产验收 |
| `generate_audio` | 目标支持 |
| `duration` | 4–15；北向缺省按 5 秒校验和预扣，南向保持字段缺失；Provider 缺省语义待验收 |
| `ratio` | 首先发布已验证的 `16:9`、`9:16`、`1:1` |
| `watermark` | 目标支持 |
| 480p/720p/1080p | raw REST 已验证；未传时实测默认 720p |
| SDK-only 字段 | 不支持；不得因 SDK 存在而自动投影 |
| 加密模式 | 不属于 `modelark_v3_cmcc` |

Fast、Mini、2.5 不能直接继承本表。每个模型必须分别验证 duration、resolution、ratio、多模态输入、
音频、删除、Task 状态和 usage；如果移动云合同与 Standard 不同，由同一个 `modelark_v3_cmcc` adapter
中的精确 Provider model spec 表达，差异过大时再新增代码协议，禁止按模型名猜测。

| 素材更新 | 是 | 修改素材名称 |
| 素材删除 | 是 | 单资源 |
| 素材列表 | 否 | 上游即使提供，平台也不发布 |
| 素材组创建 | 是 | 直接创建仅用于 AIGC 组 |
| 素材组查询 | 是 | 单资源 |
| 素材组更新 | 否 | 当前北向合同未发布该操作 |
| 素材组删除 | 否 | Provider 虽提供，但平台不发布也不主动调用 |
| 素材组列表 | 否 | 上游即使提供，平台也不发布 |
| 真人认证会话 | 是 | 移动云 H5；不接收 `redirect_url` |
| 真人 token 换组 | 是 | `bytedToken` 返回 opaque group ID |

## 4. 媒体与素材组矩阵

首版“全部都做”指移动云官方明确提供的 AIGC 与真人两种组，以及 Image/Video/Audio 三类素材；不扩大
为平台自建真人认证或 Provider 列表同步。

| 素材场景 | Image | Video | Audio | `asset_group_requirement` |
| --- | --- | --- | --- | --- |
| general / AIGC | 支持 | 支持 | 支持 | required |
| real_person | 支持 | 支持 | 支持 | required；group ID 来自真人 H5 流程 |

调用方负责保存 `customer_model + group_id + asset_id/reference`。平台不建立 Asset/AssetGroup 事实，
不校验视频中的 `asset://` 所有权、状态、素材组、模型或租户，最终兼容性由选定移动云租户判定。

Standard 验收通过不自动证明 Fast、Mini 或 2.5 能消费同一 opaque ID。候选模型只有完成同租户素材
创建、引用生成与失败闭合验证后才投影 `assets.supported=true`。多个已验证模型配置在同一个 Channel
时可获得相同 `reuse_scope`；该 scope 仍只表示可尝试复用。

## 5. 创建约束

- source URL 只进入创建请求与当次 Provider 调用，不持久化、不记录、不返回；
- 创建素材必须显式提供 group ID，平台不自动建组；
- AIGC group 使用 `groupType=AIGC`；真人 group 只通过 H5 token 结果取得；
- 素材类型精确映射为 Image、Video、Audio，不接受未登记类型；
- `redirect_url` 对移动云真人会话不支持，非空时明确拒绝；
- Provider 查询返回的短期签名 URL 必须剥离，不进入北向响应、数据库或日志；
- 不支持的操作返回 `422 unsupported_asset_operation`，上游业务失败不能改判为“不支持”。

## 6. `reuse_scope` 不变量

移动云素材 endpoint 是所有租户共享的固定地址，因此不能只使用 endpoint 生成 scope。首版使用代码协议、
规范化 endpoint 与 `stable_channel_identity` 生成匿名值。`stable_channel_identity` 是按 Channel ID
关联、独立受保护持久化且由系统随机生成的 `asset_scope_identity`，不进入 Channel 公共列、settings、
管理 DTO 或素材凭据值；任何可枚举 Channel ID、配置哈希、Channel Key、API Key、AccessKey、SecretKey
都不得参与或替代它。

scope 相同仅表示调用方可尝试复用，不证明素材所有权、READY 状态或视频兼容性。scope 不同则调用方
不得跨模型发送素材引用。不同 Channel 即使属于同一移动云租户也先保持不同 scope，不得以人工判断
绕过；未来只有取得稳定 tenant ID 并明确变更合同时才扩大复用域。

## 7. 代码落地后的权威位置

实现后，精确协议枚举、操作矩阵和公开投影应分别以新增的代码注册文件为权威，并同步更新：

- [Seedance 专用渠道与 Link 架构](../../Seedance专用渠道与Link架构.md) 的协议枚举；
- [Seedance 模型素材库支持矩阵](../../Seedance模型素材库支持矩阵.md) 的已实现能力；
- [公开模型调用与素材能力元数据设计](../公开模型调用与素材能力元数据设计.md) 规定的统一投影。

在真实账号验收完成并启用 Channel 前，目录只能把 Standard 表达为 disabled，不得把目标值当作生产
已发布事实。Fast、Mini、
2.5 还必须先补齐移动云官方存在性、Provider mapping 和价格证据。任何候选模型转为可发布时，必须在
同一变更中同步更新本文件“当前状态”与“可否进入公开目录”两列，以及对应价格、能力矩阵和代码投影；
不得只启用代码而保留过期文档状态。
