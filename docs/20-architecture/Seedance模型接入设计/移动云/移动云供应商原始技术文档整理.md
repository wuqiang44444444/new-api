## 2. 开通资格与调用方式

### 2.1 必须先开通服务

移动云文档当前说明该模型仅支持非免费账号。免费账号即使提交订单也可能开通失败，模型权益不会
生效。有效调用至少需要：

1. 订购 AICC-Doubao-Seedance 2.0 并显示开通成功；
2. 使用移动云 MaaS 公布的服务接入点；当前已验证的 Base URL 为
   `https://zhenze-huhehaote.cmecloud.cn`；
3. 取得 API Key 和所选移动云 Seedance 模型权限；当前公开合同只确认 `doubao-seedance-2.0`。

“服务是否开通”是账号与模型权益；“是否加密调用”是客户端传输方式，二者不是同一开关。没有开通
权益时，加密 SDK 和非加密 REST 都不能使调用获得模型资格。

### 2.2 SDK 是否必需

| 调用方式 | SDK 是否必需 | 凭据/额外材料 | 原始合同 |
| --- | --- | --- | --- |
| REST 非加密调用 | 否 | Bearer API Key | 客户端可直接请求 ModelArk V3 风格 REST API |
| 官方 SDK 非加密调用 | 是，仅因选择 SDK | Bearer API Key | Java/Python/Go SDK 可关闭加密 |
| 官方 SDK 加密调用 | 是 | Bearer API Key、SDK 安全信道；视频解密还依赖 RSA 密钥对 | SDK 负责安全信道协商、请求加密、响应解密及结果视频解密 |

因此“必须使用移动云 SDK”只适用于官方已验证的加密链路。非加密 REST 不需要 SDK。加密模式不是
在普通 REST 请求上增加一个布尔字段即可等价实现；RSA 私钥还关系到历史加密视频能否解密，丢失后
无法恢复。

## 3. 视频 API 原始事实

| 项目 | 官方资料事实 |
| --- | --- |
| Gateway | 当前文档与目标 API Key 实测均为 `https://zhenze-huhehaote.cmecloud.cn`；它是服务接入点/Base URL，不是另一套账号或凭据 |
| 创建路径 | `POST /api/v3/contents/generations/tasks` |
| 鉴权 | `Authorization: Bearer <API Key>` |
| 请求模型 | `doubao-seedance-2.0` |
| 响应模型示例 | `doubao-seedance-2-0-260128` |
| 已在非加密文档列出的输入 | `model`、`content`、`generate_audio`、`ratio`、`duration`、`watermark`；页面于 2026-08-21 再次核对 |
| `content` 类型 | text、image、video、audio |
| 已在非加密文档列出的比例 | `16:9`、`9:16`、`1:1` |
| Task 状态 | queued、running、succeeded、failed、cancelled、expired |
| 成功用量 | `usage.completion_tokens`、`usage.total_tokens` |
| 结果 | `content.video_url` 等 ModelArk V3 风格字段 |
| 任务操作 | 创建、查询单项、查询列表、删除/取消 |

官方 SDK 暴露 `resolution`、`callback_url`、`return_last_frame`、`service_tier`、
`execution_expires_after`、`draft`、`tools`、`priority`、`frames` 和更多比例等字段，但当前非加密 REST
页面没有完整列出这些字段。目标 API Key 已实测确认 raw REST 接受 `resolution=480p/720p/1080p`；其余
SDK 字段仍不能仅凭 SDK 类型推断为 raw REST 已开放。

非加密页面示例同时包含两张参考图片、一个参考视频和一个参考音频，但没有声明 Image/Video/Audio 的
最大数量。实现不得从火山、BytePlus 或其它移动云外渠道复制 `9/3/3` 等数量上限；请求仍受北向结构与
请求体大小约束，Provider 未接受的组合按其脱敏错误失败关闭。

SDK 在含视频输入时会发送 `Input-Has-Video: true`，移动云价格也按“是否含视频输入”分档。目标 API Key
已实测确认 raw REST 可携带该 Header，并成功处理 `video_url/reference_video`。任务 usage 会计入输入视频
Token；¥56/百万 Token 的含视频输入价是否实际落账仍须以移动云账单验证，不能由任务成功单独推断。

### 3.1 目标租户 raw REST 实测事实

2026-08-20 使用目标租户的新 API Key 完成脱敏探测；未保存或记录 API Key、Provider Task ID、签名 URL
和原始响应。已确认：

| 请求 | 终态事实 |
| --- | --- |
| 纯文本、5 秒、未传 `resolution` | succeeded；默认 720p；24fps；`completion_tokens=108900` |
| 纯文本、5 秒、480p | succeeded；`completion_tokens=50638` |
| 纯文本、5 秒、1080p | succeeded；`completion_tokens=245025` |
| 5 秒 `reference_video` 输入、5 秒输出、720p、`Input-Has-Video: true` | succeeded；`completion_tokens=216900` |

上述任务都显式传入 `duration=5`，尚未取得“不传 duration”时移动云实际采用 5 秒的目标租户证据。
平台 ModelArk V3 北向合同把缺省 duration 解释为 5 秒并保持可选字段不出现在南向 JSON；移动云生产
启用前必须补做该缺省请求探测，若 Provider 语义不同则保持渠道禁用并调整精确 adapter 合同。

列表接口返回该 API Key 可见范围内的既有任务，而不是平台 `user_id + app_id` 范围。因此平台北向列表
只能查询本地 Task 事实，绝不能把移动云列表接口直接透传给客户。

文档不同章节对 Task 与结果 URL 的保留期表述并不完全一致：可见“仅保留近 7 天任务”和结果 URL
约 24 小时等口径。平台不能把其中任一口径承诺为长期存储，内容回源必须使用 Task 创建时冻结的连接，
调用方应及时转存结果。

## 4. 素材 API 原始事实

素材接口与视频接口不是同一种鉴权合同：

| 项目 | 官方资料事实 |
| --- | --- |
| 固定 Gateway | `https://ecloud.10086.cn/api/openapi-maas/exp/aicc/v2` |
| 鉴权 | 移动云全局 AK/SK 的 V2.0 Query 签名 |
| 资源池 | OpenAPI 页面标记为 `CIDC-CORE-00` |
| Region/ProjectName 请求字段 | 素材 API 文档未要求 |
| 资源归属 | 当前签名用户/租户；没有 ProjectName 不等于跨租户全局可见 |

签名 Query 包含 `AccessKey`、`Timestamp`、`SignatureMethod`、`SignatureVersion=V2.0`、
`SignatureNonce` 和 `Signature`。规范化查询字符串排序并编码后，签名原文为：

```text
HTTPMethod + "\n" + percentEncode(servletPath) + "\n" + shaEncode(CanonicalizedQueryString)
```

签名密钥使用 `BC_SIGNATURE&` 前缀与 SecretKey 组合。该合同不同于火山/BytePlus 的 Action、Region、
ProjectName 签名，不能复用其 adapter。

### 4.1 素材组与素材操作

| 资源 | 方法与路径 | 关键请求/响应事实 |
| --- | --- | --- |
| 创建 AIGC 素材组 | `POST /asset-group` | `groupType=AIGC`、`groupName`，可选 `description`；返回 opaque group ID |
| 查询素材组 | `GET /asset-group/{groupId}` | 单资源查询 |
| 更新素材组 | `PUT /asset-group/{groupId}` | 上游提供；平台北向当前不因此自动发布该操作 |
| 删除素材组 | `DELETE /asset-group/{groupId}` | Provider 原始能力；平台不发布也不主动调用 |
| 创建素材 | `POST /asset` | `groupId` 必填，另有 `assetName`、`assetUrl`、`assetType`；异步处理，返回 opaque asset ID |
| 查询素材 | `GET /asset/{assetId}` | 状态 PROCESSING/ACTIVE/FAILED；返回错误信息及约 12 小时签名 URL |
| 更新素材 | `PUT /asset/{assetId}` | 修改名称 |
| 删除素材 | `DELETE /asset/{assetId}` | 单资源删除 |

`assetType` 支持 Image、Video、Audio。移动云还提供素材组和素材列表接口，但平台公开合同继续只代理
带客户模型的单资源操作，不发布列表。

与火山/BytePlus 官方素材接口相比，移动云的普通素材创建必须提供 `groupId`。调用方必须先创建或取得
素材组，平台不能因缺少“项目名称”而自动创建分组或把分组视为 Project 的替代品。

### 4.2 AIGC 与真人人像

AIGC/虚拟人像使用普通 `groupType=AIGC` 素材组。真人人像通过认证 H5 建组：

1. `POST /real-person-auth/sessions` 创建认证会话；请求无业务参数，返回 `bytedToken`、`h5Link`、
   `expiresIn`；
2. 用户在 H5 完成移动云要求的登录与认证；
3. `POST /real-person-auth/asset-group/by-byted-token`，传入 `bytedToken` 获取 group ID；
4. 再在该真人组内创建 Image、Video 或 Audio 素材。

官方指南要求一个真人组只对应一个真人；同一真人的不同造型可进入同组并由 Provider 做一致性校验。
平台只代理会话、H5 URL 和 token 换组，不自建人脸表单、真人授权库或撤回状态机。

## 5. 价格原始事实

单位为人民币/百万 Token：

| 输出规格 | 含视频输入 | 不含视频输入 |
| --- | ---: | ---: |
| 480p/720p | ¥56 | ¥92 |
| 1080p | ¥62 | ¥102 |

官方估算公式为：

```text
estimated_tokens = (input_video_seconds + output_seconds) × output_width × output_height × fps / 1024
```

目标租户四次成功样本进一步显示终态 usage 的实测取整规则为：

```text
observed_completion_tokens = floor(
  ((input_video_seconds + output_seconds) × fps + 1) × output_width × output_height / 1024
)
```

其中无视频输入时 `input_video_seconds=0`；额外的 `+1` 表现为一个输出帧。该规律用于首版保守预扣，
不是替代终态 usage 的供应商承诺。5 秒输入加 5 秒输出的 720p 样本为 216900 Token，按公开含视频价
¥56/百万 Token 计算名义成本为 ¥12.1464；实际 Provider 金额仍以账单为准。

成功终态以 `usage.completion_tokens` 为实际结算证据。官方资料称仅成功生成的视频收费，审核失败等
不收费；该口径仍需用目标租户账单验证。资源包按 Token 预付、存在有效期及延迟扣减，不能直接作为
每个客户 Task 的即时 Provider 成本事实。

## 6. 上线前必须补齐的原始证据

本节闸门同样适用于 Standard。`seedance-2.0-cmcc` 可以作为已配置但不可调用的模型进入统一目录，
并明确返回 `availability=disabled`；在视频、素材和账单要求全部闭合前不得生产启用。Fast、Mini、2.5
没有 Provider mapping，不能配置进 Channel 或进入目录，还要额外满足各自的存在性与价格证据。

- 目标非免费租户的开通成功截图或受控运维记录和模型权限；
- 非加密 REST 对 image/audio 输入、缺省 duration、更多比例、时长边界和删除语义的真实响应；
- 480p/720p/1080p 各价档的 `usage` 与移动云账单对应关系；其中分辨率、视频 Header、纯文本和
  `reference_video` 的 API 行为已验证，但实际账单价档尚未验证；
- 视频 API Key 与素材 AK/SK 在同一租户下的素材引用可见性；
- AIGC 与真人组的 Image/Video/Audio 创建、ACTIVE/FAILED 状态、H5 过期和 URL 生命周期；
- 失败、cancelled、expired、审核拒绝和网络结果不明时的 Provider 实际收费。
- Fast、Mini 和 2.5 各自的移动云官方模型 ID/别名、开通入口、REST 字段、规格、素材兼容性和价格；
  在证据齐全前保持未映射、未定价、未发布。
