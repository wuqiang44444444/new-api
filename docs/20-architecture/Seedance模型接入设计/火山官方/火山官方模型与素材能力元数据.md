# 火山官方模型与素材能力元数据

## 1. 公开模型投影

| 字段 | 值 |
| --- | --- |
| `video.protocol` | `modelark_v3` |
| `video.operations` | create/list/get/delete/content（按 ModelArk V3） |
| `assets.supported` | `true` |
| `assets.management_mode` | `caller_managed_stateless` |
| `assets.requires_model` | `true` |
| `assets.reference_format` | `asset://{opaque_upstream_asset_id}` |
| `assets.media` | general image/video/audio；real_person image |
| `asset_group_requirement` | optional |
| `reuse_scope` | `asset_scope_<credential/project/region fingerprint>`，只读匿名值 |

列表操作在公开元数据中固定为 `supported=false`，真人认证查询使用单个会话 ID。Provider、Channel、AK/SK、Region、Project 和原始 task ID 不返回。

## 2. 逐模型视频记录

| 模型系列 | 分辨率 | 时长 | 参考媒体 |
| --- | --- | --- | --- |
| Standard | 480/720/1080p/4K（按代码/账号开通） | 4–15s | 由模型和官方账号合同决定 |
| Fast/Mini | 480/720p | 4–15s | 由官方模型合同决定 |
| 2.5 | 480/720p | 4–30s 或 -1 | 图≤30、视频≤10、音频≤10；支持 seed |

## 3. 生成规则

元数据来源是 `modelark_v3_volcengine + model_mapping + 官方 Action 素材协议`，不按客户模型名称或价格推断。代码事实：`model/channel_seedance_public_catalog.go`、`relaykit/dto/public_model_api.go`、`relay/channel/task/seedance/assets/official_action.go`。
