# 火山官方模型与素材库对接设计

## 1. 协议与凭据

视频使用 `video_upstream_protocol=modelark_v3_volcengine`，ModelArk V3 北向固定为 `/api/v3/contents/generations/tasks`。素材使用 `asset_upstream_protocol=volcengine_assets_action_v2024_01_01`，凭据为独立 AK/SK，Region 固定 `cn-beijing`，ProjectName 必填；视频 Channel Key 与素材 AK/SK 不混用。

## 2. 视频映射

客户模型经 `model_mapping` 映射到精确 `doubao-*` Model ID；文本、媒体、duration、resolution、ratio、generate_audio、watermark 按官方字段转换。代码登记 2.0/ Fast/ Mini 的 4–15 秒与 480/720p（标准版另可 1080p/4K），2.5 为 4–30 秒或 `-1`、480/720p。显式不支持字段在 Provider POST 前拒绝。

## 3. 素材映射

官方 Action adapter 对单资源和组执行 CRUD、列表和真人认证；平台对外仍只提供带 `model` 的单资源操作，不提供列表。创建/查询/更新/删除均使用冻结 Provider opaque ID；`asset://<opaque-id>` 进入视频请求时不做本地查询，兼容性由火山裁决。source URL 不持久化，平台不保存媒体二进制。

官方组/素材的 `ProjectName`、Region 和凭据组成连接作用域；公开 `reuse_scope` 只是匿名投影。切换账号、
Region、Project 或协议时，管理员必须在当前 Channel 编辑界面确认替换素材租户；后端原子保存并重建
scope identity，Channel ID 与客户模型保持不变。旧素材不迁移，历史 Task 按创建时快照执行。

## 4. 签名与异步安全

Action 请求由 adapter 生成签名，禁止把 AK/SK 写入日志。视频创建遵守 durable attempt、hold、sending、可信 task ID 原子规则；查询/删除使用冻结连接，不因当前配置改变而重选渠道。明确不支持返回 `unsupported_asset_operation`，未知结果不重试、不自动退款。

## 5. 验收边界

需逐模型核对中国区账号开通、成功/失败/取消语义、Token usage、官方账单和素材真人认证；代码实现与官方文档存在不等价时，以代码测试和真实 Provider 证据共同更新本目录。
