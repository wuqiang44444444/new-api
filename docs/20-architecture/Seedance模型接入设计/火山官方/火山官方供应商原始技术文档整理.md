# 火山官方供应商原始技术文档整理

## 来源与范围

资料来自 `docs/70-research/huoshan/` 的开通/创建/查询/取消文档、`Seedance国内与BytePlus官方模型及价格调研.md`，并以当前官方 adapter 代码核对路径和签名边界。官方文档只描述 Provider API；平台公开合同仍以 ModelArk V3 和本目录对接设计为准。

## 视频任务原始合同

| 项目 | 火山方舟事实 |
| --- | --- |
| 服务 | Ark，版本 `2024-01-01` |
| 创建 | `CreateContentsGenerationsTasks`，异步返回 task ID |
| 查询 | `GetContentsGenerationsTask`；另有任务列表、取消/删除文档 |
| 北向模型 ID | `doubao-seedance-2-0-260128`、`...fast...`、`...mini...`、`...2-5...` |
| 输入 | text/image/video/audio content、duration、resolution、ratio、generate_audio、watermark；2.5 另有 seed/output_format |
| 计量 | 成功视频按 Token；区分是否含输入视频和输出规格 |

官方地区资料明确区分中国区 `doubao-*` 与海外 `dreamina-*`，不得跨区复用模型 ID 或价格。

## 素材 Action 原始合同

代码按火山 Action API 使用 `Action`、`Version=2024-01-01`、Region `cn-beijing` 和 `ProjectName`；操作包括 `CreateAsset`、`GetAsset`、`UpdateAsset`、`DeleteAsset`、`CreateAssetGroup`、`GetAssetGroup`、`DeleteAssetGroup`、列表及 `CreateVisualValidateSession`/`GetVisualValidateResult`。鉴权为 AK/SK 签名，平台不向客户暴露。

## 原始计价资料

当前官方按量价：2.0 46/28、Fast 37/22、Mini 23/14、2.5 70/42 RMB/百万 Token（无视频/含视频）。官方资源包为 90 天预付 Token，不等于平台客户零售价。旧版 1.x 价格仅作存量核对。

## 资料限制

官方页面、API Explorer、账号开通状态可能变更；本文不把“页面可见”写成“本账号已开通”，也不复制密钥、签名参数或原始响应。
