# 计费表达式与协议探针架构

## 1. 范围与事实源

本文描述表达式计费从管理端编辑、保存校验、请求预扣到异步终态结算的稳定边界，重点说明为什么
Seedance 的按秒表达式必须使用明确的代码协议探针。表达式语言、变量归一和版本语义以
[`pkg/billingexpr/expr.md`](../../pkg/billingexpr/expr.md) 为权威；本文不复制完整语言参考。

表达式是客户模型自身的价格合同，只定义模型费用，不承载用户合同折扣、Provider 成本折扣、工具费或
违规费。用户合同折扣由[用户模型合同定价架构](用户模型合同定价架构.md)在模型费用小计完成后单独应用。

## 2. 端到端控制流

```text
管理员编辑当前客户模型
  -> 按客户模型与明确协议构造保存校验环境
  -> 编译、冒烟执行并持久化表达式
  -> 请求映射 Provider 模型并构造运行时 billing probe
  -> 预扣时冻结表达式、probe、组倍率和合同事实
  -> 终态按冻结表达式与可信实际用量幂等结算
```

保存校验与运行时必须使用同一协议字段边界。缺少必要字段、协议不匹配或表达式算术失败时必须失败关闭，
不得补零、按默认价格继续、切换另一份表达式或根据模型名猜测协议。

## 3. 校验环境的类型化边界

| 模型上下文                                        | 校验环境                         | 允许的任务字段                                                                                                 |
| ------------------------------------------------- | -------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| 普通模型或未绑定已启用 Seedance Channel           | 原有通用 token 请求向量          | 不提供 `_task`                                                                                                 |
| 已绑定 `ChannelTypeSeedanceLink` 的 Seedance 模型 | 代码 adapter 的任务探针          | `duration_seconds`、`resolution`、`has_video_input`、`generate_audio`、`input_mode`、`control_mode` 等通用字段 |
| 飞彩 `feicai_videos_v1`                           | Seedance 通用探针 + 飞彩专属字段 | 额外提供 `ratio`、`billing_mode`、`size_multiplier`                                                            |

协议身份来自已启用 Channel、精确客户模型和代码注册的 `video_upstream_protocol`，不来自模型名称、价格、
Base URL 或请求字段。飞彩专属字段只在飞彩协议的每一个冒烟请求体中提供；其它协议引用这些字段必须在保存
阶段失败，避免校验环境比实际运行时更宽。

## 4. 运行时与快照

- Provider 模型映射完成后，由所选 adapter 构造 `BuildTaskBillingProbe`；原始客户请求不能直接充当计费探针。
- 预扣和终态使用同一表达式版本、表达式内容、probe、原生组倍率和（若存在）合同计费事实。
- 异步 Task 在创建时冻结上述事实；管理员修改价格、协议、合同折扣或渠道配置不重新解释已创建 Task。
- 终态实际用量由 adapter 如实归一，客户结算单位由创建时冻结的计价方式决定。按秒/按次任务可以保存
  Token 作为 Provider 证据，但不把它改写为客户计价单位。
- 表达式结果到 quota 的转换使用统一 checked 饱和函数；缺失、NaN、溢出或负值不得产生负费用。

## 5. Seedance 价格事实示例

飞彩按秒模型的表达式系数使用美元/秒乘以一百万后的原价单位：

```text
seedance-2.0-1080p -> 363431.000000
seedance-2.0-4k    -> 741114.000000
```

新表达式直接读取 `_task.duration_seconds`。历史飞彩表达式中的 `_task.size_multiplier` 仅作为存量迁移兼容
字段，运行时恒为 `1`，不得复制到普通或其它 Seedance 协议，也不能被当作分辨率能力或额外折扣。

## 6. 前端编辑状态

定价编辑器以客户模型名绑定编辑器实例。切换模型会重新初始化表达式、计价模式和任务默认值，避免上一模型
的表达式在当前模型首帧短暂显示或被保存。保存成功后保留当前模型编辑上下文，不建立第二套价格状态源。

## 7. 变更性质：原生接线与本地优化

| 变更面                             | 性质                             | 约束                                                                  |
| ---------------------------------- | -------------------------------- | --------------------------------------------------------------------- |
| 表达式编译、AST 归一、quota 转换   | NEWAPI 原生计费能力保持不变      | 不修改语言语义，不复制第二套表达式引擎                                |
| 原生价格保存入口                   | NEWAPI 原生文件的必要窄接线      | 只把精确模型/协议上下文传给新增校验服务，不把 Link 规则写入原生价格表 |
| Seedance probe、协议字段和模型规格 | Link 专属新增文件与 adapter 优化 | 由代码注册协议决定，不增加管理员脚本或模型名推断                      |
| 管理端模型切换隔离                 | 既有前端定价页的局部正确性修复   | 只绑定编辑器生命周期，不重构通用定价组件                              |
| Task 计费快照                      | 共享异步底座的窄扩展             | 仅在适用任务接线，不改变未带快照的原生/历史任务语义                   |

## 8. 架构不变量

1. 一个表达式字符串在相同 token、请求上下文和版本下得到同一模型费用。
2. 保存环境与运行时 probe 的字段集合按同一协议注册表构造。
3. 缺少字段不补零、不静默降级、不切换协议或价格分支。
4. 合同折扣不写入表达式文本，工具费、违规费和 Provider 成本不经过合同乘法。
5. 已创建异步任务只使用冻结表达式和计费事实；新配置只影响新任务。
6. 所有公开和私有日志均不保存完整 Provider 响应、凭据、签名 URL 或 Task 私有数据。
