# 计费表达式与协议探针架构

## 1. 范围与事实源

本文描述表达式计费从管理端编辑、保存校验、请求预扣到异步终态结算的稳定边界，说明 Seedance 的
u() 用量字段合同如何复用 NEWAPI 原生表达式引擎。表达式语言、变量归一和版本语义以
[`pkg/billingexpr/expr.md`](../../pkg/billingexpr/expr.md) 为权威；本文不复制完整语言参考。

表达式是客户模型自身的价格合同，只定义模型费用，不承载用户合同折扣、Provider 成本折扣、工具费或
违规费。用户合同折扣由[用户模型合同定价架构](用户模型合同定价架构.md)在模型费用小计完成后单独应用。

## 2. 端到端控制流

```text
管理员编辑当前客户模型
  -> 按客户模型与明确协议构造保存校验环境
  -> 编译、冒烟执行并持久化表达式
  -> 请求映射 Provider 模型并构造运行时 billing probe
  -> 预扣时把冻结 probe 投影为受控 u() 事实并冻结表达式、组倍率和合同事实
  -> 终态按冻结表达式与可信实际用量幂等结算
```

保存校验与运行时必须使用同一协议字段边界。缺少必要字段、协议不匹配或表达式算术失败时必须失败关闭，
不得补零、按默认价格继续、切换另一份表达式或根据模型名猜测协议。

## 3. Seedance u() 字段合同

Seedance 新受理统一使用原生任务用量表达式 `u()`，表达式结果为该次请求的美元费用；旧 `c` /
`param("_task.*")` 不再用于新受理，也不能作为当前价格原样重存；历史 Task 仍按冻结快照解释。
固定价（即使不包含 `u()`）同样输出 USD，单位由 Seedance 类型化入口确定。字段合同的唯一权威来源是
`pkg/seedancebilling`：编辑器字段定义、保存校验、预扣事实构造、终态验证和盘点工具都读取这一份
Go 描述，不维护第二份 Go/JS/前端字段表，也不把 Provider 模型登记注入通用模型索引。

| 字段 | 类型/单位 | 来源 | 终态是否实测 |
| --- | --- | --- | --- |
| `tokens` | number / token | 提交时为管理员预扣预算；完成时为可信实测 completion tokens | 是（唯一实测计量） |
| `resolution` | enum 480p/720p/1080p/4k | 冻结的规范化请求条件 | 否 |
| `has_video_input` | boolean | 结构化视频输入；图片和音频不算视频输入 | 否 |
| `duration_seconds` | number / second | 冻结的请求计费时长 | 否 |
| `generate_audio` | boolean | 显式请求值或协议默认值 | 否 |
| `input_mode` / `control_mode` | enum | 受控请求分类 | 否 |
| `ratio`、`billing_mode` | enum（仅 feicai / funcloud 协议声明） | 协议专属探针字段 | 否 |

历史兼容字段 `size_multiplier`（运行时恒为 1）不进入新合同；引用它的旧表达式转人工处理，不自动生成。
管理展示、保存校验与离线迁移通过 `model.SeedancePricingChannels` 选择同一客户模型的合同：
有启用渠道时只采用启用渠道，无启用渠道时共同采用全部停用渠道的字段交集。管理快照一次加载
渠道并构建请求内投影，不引入跨请求缓存或运行时路由选择。

金额换算沿用上游引擎的两套语义，由快照冻结标记 `TaskUsageBilling` 分派，不在运行时翻译表达式：

```text
u() 任务表达式 quota = 表达式输出（USD） * QuotaPerUnit * groupRatio
c 旧 token 表达式 quota = 表达式输出（$/1M） / 1_000_000 * QuotaPerUnit * groupRatio
```

实测依赖规则（与保存校验、预扣、结算、补查和数据库资金保护共用）：表达式读取 `u("tokens")` 时，
成功终态必须已有可信实测用量才能结算，预算本身不构成实测；只读取冻结条件的表达式按冻结事实直接
结算，不等待 Token，也不因此免除已发布协议的预算配置要求。`u()` 必须直接调用，键为与引擎精确匹配的静态字面量；函数别名、动态键与带首尾空白的键
在保存与受理前拒绝，无法证明的已有快照按需要实测处理。

## 4. 保存校验边界

| 模型上下文 | 校验环境 |
| --- | --- |
| 普通（非 Seedance）模型 | 原生插件 usage schema 或通用 token 冒烟向量 |
| 已归属 Seedance Channel 的客户模型，所有保存（包括重复保存或仅修改预算） | 同一 u() 字段合同：只允许声明字段、必须 `tier()` 包裹、禁止 header/时间函数、禁止 param 与 c/p 等 Token 变量混用，向量结果有限且非负 |

冒烟校验完整枚举实际引用字段的边界组合，不裁剪中间枚举值；超过 4096 个组合时明确拒绝，
不把有限边界检查声称为任意数值输入的形式化证明。请求预扣与结算仍分别校验实际求值及金额边界。

校验环境按精确客户模型与已启用（无则全部停用）Seedance Channel 的代码协议构造，不按模型名称、
价格或请求字段推断。飞彩专属字段只在飞彩协议声明；其它协议引用必须在保存阶段失败，避免校验环境
比实际运行时更宽。

管理价格接口对 Seedance 归属模型返回该字段合同（`usage_schema`）、`preconsume_token_budget` 标记
以及跨类型同名冲突 `billing_contract_conflict`；原生插件模型继续返回原生 schema。冲突在管理端与
公开端一致阻止编辑与保存，不以其中一类覆盖另一类。

## 5. 运行时与快照

- Provider 模型映射完成后，由所选 adapter 构造 `BuildTaskBillingProbe`；原始客户请求不能直接充当计费探针。
- 预扣把冻结 probe 投影为受控 u() 事实（`u("tokens")` 取预扣预算），并冻结表达式、事实、组倍率、
  UsageUnits 与（若存在）合同计费事实；终态求值输入 = 冻结 probe 投影 + 已接受实测 tokens，
  是临时投影，已接受事实（`ActualUsageReported`/`ActualTokens`）始终是存储与资金权威。
- 异步 Task 在创建时冻结上述事实；管理员修改价格、协议、合同折扣或渠道配置不重新解释已创建 Task。
- 终态实际用量由 adapter 如实归一；客户结算单位由创建时冻结的快照标记决定，Token 只作证据，
  不改写按秒、按次或按冻结条件的计价单位。
- 表达式结果到 quota 的转换使用统一 checked 饱和函数；缺失、NaN、溢出或负值不得产生负费用。

Synlink Video V1 使用通用 Seedance 探针，必须配置 `tiered_expr`，不套用官方倍率或 FunCloud 价格。
依赖 `u("tokens")` 的表达式必须配置预扣预算；纯冻结参数表达式沿用已发布协议例外。终态 `task.usage`
只作为可信用量归一输入，缺失或非法用量不补零，沿用 `awaiting_usage`；客户 quota 不代表未知的
供应商成本。

## 6. Seedance 价格事实示例

新合同表达式直接输出美元费用（系数为真实单价）：

```text
按 Token：tier("base", u("tokens") * 5 / 1000000)
按秒：  tier("base", u("duration_seconds") * 0.4)
按分辨率分档：u("resolution") == "4k" ? tier("4k", 0.7) : tier("base", 0.5)
```

历史飞彩按秒表达式使用美元/秒乘以一百万后的原价单位（例如
`param("_task.duration_seconds") * 363431`）。历史飞彩表达式中的 `_task.size_multiplier` 仅作为
存量迁移兼容字段，运行时恒为 `1`，不得复制到普通或其它 Seedance 协议，也不能被当作分辨率能力或
额外折扣；迁移由离线工具 `cmd/seedance-price-migrate` 按可证明子集转换，其余转人工。

## 7. 前端编辑状态

定价编辑器以客户模型名绑定编辑器实例。Seedance 归属模型进入任务用量编辑器并独立组合预扣预算
字段；字段定义与「预算是否必需」是两个独立事实，不能把有 schema 等同于无需预算。切换模型会重新
初始化表达式、计价模式和任务默认值，避免上一模型的表达式在当前模型首帧短暂显示或被保存。保存
成功后保留当前模型编辑上下文，不建立第二套价格状态源。预算为空时显示条件提示：需要预算的请求
会被拒绝；是否必需仍由后端协议判断，前端不通过字符串匹配另行推导。预算变更和还原均纳入未保存状态。

## 7a. 只读展示投影与管理员试算

前端不再用正则或 JavaScript 求值解释表达式金额；金额与条件展示统一消费后端只读投影
（`pkg/billingexpr/display.go`，投影版本随语义演进，当前为 v2）：

- 投影只对可证明的线性 Token 单价、常量算术、档位条件与条件倍率给出 `exact` 结果；条件作为除数
  时按倒数倍率解释，价格子树作分母等非线性结构整体标记 `opaque` 并给出稳定原因，原式仍可保存执行。
- 投影保留完整档位条件（含前序条件的否定）、非 1 的另一分支与显式零倍率；固定请求费用单独标注
  每请求单位；同一变量多次出现正确合并。常数折叠使用 Go 数值语义，与实际引擎逐项对照。
- 公开定价、合同定价与用量日志在可见性过滤/脱敏之后为响应附加 `billing_display`；日志只改响应
  对象，历史金额与 `request_rules` 不变。命中档位行展示日志事实 `matched_tier`，与单价投影解耦；
  缺历史命中事实时明确说明，不用当前时间猜测。分页内按完整表达式去重并复用有界静态缓存；
  版本不支持或 hash 不一致时显示「暂无法展开」，不回退猜价。
- 任务用量（u()）表达式由同体系任务投影输出美元金额与任务单位：支持 `tier()` 内条件单价与
  条件两侧任意层级嵌套展开，分辨率矩阵类条件公式可完整给出各档价格，不再整体标记不可展开；
  仍无法证明的结构维持明确不可展开状态，不返回局部猜价。
- 详情页档位条件按结构化条件树本地化渲染否定、布尔或与数值比较，不向客户输出表达式原文。
- 卡片价格范围同时纳入用量费、固定附加费与可证明的条件倍率场景；固定费按每请求单位展示，
  不参与 1K/1M Token 单位换算。仅部分档位存在的收费项按存在性语义参与范围，不凭空补项。
- 显式零价与零组倍率按「存在且为零」展示，与未配置价格区分。公开定价响应携带
  `basis_price_configured` 存在性字段，未配置价格的模型明确显示未配置，不以引擎缺省价冒充
  已配置售价。
- 模型详情与分组详情消费同一投影；分组详情优先使用响应中的 `group_ratio`，仅缺失时回退全局
  倍率，保留显式零倍率。示例金额装配采用写时复制，隔离定价缓存与请求内修改。

管理员只读试算入口 `POST /api/option/billing-expression/preview`（Root 权限，与 option 组一致，
原生 router 仅一行注册）：

- 输入完整表达式与明确用量口径（openai/anthropic，含缓存创建字段差异）；可选模拟时刻（RFC3339）
  与合成 param/header 探针。缺上下文时展示缺失项或要求显式模拟缺失，不伪装真实请求。
- 服务端复用 `BuildTieredTokenParams`、真实引擎与统一 quota 换算（`GroupRatio=1` 只读快照，不落
  账），返回模拟时刻、归一用量、命中 tier/规则、raw USD 与整数 quota。允许零用量试算（固定费、
  零费用）；负值、非有限值与非法上下文报错，不显示金额 0。
- 任务用量（u() 美元）表达式通过 `task_usage=true` 的同一试算路径执行：TaskUsageBilling 单位、
  合成 `sample.usage` 样本、数字/枚举/布尔/查表/固定价均支持；引用字段缺少样本、负值或非有限值
  拒绝。识别到 Token 变量的任务试算明确报单位错误；对无渠道引用的旧 `c/_task` 配置，页面提供显式
  「按旧 Token 规则试算」入口并标注结果不改配置，无自动单位 fallback。
- 试算失败不替代保存校验；模拟时间与合成上下文不写入计费配置，试算不触发 Provider 调用。

## 8. 变更性质：原生接线与本地优化

| 变更面                             | 性质                             | 约束                                                                  |
| ---------------------------------- | -------------------------------- | --------------------------------------------------------------------- |
| 表达式编译、AST 归一、quota 转换   | NEWAPI 原生计费能力保持不变      | 不修改语言语义，不复制第二套表达式引擎                                |
| 原生价格保存入口                   | NEWAPI 原生文件的必要窄接线      | 只把精确模型/协议上下文传给新增校验服务，不把 Link 规则写入原生价格表 |
| Seedance 字段合同与校验            | Link 专属新增包 `pkg/seedancebilling` | 唯一字段权威来源；复用既有协议配置，不改插件 ABI 或加入原生模型索引 |
| Seedance probe、协议字段和模型规格 | Link 专属新增文件与 adapter 优化 | 由代码注册协议决定，不增加管理员脚本或模型名推断                      |
| 管理端模型切换隔离                 | 既有前端定价页的局部正确性修复   | 只绑定编辑器生命周期，不重构通用定价组件                              |
| Task 计费快照                      | 共享异步底座的窄扩展             | 仅在适用任务接线，不改变未带快照的原生/历史任务语义                   |

## 9. 架构不变量

1. 一个表达式字符串在相同 token、请求上下文和版本下得到同一模型费用。
2. 保存环境与运行时 probe 的字段集合按同一字段合同构造；Seedance 字段合同唯一来源是
   `pkg/seedancebilling`。
3. 缺少字段不补零、不静默降级、不切换协议或价格分支。
4. 合同折扣不写入表达式文本，工具费、违规费和 Provider 成本不经过合同乘法。
5. 已创建异步任务只使用冻结表达式和计费事实；新配置只影响新任务。
6. 所有公开和私有日志均不保存完整 Provider 响应、凭据、签名 URL 或 Task 私有数据。
7. `u("tokens")` 是唯一实测计量；预算不构成实测，纯冻结条件不触发 Token 等待。
