# ADR-0019: 合同解耦为客户折扣层

## Context

客户合同最初与授权和路由耦合：合同规则把一个公开模型绑定到一个具体渠道，请求命中规则后
返回该渠道与路由组，并通过合同 pin、强制组、模型白名单和重试覆盖参与执行控制。这带来两个问题：

1. 同一公开模型由多个渠道提供时，一份合同只能登记一个渠道，管理员无法在同一合同内表达
   「同模型多渠道、同一折扣」的商业约定。
2. 合同成为原生分发之外的第二套路由与授权事实：折扣随实际选中渠道变化，渠道明细被当作
   履约资格，与 NEWAPI 原生选择器（优先级、权重、分组、重试）的权威地位冲突。

约束：NEWAPI 原生权限、分组和分发继续是唯一权威；合同仍按 API Key 绑定；异步任务保持
创建时冻结的资金事实；SQLite、MySQL、PostgreSQL 三库兼容；
[硬约束](../../00-context/硬约束.md)不因合同放宽。
[方案记录](../../99-archive/2026/09/2026-09-14-合同同模型同折扣多渠道支持方案.md)与
[合同定价架构](../账单计费-用户模型合同定价架构.md)描述目标规则与实现边界。

## Decision

本决策对应已确认并授权实施的合同折扣边界；accepted 表示架构决策已接受，不表示真实账单、
MySQL/PostgreSQL 升级与生产灰度已完成。外部验证状态以实施方案为准。

- 合同仅是客户折扣层。运行时只按「绑定合同 + 精确公开模型」解析唯一折扣；管理明细中的
  `channel_id`、`route_group` 是配置来源上下文，不构成路由候选集、履约资格或授权范围。
- 同一合同内允许同模型多渠道规则共存，前提是折扣按八位定点 `ratio_units` 完全相等；
  规则唯一约束为 `contract_id + public_model + channel_id`，折扣不进唯一键。同模型不同
  折扣、同模型同渠道重复、仅大小写不同的模型名均拒绝保存；折扣一致性在完整规则集
  保存边界统一校验。
- 合同不再写入 pin、组覆盖、模型白名单、重试覆盖或候选过滤。合同成功读取但未约定该模型时
  按原生价格继续；合同读取失败、归属错误、版本或折扣一致性异常时计费前失败关闭，不降级为
  原价或倍率 1。
- 计费顺序保持「客户模型费用 = 原生模型费用小计 × 实际有效原生组倍率 × 合同折扣」。
  合同折扣不作用于独立工具费、违规费、充值折扣或 Provider 成本；不承诺不同渠道或分组的
  最终成交价相同。
- 首次计费前冻结合同 ID、版本、公开模型与折扣事实；实际渠道与组从真实执行上下文取证。
  在途任务与历史冻结记录不因合同修改、规则删除或 Key 换绑重解释。
- 旧唯一索引显式迁移并在三个数据库分别验证升级与重复执行行为；存量单渠道规则保留。
  无调用方的合同 pin 标识与专属路由辅助逻辑直接删除，不留兼容开关或双读路径。

## Consequences

- 收益：一份合同可表达同模型多渠道同折扣；折扣不再随实际选中渠道变化；合同回归纯商业
  条款，路由与授权权威唯一。
- 代价：唯一索引迁移需在三个数据库分别验证；解除合同路由覆盖后，存量 Key 的原组、
  AutoGroups 与模型限制立即按原生语义生效，升级可能改变现有路由结果，须在升级前核对。
- 风险：客户可能把「同模型同折扣」误解为「跨渠道同价」；原生分组倍率不同时最终价格仍
  不同，该差异被明确接受而非修复。
- 风险：合同渠道明细停用不再影响折扣与可用性；管理员若继续把明细当作资格清单会误判，
  管理界面与统计口径必须区分「渠道规则数」与「去重模型数」。
- 后续约束：不得重新引入合同专属候选选择、跨组优先级比较、渠道过滤器、pin 或单次执行
  限制；不得按「模型 + 实际渠道」分支定价；合同明细不得升级为第二套模型可用性事实；
  Seedance 一模型一启用渠道等专用入口约束不因折扣相同放开。

## Alternatives Considered

- 合同专属候选选择与跨组优先级比较（此前提案）：未采用，它把合同升级为第二分发器，与
  原生选择器权威冲突，且跨组比较需要统一本不可比的组语义。
- 保持一模型一渠道，由管理员为多渠道建立多份合同：未采用，Key 只绑定一份合同，客户需
  多 Key 切换，折扣一致性退化为人工维护。
- 允许同模型不同折扣并按实际渠道匹配：未采用，运行时折扣匹配重新依赖渠道身份，回到
  「折扣随渠道变化」的原问题，并产生同模型多价的不可判定定价。
- 折扣纳入唯一键以允许同渠道不同折扣：未采用，同渠道同模型出现两个合法折扣没有业务
  含义，只会制造歧义配置。
- 为「跨渠道同价」覆盖原生组倍率或新增平行计价规则：未采用，破坏原生组倍率语义并建立
  第二套计价；如需该效果，应另行决策最终计价一致性要求。
