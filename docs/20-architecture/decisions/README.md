## 不建立本地 ADR 的上游事实

NEWAPI 原生路由、DTO、Relay、Adapter、模型发现和客户端协议语义以上游代码为唯一权威，包括原生 `/v1/videos` 与 `/v1/video/generations`。同步上游能力不创建“恢复”“共存”或“兼容”ADR，也不得据此新增原生专属 Router、DTO、`client_protocol`、fallback、兼容中间件或历史协议推断。

Link 隔离只能在 Link 自身的显式注册、类型化路由、capability 和候选实现选择中完成。Link 文档不能授权修改、复制、替换或收紧 NEWAPI 原生合同。

## 维护规则

- ADR 只记录长期、跨模块、难以逆转且存在真实备选方案的决策；实现步骤、兼容补丁、排障过程和当前代码清单不新建 ADR。
- ADR 编号和文件身份创建后不可更改。新决策取代旧决策时，旧 ADR 保留原编号并更新
  `status: superseded`、`superseded-by`；索引同时列出新旧关系。
- 当前有效 ADR 不把 superseded ADR 作为规范性前置条件；专题架构直接描述当前事实，仅在解释
  取舍时链接决策链。
- ADR 中的实现范围必须显式说明是否仅适用于 Link；未明确接入的 NEWAPI 原生路径默认不受本地 ADR 约束。
- 当前事实、路由和实现清单写入专题架构；ADR 只保留决定、原因、后果和未采用方案。
- 新 ADR 使用现有最大编号加一，不回填缺号，不因文件删除、标题优化或目录整理重新编号。
