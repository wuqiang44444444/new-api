# ADR-0022: 日报当前版本发布与历史证据迁移

## Context

旧发布规则将已入账事实与派生原价的覆盖变化合并为同一种错误。历史图片冻结表达式中的等价叶子触发误判，
导致账单重建失败并延误同日用量升级。另有日期已经缺少数据库日志，只留有冻结投影。切换新解析或计量版本时，
页面需要明确区分重建、缺少来源和已验证结果。已确认正式月账单有独立的版本与更正流程。

## Decision

- 日报默认查询、显式版本引用、新导出和新用量邮件只接受相应类型的当前版本。未完成日期按重建或来源不足展示，
  同版本退役批次继续遵守引用期限，Root 只可恢复当前解析版本的批次。
- 原始消费、退款、净额、资金归属和来源覆盖继续校验。原价证据不足可以作为派生字段的质量原因随新版发布，
  结算留存的原价仍受保护。历史复算始终使用当时的冻结价格与计费事实，逐笔差异在 Root 诊断中记录。
- 按源日志、冻结逐笔、冻结汇总的证据顺序处理历史日期。使用冻结投影时标识证据粒度，无法证明的字段保持缺失。
  已证实没有充分历史来源时返回明确状态。正式月账单及其更正流程继续使用正式冻结版本。
- 用量计量升级可独立重建，涉及跨日退款的关联批次继续按已有事务边界发布。发布候选使用原有租约和来源边界。

## Consequences

版本切换期间部分日期只显示状态或已发布日期的小计。原价派生解释与来源缺失可分别复核。
部署需先处理旧 worker、旧邮件及旧导出，再启动升级 worker。重建按日期和原有资源门控推进。

## Alternatives Considered

- 继续提供上一个日报版本会使页面和导出长期混用不同解析口径。
- 直接放开覆盖校验会漏掉真实来源丢失、资金归属和金额变化。
- 用当前价格重算历史费用会覆盖当时的已入账与冻结证据。
