# ADR-0010: 视频公开 SKU 能力与候选渠道等价

## Context

[ADR-0007](./0007-视频Link合同与共享任务底座.md) 已确定 `contract_id` 是 Link 合同键，
`video_upstream_profile` 是渠道执行键。但是，只校验 profile 能否解析请求，或只依赖
`Ability` 把模型绑定到渠道，不能证明同一公开 SKU 的全部候选渠道具有相同的请求值域、
媒体组合、任务状态、取消、删除和内容下载语义。

如果同一 SKU 同时进入生命周期能力不同的 official、反代或中转渠道，客户端对同一个
DELETE、查询或内容下载请求会因随机选渠得到不同结果。这违反“一个公开 SKU 对应一个稳定
合同”。反过来，让渠道 profile 决定客户端是否支持某个字段，也会导致渠道配置反向扩张或收缩
已经发布的合同。

## Decision

- 建立版本化的 `VideoSKUCapability`，作为公开视频 SKU 能力合同的唯一权威。至少声明：
  - `contract_id`、合同版本和公开模型；
  - 创建模式、媒体类型、角色、数量、组合、scheme、MIME 与大小上限；
  - duration、resolution、ratio、audio 等字段的值域、缺省值和规范化规则；
  - 查询、列表、排队取消、运行中动作、终态删除和内容下载能力；
  - 公开状态、终局判定、结果要求和计费维度。
- 渠道和 `video_upstream_profile` 只声明渠道实现能力，不得成为 SKU 能力合同的来源。一个候选渠道
  必须完整实现所绑定 SKU 的能力；只实现子集时从该 SKU 的候选集合移除，不能在选中后删字段、
  降级或返回随机的生命周期差异。
- 请求处理顺序固定为：

```text
客户端 DTO 与合同版本校验
-> SKU 能力校验和规范化
-> 枚举 Ability 候选渠道
-> 校验渠道/profile 完整实现 SKU 能力
-> 应用 asset binding 和其他路由交集
-> 按优先级、权重和可用性分发
-> 发送前使用同一冻结能力版本再次校验
```

- 配置发布时必须校验同一 SKU 的全部候选渠道在客户端可观察能力上等价；不等价的 Ability
  拒绝发布。运行时仍执行 fail-closed 校验，以防缓存、并发编辑或历史脏配置绕过发布检查。
- 生命周期能力由公开 SKU 定义，渠道 profile 只能报告是否实现。Task 创建时冻结
  `sku_capability_version` 和最终生命周期能力；列表、查询、DELETE 与内容下载均按冻结事实
  投影，不按渠道当前配置重新计算。
- 不改变语义的显式值可以由 SKU 规范化规则接受。例如固定分辨率 SKU 可以接受字段缺失或
  与固定值完全一致的显式值，只拒绝冲突值；只禁止开启音频的 SKU 可以接受
  `generate_audio=false`，只拒绝 `true`。规范化后的同一个值必须同时用于能力判断、计费和
  Provider 转换。
- `asset://ast_xxx` 与请求级 URL/Data URL 是否可在一次请求中混用，也是 SKU 的媒体组合
  能力。未显式声明时 fail closed；第一阶段 ModelArk 视频 SKU 不混用两条路径。

## Consequences

- 收益：公开 SKU 的合同不再随权重、渠道状态或渠道 profile 漂移。
- 收益：字段缺省、显式等价值、生命周期和媒体组合都有单一、可测试的规范化来源。
- 收益：新增渠道只需证明自己完整实现已有 SKU 能力合同，不会反向改变客户 API 合同。
- 代价：Ability 发布和运行时选渠增加能力等价校验，Task 快照增加能力版本。
- 风险：能力声明与 adapter 实现不一致仍可能造成运行错误；必须同时保留发送前校验、合同
  测试和真实渠道灰度。
- 后续约束：新增或改变客户端可观察能力时必须升级 SKU 能力版本；不兼容变化应拆分公开 SKU
  或 Link 合同版本，不能只修改 profile。

## Alternatives Considered

- 只依赖 `Ability` 表示渠道支持模型：未采用。模型可路由不等于完整实现请求和生命周期合同。
- 在选中渠道后按 profile 拒绝不支持字段：未采用。同一请求会因随机选渠而成功或失败。
- 取全部候选渠道能力的最小交集作为动态 Link 合同：未采用。渠道上下线会静默改变已发布合同。
- 要求所有 Seedance 渠道实现完全相同能力：未采用。等价范围应按公开 SKU 隔离，不应阻止
  使用不同 SKU 发布真实存在的能力差异。
