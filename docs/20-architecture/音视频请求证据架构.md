# 音视频请求证据架构

## 边界与目标

音视频请求证据（一期）为客服与运维提供"客户请求、履约选择、南向发送、上游响应、轮询观察、
结果交付"的事实记录。证据只描述发生过的事实，不是任务状态、资金或重放许可的第二事实源；
不得为补日志自动重发、换渠、退款或改写任务结果。

## 数据与控制流

- 主库索引：`task_request_evidences`（请求、用户/应用、Task/attempt 关联、协议事实、保留期、
  正文过期标记）+ `task_request_evidence_events`（阶段、尝试序号、对象引用、字节数、sha256、
  完整/脱敏标记）+ `task_request_evidence_access_logs`（查看/下载审计）。
- 私有对象：正文（北向/南向/上游响应）进入独立命名空间的加密对象存储（一期本地 AES-256-GCM
  目录实现，接口为 `TaskRequestEvidenceObjectStore`）。加密密钥显式配置优先，未配置时从
  CRYPTO_SECRET/SESSION_SECRET 派生（派生密钥随宿主密钥轮换失效，读取得到明确解密失败）。凭据在采集时以占位符脱敏，永不落库。
- 采集点（全部为窄调用）：
  - ModelArk 转换前、`executeTaskSubmissionWith`（其他任务类）与 `AudioHelper`（音频类）建立证据会话，
    同步持久化北向证据；失败在发送前拒绝。
  - `doRequest` 发送前持久化最终南向证据（在 `MarkTaskCreateAttemptUpstreamStarted` 之前），
    发送后包装响应体边转发边有界捕获。
  - Seedance HTTP 返回边界在归一化前捕获原始轮询；其他 adapter 在 `task_polling` 正文读取点追加证据。
  - 外层响应呈现结束记录客户 JSON/文本响应；二进制响应仅记录交付统计。
  - 两套内容代理交付路径记录状态与实际写出字节。

## 不变量

- 对象键使用数据库事件 ID；事件先保留 unavailable 状态，对象提交后才更新真实阶段。对象不可覆盖。
- 完整性由 EOF、读写错误与截断决定；脱敏改写长度不表示传输截断。无法安全脱敏的结构化片段不存储。
- JSON、multipart、表单及 SSE 按内容类型脱敏；管理员预览在截取前遮盖 URL 查询参数。
- 配置异常不关闭取证，拒绝新增受理；文件写入有界等待且限制并发。底层文件系统阻塞无法强制取消，
  超时后不再取得发送资格；发送前复核既有 attempt 状态，恢复已改变状态时保留资金等待原有对账。

- 证据持久化不可用时，有限正文的高成本请求在发送前以本地不可重试错误拒绝
  （`ErrTaskRequestEvidenceUnavailable`/`ErrTaskRequestEvidenceBodyTooLarge`）；hold 已建立时
  走既有 `ReleaseRejectedTaskCreateAttempt` 释放，不标记 unknown，不换渠重试。
- 无 attempt 的音频路径（TTS/转写/翻译）按平台请求 ID 建立证据，不创建伪视频 Task。
- 崩溃窗口语义不变：hold/sending 后、发送前崩溃仍按 unknown 保守处理；不凭证据缺失退款或重发。
- 脱敏为采集时单向操作：Authorization/Cookie/API Key/支付凭据/代理认证不保存；
  `max_tokens` 等业务字段保留；签名 URL 仅可存在于受保护正文中，管理员视图遮盖签名参数，
  Root 下载原始对象。
- 权限：管理员查看脱敏业务证据与事件时间线，Root 下载原始对象；每次查看/下载写访问审计；
  任务日志和带平台请求 ID 的消费日志详情按需加载证据。列表不返回正文，详情返回有界脱敏预览。上游诊断字段仅 Root 投影。
- 保留期 `TASK_REQUEST_EVIDENCE_RETENTION_DAYS`（默认 0 = 不清理）到期后删除正文、保留索引并
  标记"正文已过期"。

## 覆盖边界（一期）

已接入：共享 `doRequest` 覆盖的全部 HTTP 音视频创建/音频 JSON/multipart、Seedance 与插件轮询
直连、两套视频内容代理、结果交付统计。
未接入（二期）：Realtime/WebSocket 双向流、Volcengine TTS 与讯飞独立 WebSocket、Midjourney、
Chat/Responses/Gemini 媒体入口的按需开启。二期完成并通过覆盖矩阵验收前，不宣称全量记录。

## 正文边界与保留期限

非结构化纯空白正文按原文保存；结构化正文无法解析时标记不可用，不在脱敏分类时访问空切片。
存量任务首次轮询或结果交付时补建证据索引，与其它创建入口使用同一保留期限计算规则；
启用有限保留天数时必须写入到期时间，避免默认零值绕过正文清理。
