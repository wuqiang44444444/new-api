# 音视频请求证据架构

## 边界与目标

音视频请求证据（一期）为客服与运维提供"客户请求、履约选择、南向发送、上游响应、轮询观察、
结果交付"的事实记录。证据只描述发生过的事实，不是任务状态、资金或重放许可的第二事实源；
不得为补日志自动重发、换渠、退款或改写任务结果。

## 数据与控制流

- 主库索引：`task_request_evidences`（请求、用户/应用、Task/attempt 关联、协议事实、保留期、
  正文过期标记）+ `task_request_evidence_events`（阶段、尝试序号、对象引用、字节数、sha256、
  完整/脱敏标记）+ `task_request_evidence_access_logs`（查看/下载审计）。
- 私有对象：正文（北向/南向/上游响应）进入独立命名空间的加密对象存储（一期本地 AES-256-GCM
  目录实现，接口为 `TaskRequestEvidenceObjectStore`）。加密密钥显式配置优先，未配置时从
  CRYPTO_SECRET/SESSION_SECRET 派生（派生密钥随宿主密钥轮换失效，读取得到明确解密失败）。凭据在采集时以占位符脱敏，永不落库。
- 采集点（全部为窄调用）：
  - ModelArk 转换前、`executeTaskSubmissionWith`（其他任务类）与 `AudioHelper`（音频类）建立证据会话，
    同步持久化北向证据；失败在发送前拒绝。
  - `doRequest` 发送前持久化最终南向证据（在 `MarkTaskCreateAttemptUpstreamStarted` 之前），
    发送后包装响应体边转发边有界捕获。
  - Seedance HTTP 返回边界在归一化前捕获原始轮询；其他 adapter 在 `task_polling` 正文读取点追加证据。
  - 外层响应呈现结束记录客户 JSON/文本响应；二进制响应仅记录交付统计。
  - 两套内容代理交付路径记录状态与实际写出字节。

## 不变量

- 创建响应的上游请求追踪 ID 由 HTTP 响应边界统一提取与校验，Task 和证据索引复用同一结果。
  索引反映当前请求最后一次响应；后续响应未提供可用 ID 时清空前次值，不把旧尝试的 ID 冒充最终响应。
  平台请求 ID、Provider 任务 ID、创建请求追踪 ID 分别保留其身份，不互相填充，也不把创建追踪 ID
  标为失败轮询的追踪 ID。错误日志中的“查看任务”按公开 Task ID 定位既有任务页面，Provider 任务 ID
  继续仅在任务详情的 Root 视图显示。
- 对象键使用数据库事件 ID；事件先保留 unavailable 状态，对象提交后才更新真实阶段。对象不可覆盖。
- 完整性由 EOF、读写错误与截断决定；脱敏改写长度不表示传输截断。无法安全脱敏的结构化片段不存储。
- JSON、multipart、表单及 SSE 按内容类型脱敏；默认预览先按正文格式解码，再遮盖 URL 查询参数，
  最后截取。协议头大小写与 JSON 转义、表单编码不绕过遮盖；JSON 数字标识保持原精度。
  multipart 文件正文不作为文本预览，原始对象仍可由 Root 下载。结构解析失败明确显示读取失败，
  不回退原始正文；预览处理不修改已存对象。
- 配置异常不关闭取证，拒绝新增受理；文件写入有界等待且限制并发。底层文件系统阻塞无法强制取消，
  超时后不再取得发送资格；发送前复核既有 attempt 状态，恢复已改变状态时保留资金等待原有对账。

- 证据持久化不可用时，有限正文的高成本请求在发送前以本地不可重试错误拒绝
  （`ErrTaskRequestEvidenceUnavailable`/`ErrTaskRequestEvidenceBodyTooLarge`）；hold 已建立时
  走既有 `ReleaseRejectedTaskCreateAttempt` 释放，不标记 unknown，不换渠重试。
- 无 attempt 的音频路径（TTS/转写/翻译）按平台请求 ID 建立证据，不创建伪视频 Task。
- 崩溃窗口语义不变：hold/sending 后、发送前崩溃仍按 unknown 保守处理；不凭证据缺失退款或重发。
- 脱敏为采集时单向操作：Authorization/Cookie/API Key/支付凭据/代理认证不保存；
  `max_tokens` 等业务字段保留；签名 URL 仅可存在于受保护正文中，所有角色默认预览均遮盖 URL
  查询参数。Root 显式查看或下载受保护原文；原文不是未经处理的传输字节，不恢复认证凭据。
- 权限：管理员查看脱敏业务证据与事件时间线；Root 通过 `/events/:event_id/content` 查看原文，
  通过 `/events/:event_id/object` 下载。整个证据路由组禁止缓存。预览、原文查看、下载分别在实际
  入口记录 `view/redacted`、`view/original`、`download/original`，不重复记预览；审计沿用尽力写入，
  失败记录系统错误，不改变正文交付，也不宣称审计一定落库。
- 任务日志和带平台请求 ID 的消费日志详情按需加载证据；错误日志只要具备关联 ID 即可展开查询，
  不按事件类型猜测是否采集，有 HTTP 快照也可查询。任务失败优先仅按任务 ID 查询，无任务 ID 时
  按请求 ID；普通请求错误按请求 ID。无记录、过期、不完整与读取失败分别展示，不恢复历史缺失正文。
  无快照任务失败事件不展示空 HTTP 正文区块。错误码与失败原因独立展示，不向错误事件复制正文。
- 证据索引计数或列表查询失败返回失败响应，不包装为成功空列表；页面显示加载失败并支持重试。
  “查看任务”的显式零起始时间保持为零，不触发默认当天范围，历史任务与跨日任务仍按 Task ID 查询。
- 列表不返回正文，详情只返回有界脱敏预览，上游诊断字段仅 Root 投影。Root 原文弹窗共用于错误
  日志和任务详情，旧任务请求快捷入口也使用原文查看接口。原文不持久化到浏览器存储，关闭、切换
  记录或登录身份时取消查询并清除缓存，迟到结果丢弃；退出登录复用认证状态与查询缓存清理。
- 保留期 `TASK_REQUEST_EVIDENCE_RETENTION_DAYS`（默认 0 = 不清理）到期后删除正文、保留索引并
  标记"正文已过期"。

## 错误归属与公开响应

`TaskRequestEvidenceError` 保存主因类别、阶段、正文来源与错误链；
`ClassifyTaskRequestEvidenceRejection` 是唯一公开状态码和文案映射，入口只适配各自协议信封。
只有客户原始正文超限或明确的正文接收/JSON 语法违例返回 413/400；南向转换、存储与记录处理失败
返回服务错误，不反向归责客户。主处理故障后事件更新再次失败时，保留主因和次因，不用次因覆盖分类。
日志通过 `SanitizeTaskDiagnostic` 输出净化原因，公开响应不输出原始 cause。

发送资格无法核实时保留 `send_unverifiable` 与既有 unknown/资金处理语义，不能仅由公开 503 推导
安全重试或退款。客户端错误码见[错误与重试](../../web/public/docs-content/zh/concepts/errors.md)。

## 覆盖边界（一期）

已接入：共享 `doRequest` 覆盖的全部 HTTP 音视频创建/音频 JSON/multipart、Seedance 与插件轮询
直连、两套视频内容代理、结果交付统计。
未接入（二期）：Realtime/WebSocket 双向流、Volcengine TTS 与讯飞独立 WebSocket、Midjourney、
Chat/Responses/Gemini 媒体入口的按需开启。二期完成并通过覆盖矩阵验收前，不宣称全量记录。

## 正文边界与保留期限

非结构化纯空白正文按原文保存；结构化正文无法解析时标记不可用，不在脱敏分类时访问空切片。
存量任务首次轮询或结果交付时补建证据索引，与其它创建入口使用同一保留期限计算规则；
启用有限保留天数时必须写入到期时间，避免默认零值绕过正文清理。
