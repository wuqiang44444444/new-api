# 墨行 Seedance 发布门禁与验证矩阵

## 1. 发布阶段

| 阶段 | 必要事实 | 允许状态 |
| --- | --- | --- |
| 设计 | 当前 V2、历史 Ark、素材和账单边界已分离 | 文档 accepted，不表示 Ability 可用 |
| capability | 当前模型字段、值域、默认、媒体和生命周期有证据 | SKU 可解析，仍不表示生产可用 |
| implementation | 精确版本、binding、profile、路径、素材和 adapter/hash 完整 | 禁用渠道可做结构校验 |
| publication | HTTPS、单 Key、价格、exposure、素材作用域和实现覆盖通过 | 启用时原子 publication + Ability |
| 生产开放 | 成功、失败、unknown、内容、素材、usage 和账单黑盒通过 | 仅指定分组可用 |

## 2. 当前阻断项

在以下差距关闭前，墨行 Seedance 不应视为生产就绪：

| 项目 | 当前风险 | 发布要求 |
| --- | --- | --- |
| V2 与 Ark 等价性 | 当前注册可让 Ark 履约 V2 SKU | 排除 `moxing.seedance-ark-assets` 当前 SKU 候选 |
| 分辨率 | capability 含 1080p/4K | 当前 V2 只发布 480p/720p |
| last frame | capability 投影支持 | V2 未定义，发布为 false |
| prompt/default | 代码默认与官方必填/缺省说明未闭合 | 初版强制文本、时长、分辨率和比例显式 |
| 真人素材 | implementation 声明 real_person，relay adapter 只支持 general | 当前 V2 只登记 general |
| 结果/usage | 官方文档与 adapter 结构不一致，现有 fixture/代码注释不能证明生产事实 | 冻结真实终态样例、单位、证据来源与验证时间 |
| Provider 对账 | 只有接口资料 | 验证请求 ID、账号归属、最终一致性和失败扣费 |
| 部署数据 | publication/Task/binding 是否存在未知 | 变更 implementation 版本前只读审计 |

## 3. 确定性回归矩阵

### 3.1 注册与发布

- 精确 `moxing.seedance-media-task/<version>`、channel type、profile、create/query path、adapter、
  `relay_assets` 和单 Key 校验；
- 客户模型经 `model_mapping` 唯一得到 `seedance-2-0-oversea`；
- execution binding 唯一解析同一 Link SKU，缺失、重复或歧义均失败；
- 同范围普通候选冲突、publication 创建/核对/显式改绑和零候选保持 publication；
- Ark、TokenSave 和 JoyCreator 均不能加入当前 V2 候选；
- implementation/capability hash 改变时旧 Task 不由新版本轮询。

### 3.2 请求

| 用例 | 期望 |
| --- | --- |
| 文本 + 4/15/-1 秒 | 通过并产生精确 V2 字段；`-1` 保留发送，billing probe 固定按 15 秒预扣 |
| 3、0、16 秒或非整数 | 预扣前 4xx |
| 480p/720p | 通过 |
| 1080p/4K/未知分辨率 | 初版预扣前拒绝 |
| 七种已登记比例 | 逐值映射到 `aspect_ratio` |
| 无文本 | 初版拒绝 |
| 单首帧、首尾帧、1/9 张参考图 | 分别转换为 `single_image/none`、`multi_image/end_frame`、`multi_image/reference` |
| 10 张图、多个首帧/尾帧、首尾帧与参考图混用 | 拒绝 |
| 音频或视频输入 | 初版拒绝 |
| `generate_audio=false` | 上游仍收到显式 false |
| `watermark`、Provider 私有字段、metadata/extra 旁路 | 未发布前拒绝 |
| 直接媒体与 `asset://ast_*` 混用 | 拒绝 |

### 3.3 Task 与错误

- 创建 task ID 正常、缺失、空白、过长和控制字符；
- 发送前拒绝、发送后断连、超时、无效 JSON 和非可信非 2xx；
- `queued/running/succeeded/failed`、未知状态和任务 ID 不匹配；
- 成功结果缺失、URL 非 HTTPS、userinfo、SSRF、重定向和过期；
- unknown hold、人工恢复/拒绝、到期释放和 exposure 全部幂等；
- 轮询合同违例可在后续合法响应恢复，不被提前退款。

### 3.4 素材

- `/assets` 创建、Pending/Processing/Active/Failed、更新和删除；
- `upstream_id` 优先、缺失时 uuid fallback，以及客户永不看到两者；
- 所有者、App、publication、implementation、channel、凭据指纹和 profile 围栏；
- Key/Base URL 轮换后旧 binding 失败关闭；
- general 图片可用，real_person、音频/视频素材对当前 SKU 拒绝；
- Ark binding、JoyCreator ID 和当前 relay binding 不互换；
- 多素材共同候选和发送前二次校验。

### 3.5 计费与对账

- 预扣上界存在、越界、余额不足和 quota saturation；
- 模型时长只接受 `4..15/-1`，`-1` 按 15 秒预扣，且不能用全局 3600 秒上限替代模型校验；
- 可信 usage 与缺失/字符串/负数/超大 token；
- 成功结算、失败退款、unknown 保留、到期释放与 exposure；
- 捕获 `X-Oneapi-Request-Id`，不误用客户端 request ID；
- Provider 对账 pending/success/failed/404/401/403 与退避；
- 模型 Key 不能调用账户接口，集成 Token 不能发往模型接口；
- `charged_quota/charged_yuan` 不覆盖 NEWAPI 客户 Log；
- 同一 request ID 重复对账幂等，敏感 Token 和响应 body 不落库。

## 4. 真实 Provider 验收

使用目标生产域名、目标模型 Key、独立集成 Token 和隔离测试账号完成：

1. 模型权限、证书、创建与查询路径；
2. 文生、首帧、首尾帧、参考图和所有边界时长/比例/分辨率；
3. 显式 `generate_audio=false/true`，以及 watermark 是否准备发布；
4. 创建和每次轮询的完整脱敏响应 schema、请求 ID 和状态延迟；
5. 成功结果 URL、下载鉴权、Range、有效期、同源和跳转；
6. `/assets` 归属、状态、引用、Key 轮换、删除和多素材；
7. 余额不足、限流、无权限、非法字段和 Provider 失败；
8. 终态 usage 与 `/usage-records` 的 token、金额、状态和时间一致性；
9. 失败是否扣费、重复请求是否重复扣费、create unknown 是否可唯一关联；
10. 客户消费日志、退款、Provider 对账和 exposure 的分账结果。

## 5. 发布不变量

1. V2 模型通过不代表历史 Ark 模型通过。
2. 官方营销描述、价格表和示例不能代替字段与账单黑盒。
3. 任一未决默认值、结果、usage 或素材作用域保持未发布。
4. 代码注册、渠道启用、publication 和生产开放是四个不同阶段。
5. 发布门禁不触碰 NEWAPI 原生 OpenAI Videos 路径与语义。
