# 客户合同管理总览实施计划

## 1. 目标与范围

在管理员侧边栏增加“客户合同”，提供全部已建立客户模型合同的分页总览、状态摘要、检索筛选和现有合同
编辑器入口。实施必须保持一个合同只属于一个 User ID、只有一个权威保存接口、未配置模型不可见不可调
用，以及原生用户逻辑不变。

设计依据：

- [客户合同管理总览设计](../80-dev/2026-08-18-客户合同管理总览设计.md)
- [用户模型合同定价](../10-product/用户模型合同定价.md)
- [用户模型合同定价架构](../20-architecture/用户模型合同定价架构.md)
- [用户模型合同管理界面](../90-ui-ux/用户模型合同管理界面.md)

## 2. 完成定义

- [x] 管理员菜单和 `/admin/customer-contracts` 路由可用，普通用户失败关闭。
- [x] 聚合接口只返回已建立合同且当前管理员可管理的未删除用户。
- [x] 总览提供全部、生效、零权限、停用四项摘要。
- [x] 列表支持客户/公开模型关键词和合同状态筛选，并使用服务端分页。
- [x] 列表显示规则数、不可履约规则数、版本和最近修改信息。
- [x] 行操作复用现有 `UserContractDrawer`，保存后刷新总览。
- [x] 没有新增合同写接口、批量写入、计费分支或第二套合同状态。
- [x] 本批次要求的后端、前端、i18n、文档验证通过。
- [x] 未完成的真实数据库、真实账单和灰度事项没有被误写为生产完成。

## 5. API 与数据测试矩阵

| 场景 | 预期 |
| --- | --- |
| 原生用户 `version=0` | 不返回 |
| 生效且有规则 | `active` |
| 生效且零规则 | `zero_access` |
| 停用且保留规则 | `inactive` |
| 已软删除用户 | 不返回 |
| Admin 查询普通用户合同 | 返回 |
| Admin 查询管理员/Root 合同 | 不返回 |
| Root 查询合同 | 沿用既有 Root 管理语义 |
| 搜索 User ID/用户名/显示名 | 精确或模糊命中 |
| 搜索公开模型 | 通过规则存在性命中且不重复用户 |
| 状态筛选 | total 与 items 一致，summary 不改变 |
| 当前版本审计存在 | 返回管理员与修改时间 |
| 某规则当前不可履约 | `unavailable_rule_count` 增加 |
| 非法状态 | 400，不静默忽略 |

## 6. 前端测试矩阵

| 场景 | 预期 |
| --- | --- |
| 初次加载 | 显示摘要和合同列表 |
| 生效/零权限/停用 | 徽章文案与颜色语义正确 |
| 搜索或筛选 | URL 与请求参数同步，页码回到 1 |
| 空数据 | 显示“尚无客户合同” |
| 筛选无结果 | 显示调整搜索或筛选提示 |
| 列表读取失败 | toast 提示，不展示伪造旧结果 |
| 点击管理合同 | 打开目标用户现有合同抽屉 |
| 抽屉保存关闭 | 当前列表与摘要重新请求 |
| 普通用户路由 | 重定向 403 |
| 移动端 | 使用卡片布局且操作可触达 |

## 7. 最小入侵复核

| 原生文件 | 允许改动 | 禁止扩张 |
| --- | --- | --- |
| `router/api-router.go` | 一条 GET 路由 | 不重排既有路由 |
| `use-sidebar-data.ts` | 一个菜单项和图标 import | 不重构整个导航 |
| `use-sidebar-config.ts` | 一个映射项 | 不改变模块开关解析 |
| `user-contract-drawer.tsx` | 可选的成功回调 | 不复制或改变保存语义 |

合同 middleware、distributor、relay/helper、quota、Task 结算、模型发现和价格投影均不应因本功能发生修改。

## 8. 发布与回滚

- 本次数据库无 schema 迁移。
- 若总览接口异常，可回滚新增菜单、路由和新增文件；原有用户行操作合同入口仍然可用。
- 不通过 feature flag 维持两套页面；回滚只撤销聚合入口，不改合同事实。
- 发布前需用管理员和 Root 分别走查权限，检查一份生效、一份零权限和一份停用合同。

## 9. 真实环境剩余验证

以下项目不能由本地自动化测试替代：

- MySQL、PostgreSQL 真实数据量下的查询计划与响应时间；
- 管理员真实浏览器会话的桌面、移动端视觉走查；
- 生产合同数量下唯一渠道组数量对可用性计算的影响；
- 灰度发布后的真实账单和运维反馈。
