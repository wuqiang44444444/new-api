# 超级管理员请求与响应原文查看方案

## 问题与目标

错误日志与任务详情默认展示脱敏内容，超级管理员可点击“查看原文”，按需查看已保存的请求与响应业务正文。
本方案已完成本地实现，待页面与部署验收；“原文”指受保护证据正文，认证凭据仍保持移除，不承诺恢复未经任何处理的传输字节。

## 实施前情况（分析基线）

- 错误日志 `http_exchange` 保存前以占位符替换敏感字段，超限正文不保存；无法从该快照恢复原文。
- 请求证据已有私有加密存储、Root 专用对象下载接口和访问审计；凭据在采集时移除，签名 URL 可保留在受保护正文中。
- 任务详情已有 Root 请求正文查看入口；错误日志目前仅对没有 HTTP 快照的部分任务失败事件展示证据入口。
- 当前 Root 证据预览跳过 URL 遮盖，却记录为 `view/redacted`；下载还会额外产生该预览记录。审计写入失败目前仅记系统错误，不阻止正文返回。
- 当前页面已分别传递任务或请求 ID，不存在已确认的双 ID 交集缺陷；关联优先级需要继续保持。证据采集尚未覆盖所有接口，历史未保存内容不可补回。

## 优化方案

1. **共用查看入口**：有有效关联 ID 即提供“请求证据”入口，展开后查索引，不按事件类型猜测正文是否存在；事件有正文且未过期时，仅 Root 显示“查看原文”，注明“认证凭据已移除”。两个页面复用弹窗，区分客户请求、上游请求、上游响应、网关响应及轮询事件；多次事件分别展示，二进制提供下载，无记录时明确提示。
2. **默认脱敏、点击返回原文**：取消 `service/task_request_evidence_helpers.go` 中 `evidencePreviewText` 的 Root 免遮盖分支，默认预览对所有角色遮盖 URL，保留 Root 专属诊断元数据。服务端可以读取对象生成脱敏预览，但点击前不得向浏览器返回未遮盖正文；点击后通过独立 Root 查看接口读取，复用解密、完整性校验和下载读取服务，不向错误日志或 Task 复制正文。
3. **权限与审计**：原文查看与下载由 `RootAuth()` 保护。在实际操作入口分别记录脱敏预览 `view/redacted`、原文查看 `view/original`、下载 `download/original`，移除共用加载函数中的无条件预览审计，审计不含正文。本次沿用尽力写入、失败记系统错误的语义，不宣称审计必然落库，也不改写历史记录。
4. **关联规则**：任务失败优先按 `task_id` 查询，无任务 ID 时按 `request_id`；普通请求错误按 `request_id`。已有脱敏 HTTP 快照不阻止查看关联证据，不把两个 ID 作为交集条件。
5. **缺失与覆盖边界**：明确展示未记录、过期、不完整及读取失败，不用当前配置重建历史请求。先完成已有证据的查看；未接入入口的采集作为后续工作，仍复用证据存储，保持错误诊断非阻断语义，采集失败不得改变业务结果。
6. **缓存与清理**：整个证据路由组接入 `middleware.DisableCache()`，覆盖列表、预览、新查看与既有下载接口。前端不持久化原文；关闭弹窗、切换记录时解除原文查询订阅并清除数据，取消在途请求或丢弃迟到结果；退出登录复用 `queryClient.clear()`。不能仅凭 `gcTime: 0` 判定清理完成。

实现限定在既有证据查询服务、错误日志和任务详情组件，必要路由仅做窄接线；不新增平行日志体系。
新增文案仅维护简体中文与英文。

验收：普通管理员直接调用原文接口被拒绝；Root 点击前不返回未遮盖正文；三类操作的审计标签准确且不重复，
审计失败按约定告警；所有证据响应禁止缓存。两个页面读取同一事件的同一份证据；覆盖入口显隐、缺失、过期、
不完整、读取失败，以及关闭、切换、退出后在途请求完成仍不保留原文的回归。实施时运行相关后端、
前端专项检查；文档运行 `task docs:check` 与 `task ai:check`。本地回归不代表页面或生产验收。

权威边界：[硬约束](../00-context/硬约束.md) §6、[音视频请求证据架构](../20-architecture/音视频请求证据架构.md)。


## 实施与验证（2026-09-29）

- 已统一默认脱敏预览，新增 Root 原文查看接口，与下载共享读取校验；修正访问审计标签及重复记录，证据路由组统一禁缓存。
- 错误日志与任务详情共用原文弹窗；旧任务请求快捷入口改用查看接口。原文查询绑定登录身份，关闭、切换或退出时取消并清除，迟到结果丢弃；中英文入口均有交互回归。
- NEWAPI 原生 `router/api-router.go` 仅将既有证据路由块替换为注册调用；权限与禁缓存接线集中在新增专属路由文件，未来上游同步只需保留该单行入口。其余实现限定在本地证据与日志界面扩展，不修改采集、Task 状态、资金或数据库结构。
- 已通过：`go test ./controller ./service ./router -run 'Test.*Evidence' -count=1`、`go build ./...`；前端四个相关测试文件共 66 项、`bun run typecheck`、涉及文件 lint 与格式检查、`bun run build`（含文档及品牌产物校验）、`task docs:check`、`task ai:check`。
- 评审修复：任务原文入口的列表、详情请求取消后不再弹出全局错误；真正失败仍在弹窗内提示并支持重试。新增经过真实 HTTP 拦截器的取消与重试回归，前端五个相关测试文件共 70 项、类型及涉及文件 lint/格式检查通过。
- 页面人工验收、部署与真实历史对象读取验收待完成；未接入入口的后续采集不在本次范围，未保存正文不可恢复。本地测试不代表生产已发布。

## 代码评审修复（2026-09-29）

- 默认预览按 JSON、表单、multipart、SSE 格式解码后遮盖 URL，再执行有界截取；支持协议头大小写、
  JSON 转义与表单编码，不把解析失败的正文作为原文回退。JSON 数字保持原精度；multipart 文件正文
  不解释为文本，继续由 Root 下载原始对象。新逻辑集中在本地证据预览文件，不更改采集与存储内容。
- 真实详情 handler 回归覆盖管理员与 Root 默认预览，随后读取原文查看/下载接口并逐字节核对原始内容；
  覆盖异常 URL、损坏结构明确失败、签名不泄漏和数字标识精度。正常读取不改写对象或完整性摘要。
- 证据列表数据库错误不再表示“未记录”：计数与列表查询错误显式返回，页面显示现有加载失败文案与
  重试入口；回归验证故障恢复及真正空列表。未新增日志体系、权限分支或兼容查询路径。
- 修复用例已先复现旧行为，再通过对应定向回归。页面人工验收、部署及真实历史对象读取仍待完成。
- 最终验证通过：`go test ./model ./controller ./service ./router -count=1`、`go build ./...`；
  前端七个相关测试文件共 77 项、`bun run typecheck`、改动文件 lint/格式检查、`bun run build`
  （含文档和品牌产物校验）；`task docs:check`、`task ai:check`。
