# Vidu 八型号实测与历史预扣对账

2026-09-28 经用户明确授权，对国内和海外各四个模型各创建一次真实视频任务，共八次，无重发。
请求均为 4 秒、480p、16:9、5 张不同参考图、1 条参考音频，generate_audio=true、watermark=false。
八条均 SUCCESS / settled，创建 attempt 均 complete / transferred，创建与差额日志均已交付。
测试 Token 185 已停用；旧 Token 184 保持停用。渠道 139/140 保持启用。监控完成后已暂停心跳。

数据库副本重复操作验证余额和账单不再次变化；冻结 execution、协议、连接、请求、价格均一致。
线上 Root 二次验证接口没有被绕过或修改；本次为停服、备份、审计的独立离线维护。

运维备份位于本机 `/tmp/vidu-history-cn-before-20260928.db` 和
`/tmp/vidu-history-global-before-20260928.db`，权限 0600，含敏感生产式配置，不应提交仓库或公开。
