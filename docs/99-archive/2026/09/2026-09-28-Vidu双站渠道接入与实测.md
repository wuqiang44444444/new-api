# Vidu 双站渠道接入与实测

本文记录首轮真实测试时点。后续专用协议修复、合同选择器和本地渠道恢复启用见
[Vidu 协议适配与合同覆盖修复](2026-09-28-Vidu协议适配与合同覆盖修复.md)；旧任务预扣已在后续授权中完成对账，见[历史预扣对账](2026-09-28-Vidu八型号实测与历史预扣对账.md)。

## 问题与目标

按用户授权，在本机正在运行的网关数据库新增国内、海外 Vidu Drama 两个 Seedance 专用渠道，
价格复制现有官方 Seedance 对应模型，执行真实图片＋参考音频测试并交付视频。
本次操作对象为本地 `one-api.db`、`http://127.0.0.1:3501`，不是对公网生产部署的操作确认。
渠道及价格通过运行中服务的管理接口调用现有数据库事务完成，保留管理校验与审计。
没有修改业务代码，没有向原生 Ability 写入 Seedance 路由。

### 请求与素材

实际各提交一次 2.0 std；2.5/fast/mini 完成配置但未消耗额度生成，不标为实测通过。

- 国内客户模型：`seedance-2-0-vidu-cn`，上游 `viduq3-drama-std`。
- 海外客户模型：`seedance-2-0-vidu-global`，上游 `viduq3-drama-ab-std`。
- 北向：`POST /api/v3/contents/generations/tasks`。
- `content`：文字＋一张 `reference_image`＋一段 `reference_audio`，没有参考视频。
- 参数：`duration=5`、`resolution=720p`、`ratio=16:9`、`generate_audio=true`、`watermark=false`。
- 提示词：参考果茶产品外观，镜头缓慢推进，水汽及冰块闪光，以参考音频作为背景音乐。
- 采用[火山官方 API Explorer](https://api.volcengine.com/api-explorer/?action=CreateContentsGenerationsTasks&serviceCode=ark&version=2024-01-01)
  的公开果茶图片与音频示例，图片 416,179 bytes，音频约 11.107 秒、275,734 bytes；素材公网读取 HTTP 200。
- 独立临时测试 Token 184 仅允许八个测试模型，额度上限 15,000,000 quota，24 小时到期；
  使用本机管理员账户已有余额，没有注资或修改钱包数值。

### 网关验证结果

两次创建均 HTTP 200，创建 attempt 为 `complete`，hold 原子转移为 `transferred`；
Task 行 3851（国内）和 3852（海外）进入 `RECONCILIATION_REQUIRED`，`billing_state=pending`。
每条预扣 3,157,396 quota，合计 6,314,792 quota，约 USD 12.629584 / CNY 85.376。
这笔金额是预扣，不能写成最终消费；没有手工改余额、伪造成功状态或改冻结协议。

真实上游 `id` 与创建 ID 逐字符一致，报错 `ModelArk task id mismatch` 实际来自
`decodeOfficialPluginObservation` 将整个结构解码错误合并为身份错误。
数值字段 `seed`、`duration`、`created_at`、`updated_at`、`frames_per_second` 均为 JSON 字符串；
当前 `responseTask` 要求相应数值字段为 Go 整数，因而解码失败。
成功用量中的 `prompt_tokens`、`completion_tokens`、`total_tokens` 也为字符串，
当前官方用量规范明确不把字符串视为可信整数证据；仅修改 duration 不足以解决结算。

相关代码：[查询解码](../../../../relay/channel/task/seedance/plugin_official_video.go)、
[响应类型](../../../../relay/channel/task/seedance/adaptor.go)、
[严格官方用量](../../../../relay/channel/task/seedance/official_usage.go)。

## 优化方案

1. 保留新建两个渠道及八项价格，保持停用直到适配完成；原生普通 Vidu v2 渠道不是替代路径。
2. 登记 Vidu 专用响应合同：有界、严格十进制字符串转整数，覆盖任务字段和可信 usage，
   仍校验创建/查询 ID，保持现有火山/BytePlus 的严格整数语义。
3. 补齐精确模型元数据，验证 4K、2.5/fast/mini、失败语义及两站完整生命周期。
4. 已冻结的两条 Task 不得直接修改成新协议。恢复／退款须走既有受审计资金入口；
   `RefundVideoFunds` 要求管理员会话绑定的安全验证，PAT 不能代替。
5. 原始文档与真实观察分开，收敛时以本次响应事实修正“仅配置即可上线”的推断。
