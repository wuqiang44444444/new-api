# I3 与 V1 修复后真实渠道定向复验

## 问题与目标

按[原冒烟方案](../70-research/2026-11-06-本地真实渠道端到端冒烟测试方案.md)复验
[上轮发现的两项问题](../99-archive/2026/11/2026-11-08-本地真实渠道端到端冒烟重跑结果.md)。本轮仅验收修复后新产生的
I3 旧 Token 定价异步图片和 V1 Seedance Mini 4 秒视频，分别核对图片账单和视频客户、管理员日志。

## 当前实际情况

**I3 和 V1 的新记录均通过定向复验。** 2026-11-08 晚间（Asia/Shanghai），在提交
`8bd9eb2c61411bfd54da96ab672a48cf93b42c6a` 上叠加本次六个账单和日志修复文件，
构建 Go 服务与生产前端。独立实例运行于 3519，采用主库只读一致性备份生成的空业务 SQLite 副本，
日志同库、Redis 关闭。钱包和有限额 Key 各 2,500,000 quota（$5），仅保留渠道 57 和 139，
串行提交一笔真实图片和一笔真实视频。视频使用纯文本提示。价格与倍率来自副本现有配置。

| 用例 | 真实结果 | 账单或权限核对 |
| --- | --- | --- |
| I3 `gpt-image-2` 旧 Token 定价 | `Prefer: respond-async` 返回 202 和 Location，同键同请求复用原 ID，改请求体同键返回 409。真实 1024×1024 PNG 可预览，制品下载与查询结果逐字节一致 | 19 输入、196 输出 Token，冻结单价分别为 $5 和 $30 每百万 Token。预扣 32，补扣 2,956，净扣 **2,988 quota（$0.005976）**。钱包、Key、唯一消费日志、账单 API 和 Chrome 任务详情一致。中文账单为「按 Token 计费」，英文为 “Token billing”，Token 明细筛选命中同一笔 |
| V1 `seedance-2-0-mini-vidu-cn` | 一次 POST 返回 200，明确请求 4 秒、480p、16:9、无音频。冻结时长、真实 Mini 映射和协议核对匹配。约 89 秒观察到主视频 `ready` | 客户和管理员在各自会话核对同一笔消费和退款。客户 API 与 Chrome 详情均隐藏南向模型，管理员 API 与 Chrome「实际模型」均与冻结映射匹配。关联依据为消费日志请求 ID 和退款详情的公开 Task ID |

V1 视频为 864×496、24 fps、97 帧，无音轨。媒体探测与 Chrome 实测均为 4.041667 秒，
Chrome 实际播放至结束并能回拖。网关授权 GET/HEAD 均为 302，对象存储 Range GET 返回 206，
HEAD 返回 200。V1 预扣 932,249 quota，按实际报告的 40,594 Token 结算为 69,058 quota，
退差额 863,191 quota。两笔合计净扣 **72,046 quota（$0.144092）**，与钱包、Key 和账单一致。
