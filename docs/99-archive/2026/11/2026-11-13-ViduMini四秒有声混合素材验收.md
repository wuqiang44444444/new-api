# Vidu Mini 四秒有声混合素材验收

## 1. 问题与目标

在 Vidu Mini 真实线路上验收一条 4 秒、有声、同时引用图片、音频和视频的 ModelArk V3 请求。
验收覆盖本站托管引用与直接 URL 在同一请求中的履约，以及下载成片后的音轨检测。

## 2. 当前实际情况

验收使用隔离 PostgreSQL、专用测试 Key、Vidu Mini 和真实 Azure Blob。客户模型为 `seedance-2-0-mini-v`。
Vidu 的本站托管能力覆盖图片。音频和视频通过生成合同的直接 URL 输入。
[Seedance V 视频合同](../../../../web/public/docs-content/zh/api-reference/videos/seedance-v.md)

| 输入 | 类型与角色 | 地址形式 |
| --- | --- | --- |
| PNG 图片 | `image_url` / `reference_image` | 通过 `POST /v1/assets` 创建的 `asset://fhas_*` |
| MP3 音频 | `audio_url` / `reference_audio` | 直接 HTTPS URL，测试客户端提供 Azure Blob 临时地址 |
| MP4 视频 | `video_url` / `reference_video` | 直接 HTTPS URL，测试客户端提供 Azure Blob 临时地址 |

提交参数为 `duration=4`、`resolution=480p`、`ratio=adaptive`、`generate_audio=true`。
图片创建返回 HTTP 201 和 `ready`。生成请求返回 HTTP 200 并建立任务。

## 3. 优化方案

沿用已登记输入组合和现有视频结果交付。等待任务终态与 `delivery_status=ready`，下载成片，
以 FFprobe 检查时长、视频流和音轨，以 FFmpeg 统计音轨电平。按任务结算与资金流水复核本次收费。

## 4. 混合请求结果

- 真实任务成功，`delivery_status=ready`。下载的 MP4 有 864 × 496 H.264 视频流及双声道 AAC 音轨。
  视频流为 4.042 秒，容器和音轨为 4.096 秒。
- FFmpeg 测得音轨平均电平 −22.4 dBFS，峰值 −8.4 dBFS。成片有非静音音轨。
- 客户侧返回 90,814 completion tokens，结算为 94,880 quota。供应商账单未核对。

## 5. 音频和视频托管引用复验

为验证三种媒体均使用 `asset://fhas_*` 的请求，使用 Go 构建覆盖为当前 Vidu Mini 映射增加 MP3 和 MP4，
并运行另一个隔离网关和独立测试数据库。此覆盖仅用于真实验收。

- 初次素材创建遇到源文件网络超时。复验时通过 `POST /v1/assets` 分别创建 PNG、MP3 和 MP4，
  三项均返回 HTTP 201、`ready` 和 `asset://fhas_*`。把三条引用分别放入图片、音频和视频的对应槽位。
- Vidu Mini 以相同的 4 秒、480p、`generate_audio=true` 参数生成成功，交付状态为 `ready`。
  任务快照记录三个对应类型的托管对象，未持久化临时签名 URL。
- 成片含 864 × 496 H.264 视频流和双声道 AAC。视频流 4.042 秒，音轨及容器 4.096 秒。
  音轨平均电平 −24.8 dBFS，峰值 −10.9 dBFS。客户侧用量为 90,814 completion tokens，结算 94,880 quota，
  与混合请求一致。

供应商账单与生产发布仍待验收。
