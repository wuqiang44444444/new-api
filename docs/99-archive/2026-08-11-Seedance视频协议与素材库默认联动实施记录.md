# Seedance 视频协议与素材库默认联动实施记录

> 本文记录 2026-08-11 的管理端联动、国内火山素材协议接线和验证结果。它不代表真实 Provider
> 凭据、权益、账单和灰度验收已经完成，不能据此声明生产发布。

## 1. 问题与结论

原管理表单把视频协议与素材协议作为两个互不关联的技术枚举展示。管理员需要自行理解协议名称、判断
配对关系，而且国内火山视频只能选择 `none`，与火山方舟已经提供 Assets API 的事实不符。

本次改为由代码化 `video_upstream_protocol` 提供素材库默认值，并只展示兼容选项：

| 视频线路 | 视频协议 | 默认素材协议 | 可手动修改 |
| --- | --- | --- | --- |
| 国内火山方舟官方 | `modelark_v3_volcengine` | `volcengine_assets_action_v2024_01_01` | 可改为 `none` |
| 海外 BytePlus 官方 | `modelark_v3_byteplus` | `byteplus_assets_action_v2024_01_01` | 可改为 `none` |
| 墨行 | `media_task_v1` | `relay_assets_v1` | 可改为 `none` |
| Ark 反代 | `ark_media_v1` | `ark_assets_v1` | 可改为 `none` |
| 飞彩 | `media_arrays_v2` | `none` | 仅 `none` |
| FunCloud | `funcloud_seedance_v2` | `none` | 仅 `none` |

这里的联动只读取管理员明确选择的代码协议，不根据客户模型名、Provider 模型名或价格推断能力。

## 2. 管理端行为

新建 Seedance 专用渠道时默认选择国内火山方舟视频与官方素材库，素材 URL 最低有效期默认 3600 秒，
Region 固定为 `cn-beijing`。管理员切换视频协议时，表单立即切换到对应默认素材库；随后可以手动选择
“不启用素材协议”。

素材下拉框不再展示不兼容线路。例如选择国内火山时只显示“火山方舟官方素材库”和“不启用素材协议”，
不会出现 BytePlus、墨行或 Ark 素材库。已有渠道打开编辑页时保留已保存配置，不因页面加载自动改写。

协议名称继续由 i18n 翻译为业务可理解名称；“墨行 / TokenSave”在视频协议选项中直接显示“墨行”。
视频和素材下拉框扩大到桌面端 36rem 的菜单最小宽度，触发框最大宽度扩大到 2xl，并保留移动端视口上限。

## 3. 国内火山官方素材协议

新增独立协议 `volcengine_assets_action_v2024_01_01`，固定使用：

```text
Host: https://ark.cn-beijing.volces.com
Region: cn-beijing
Service: ark
Version: 2024-01-01
Credential: 独立素材 AK/SK
Scope: Channel + 协议 + Host + Project + Region
```

国内协议与 BytePlus 协议共享代码化 Action 请求/响应实现，但不共享协议标识、Host、账号作用域或素材
资源。素材凭据仍使用独立的只写存储，不与视频 Bearer API Key 拼接或返回前端。

火山方舟官方文档已经提供[创建素材资产（CreateAsset）](https://www.volcengine.com/docs/82379/2318271?lang=zh)，
Action API 的公开示例使用 `2024-01-01`、`cn-beijing`、`ark` 和
`ark.cn-beijing.volces.com`。Seedance 2.0 权益说明也明确包含 Assets API、素材资产和素材组流程。

## 4. 前后端门禁

- 前端只提供默认配对和 `none`，并在切换官方线路时清理另一账号的草稿 AK/SK、Project 和 Region；
- 国内火山官方素材必须配对 `modelark_v3_volcengine`，Region 必须为 `cn-beijing`；
- BytePlus 官方素材必须配对 `modelark_v3_byteplus`，Region 使用合法 Provider Region ID；
- 墨行与 Ark 素材协议仍分别只允许配对各自视频协议；
- 后端继续作为最终权威校验，绕过前端提交错误配对仍会被拒绝；
- 复制使用官方素材的 Seedance 渠道时清空素材协议和账号字段，不复制独立素材凭据。

## 5. 验证范围与剩余门禁

本次代码验证覆盖：协议枚举、传输 profile、国内 Host、Region 和配对校验、独立凭据提交、下拉默认映射、
兼容选项过滤、连通性按钮资格、七语言同步、前端类型检查与构建，以及 `relaykit` 独立构建。

上线前仍需使用真实国内火山账号逐项验证 Create/Get/Update/Delete Asset、AssetGroup、列表、真人流程、
URL TTL、权限拒绝、错误码、资源在视频请求中的解析、账单和审计脱敏。任何一项未通过时应保持渠道禁用，
不得回退到 BytePlus Host、跨渠道迁移素材或自动切换素材库。
