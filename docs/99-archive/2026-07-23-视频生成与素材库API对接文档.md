# 视频生成与素材库 API 对接文档

> 本文描述当前代码已经实现的北向接口合同，供客户端、SDK 和业务系统对接。
> OpenAI Videos Core 与 ModelArk `/api/v3` 的真实 Provider 全生命周期矩阵仍需在具备正式凭证的环境验收，因此不得据此宣称“完整兼容所有 Provider”。

## 1. 如何选择接口

| 使用场景 | 推荐协议 | 创建接口 |
| --- | --- | --- |
| 新的通用视频应用、OpenAI 风格 SDK | OpenAI Videos Core | `POST /v1/videos` |
| 字节 Seedance / ModelArk 原生客户 | ModelArk Video v3 | `POST /api/v3/contents/generations/tasks` |
| 已接入平台旧视频协议的存量客户 | 平台兼容协议 | `POST /v1/video/generations` |
| 需要长期复用服务商素材 | 平台素材扩展 | `POST /v1/assets` |
| 真人参考图 | 真人授权 + 平台素材扩展 | `POST /v1/real-person-authorizations` |

新项目优先使用 OpenAI Videos 或 ModelArk v3。`/v1/video/generations`、Kling 和即梦入口属于存量兼容接口，不作为新 SDK 的统一合同。

## 2. 通用约定

### 2.1 基础地址和认证

示例：

```text
Base URL: https://api.example.com
Authorization: Bearer sk-xxxxxxxx
```

除真人同意页面外，本文 API 均使用 Bearer Token：

```http
Authorization: Bearer <API_TOKEN>
```

客户端只能访问当前 Token 所属用户的任务、素材和授权。跨用户访问统一按资源不存在处理，不能依靠 ID 枚举其他用户的数据。

### 2.2 内容类型

- JSON 请求：`Content-Type: application/json`
- OpenAI 图片文件参考：`multipart/form-data`
- 视频内容下载：二进制流，可能返回 `200` 或带 Range 的 `206`

### 2.3 ID 和时间

| 类型 | 格式 |
| --- | --- |
| 视频任务 ID | `task_...` |
| 素材 ID | `ast_` 加 32 位字母或数字 |
| 素材绑定 ID | `ab_...` |
| 真人授权 ID | 服务端生成的公开 ID |
| 时间字段 | Unix 秒 |

上游任务 ID、上游素材 ID、渠道 ID 和渠道密钥不会返回给客户端。

### 2.4 幂等

以下创建接口支持 `Idempotency-Key`：

- `POST /v1/videos`
- `POST /v1/videos/{video_id}/remix`
- `POST /api/v3/contents/generations/tasks`
- `POST /v1/assets`
- `POST /v1/assets/{asset_id}/migrations`

建议每次业务操作生成一个随机 Key：

```http
Idempotency-Key: 7f732ea8-7b48-4ac2-b0fd-f3e8893f509e
```

规则：

- 相同 Key、相同请求：返回原任务或原素材；
- 相同 Key、不同请求：返回 `409 idempotency_conflict`；
- 视频和素材创建幂等记录有效期为 24 小时；
- 网络超时时必须复用原 Key，不能立即换 Key 重建。

### 2.5 推荐轮询策略

视频和素材都是异步任务：

1. 第一次等待 2 秒；
2. 随后按 5 秒、10 秒轮询；
3. 最长间隔控制在 15 秒；
4. 收到 `429`、`502` 或 `503` 时使用指数退避；
5. 到达业务超时后停止前台轮询，但不要把本地超时当作服务端失败。

### 3.2 ModelArk Video v3

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `POST` | `/api/v3/contents/generations/tasks` | 创建任务 |

| `DELETE` | `/api/v3/contents/generations/tasks/{task_id}` | 取消排队任务或删除终态任务 |
| `GET` | `/v1/videos/{task_id}/content` | 下载视频或尾帧 |

### 3.3 平台素材扩展

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `POST` | `/v1/assets` | 从公网 HTTPS URL 创建素材 |
| `GET` | `/v1/assets` | 查询素材列表 |
| `GET` | `/v1/assets/{asset_id}` | 查询素材 |
| `PATCH` | `/v1/assets/{asset_id}` | 修改素材名称 |
| `DELETE` | `/v1/assets/{asset_id}` | 删除素材 |
| `GET` | `/v1/assets/{asset_id}/bindings` | 查询素材绑定 |
| `POST` | `/v1/assets/{asset_id}/migrations` | 用新 URL 或新渠道迁移素材 |
| `POST` | `/v1/real-person-authorizations` | 创建真人素材授权 |
| `GET` | `/v1/real-person-authorizations/{id}` | 查询并刷新授权状态 |

| `POST` | `/v1/real-person-authorizations/{id}/revoke` | 撤回授权 |

平台没有素材二进制上传、下载和“后绑定”接口。以下路径不提供：

```text
POST /v1/assets/{asset_id}/complete
GET  /v1/assets/{asset_id}/content
POST /v1/assets/{asset_id}/bindings
```

## 4. OpenAI Videos Core

### 4.1 创建视频

```http
POST /v1/videos
```

JSON 示例：

```bash
curl -sS -X POST "$API_BASE/v1/videos" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: $REQUEST_ID" \
  -d '{
    "model": "sora-2",
    "prompt": "A paper boat moving through a rainy miniature city",
    "seconds": "4",
    "size": "720x1280"
  }'
```

请求字段：

| 字段 | 必填 | 当前合同 |
| --- | --- | --- |
| `model` | 是 | 必须是 Token 和渠道允许的视频模型 |
| `prompt` | 是 | 去除首尾空白后不能为空，最长 32000 个字符 |
| `seconds` | 否 | 字符串；允许 `"4"`、`"8"`、`"12"`，默认 `"4"` |
| `size` | 否 | `720x1280`、`1280x720`、`1024x1792`、`1792x1024`，默认 `720x1280` |
| `input_reference` | 否 | 图片参考，只能提供 `file_id` 或 `image_url` 其中一个 |

模型还可能收紧尺寸：

- `sora-2`：`720x1280`、`1280x720`
- `sora-2-pro`：支持上表四种尺寸
- 其他模型：以对应 Provider 的能力为准；适配器可能返回更具体的参数错误

#### 使用图片 URL

```json
{
  "model": "sora-2",
  "prompt": "Animate the reference image",
  "seconds": "4",
  "size": "1280x720",
  "input_reference": {
    "image_url": "https://cdn.example.com/reference.png"
  }
}
```

`image_url` 可使用：

- `http://` 或 `https://` URL；
- `data:` URL；
- 平台素材扩展 `asset://ast_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`。

平台素材引用必须属于当前用户、状态为 `ready`、绑定模型与本次 `model` 一致，并且所有引用素材必须共享同一个可用渠道。

#### 使用文件

文件方式使用 `multipart/form-data`，单个文件最大 20 MiB：

```bash
curl -sS -X POST "$API_BASE/v1/videos" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Idempotency-Key: $REQUEST_ID" \
  -F "model=sora-2" \
  -F "prompt=Animate the reference image" \
  -F "seconds=4" \
  -F "size=1280x720" \
  -F "input_reference=@reference.png"
```

#### 创建响应

成功返回 HTTP `200`：

```json
{
  "id": "task_xxx",
  "object": "video",
  "model": "sora-2",
  "status": "queued",
  "progress": 0,
  "created_at": 1784778000,
  "prompt": "A paper boat moving through a rainy miniature city",
  "seconds": "4",
  "size": "720x1280"
}
```

### 4.2 查询视频

```http
GET /v1/videos/{task_id}
```

```bash
curl -sS "$API_BASE/v1/videos/$VIDEO_ID" \
  -H "Authorization: Bearer $TOKEN"
```

状态：

| `status` | 含义 | 是否继续轮询 |
| --- | --- | --- |
| `queued` | 等待执行 | 是 |
| `in_progress` | 正在生成 | 是 |
| `completed` | 已完成 | 否 |
| `failed` | 失败、取消、过期或结果不确定 | 否，查看 `error.code` |

失败示例：

```json
{
  "id": "task_xxx",
  "object": "video",
  "model": "sora-2",
  "status": "failed",
  "progress": 30,
  "created_at": 1784778000,
  "completed_at": 1784778060,
  "error": {
    "code": "video_generation_failed",
    "message": "Video generation failed"
  }
}
```

### 4.3 查询视频列表

```http
GET /v1/videos?limit=20&order=desc&after=task_xxx
```

| 参数 | 默认值 | 约束 |
| --- | --- | --- |
| `limit` | `20` | 1～100 |
| `order` | `desc` | `asc` 或 `desc` |
| `after` | 无 | 当前用户可见的视频任务 ID |

响应：

```json
{
  "object": "list",
  "data": [],
  "first_id": null,
  "last_id": null,
  "has_more": false
}
```

下一页请求使用本页 `last_id` 作为 `after`。空列表的 `first_id` 和 `last_id` 固定返回 `null`。

### 4.4 下载视频

```http
GET /v1/videos/{task_id}/content
```

```bash
curl -fL "$API_BASE/v1/videos/$VIDEO_ID/content" \
  -H "Authorization: Bearer $TOKEN" \
  -o result.mp4
```

只有 `completed` 状态可以下载。接口支持 `Range`，客户端可续传：

```http
Range: bytes=1048576-
```

如果上游提供了内容过期时间，超过 `expires_at` 后返回 `410 video_content_expired`。

### 4.5 Remix

```http
POST /v1/videos/{video_id}/remix
```

```bash
curl -sS -X POST "$API_BASE/v1/videos/$VIDEO_ID/remix" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: $REMIX_REQUEST_ID" \
  -d '{"prompt":"Keep the scene and change the weather to snow"}'
```

约束：

- 原视频必须属于当前用户；
- 原视频必须由 OpenAI Videos 协议创建且未删除；
- 原 Provider 必须支持 Remix；
- Remix 固定使用原视频的渠道和计费参数；
- 原渠道不可用时不会自动切换到另一个账号。

成功响应与创建视频相同，并包含 `remixed_from_video_id`。

### 4.6 删除视频

```http
DELETE /v1/videos/{task_id}
```

仅 `completed` 或 `failed` 等终态视频可以删除。排队或生成中的任务返回：

```json
{
  "error": {
    "type": "invalid_request_error",
    "code": "video_not_terminal",
    "message": "Only completed or failed videos can be deleted",
    "param": null
  }
}
```

成功：

```json
{
  "id": "task_xxx",
  "deleted": true,
  "object": "video.deleted"
}
```

当前 OpenAI Videos 合同不提供取消运行中任务的独立端点。

## 5. ModelArk Video v3

### 5.1 创建任务

```http
POST /api/v3/contents/generations/tasks
```

文生视频：

```bash
curl -sS -X POST "$API_BASE/api/v3/contents/generations/tasks" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: $REQUEST_ID" \
  -d '{
    "model": "seedance-model",
    "content": [
      {
        "type": "text",
        "text": "雨夜城市中行驶的复古汽车"
      }
    ],
    "duration": 5,
    "resolution": "720p",
    "ratio": "16:9",
    "generate_audio": true,
    "watermark": false
  }'
```

图生视频：

```json
{
  "model": "seedance-model",
  "content": [
    {
      "type": "text",
      "text": "让画面产生自然运镜"
    },
    {
      "type": "image_url",
      "role": "first_frame",
      "image_url": {
        "url": "asset://ast_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
      }
    }
  ],
  "duration": 5,
  "resolution": "720p",
  "ratio": "16:9"
}
```

顶层字段：

| 字段 | 必填 | 当前合同 |
| --- | --- | --- |
| `model` | 是 | 必须由 Token 和 ModelArk 官方视频渠道支持 |
| `content` | 是 | 至少一个内容项 |
| `duration` | 否 | `-1` 或 4～15；`-1` 表示智能时长 |
| `resolution` | 否 | `480p`、`720p`、`1080p`、`4k` |
| `ratio` | 否 | `16:9`、`4:3`、`1:1`、`3:4`、`9:16`、`21:9`、`adaptive` |
| `service_tier` | 否 | `default` 会在不支持该字段的渠道上归一化为省略；`flex` 仅在所选渠道明确允许透传时可用，否则返回 `unsupported_parameter`。当前 Seedance 2.0 渠道不要发送 |
| `generate_audio` | 否 | 布尔值 |
| `watermark` | 否 | 布尔值 |
| `callback_url` | 否 | 当前不支持；提供后返回 `unsupported_parameter` |

`content` 支持：

| `type` | 数据字段 | `role` |
| --- | --- | --- |
| `text` | `text` | 不提供 |
| `image_url` | `image_url.url` | `first_frame`、`last_frame`、`reference_image` |
| `video_url` | `video_url.url` | `reference_video` |
| `audio_url` | `audio_url.url` | `reference_audio` |

媒体 URL 可以是 `http(s)`、`data:` 或平台 `asset://ast_...`。

数量与组合限制：

- 图片最多 9 个；
- 视频最多 3 个；
- 音频最多 3 个；
- `first_frame` 和 `last_frame` 各最多 1 个；
- 使用 `last_frame` 时必须同时提供 `first_frame`；
- 只有音频、没有图片或视频时会被拒绝。

成功返回 HTTP `200`：

```json
{
  "id": "task_xxx"
}
```

### 5.2 查询任务

```http
GET /api/v3/contents/generations/tasks/{task_id}
```

成功示例：

```json
{
  "id": "task_xxx",
  "model": "seedance-model",
  "status": "succeeded",
  "content": {
    "video_url": "https://api.example.com/v1/videos/task_xxx/content",
    "last_frame_url": "https://api.example.com/v1/videos/task_xxx/content?part=last_frame"
  },
  "resolution": "720p",
  "duration": 5,
  "ratio": "16:9",
  "service_tier": "default",
  "created_at": 1784778000,
  "updated_at": 1784778060
}
```

状态：

```text
queued → running → succeeded
                 ↘ failed / cancelled / expired
```

`content.video_url` 和 `content.last_frame_url` 都需要携带相同 Bearer Token 访问。

### 5.3 查询任务列表

```http
GET /api/v3/contents/generations/tasks
```

只返回最近 7 天、当前用户、未删除的 ModelArk v3 任务。

| 参数 | 默认值 | 约束 |
| --- | --- | --- |
| `page_num` | `1` | 1～500 |
| `page_size` | `10` | 1～500 |
| `filter.status` | 无 | `queued`、`running`、`succeeded`、`failed`、`cancelled`、`expired` |
| `filter.task_ids` | 无 | 可重复传入，最多 500 个 |
| `filter.model` | 无 | 精确匹配模型 |
| `filter.service_tier` | `default` | `default` 或 `flex` |

多个任务 ID 示例：

```text
?filter.task_ids=task_a&filter.task_ids=task_b
```

响应：

```json
{
  "total": 2,
  "items": []
}
```

注意：未传 `filter.service_tier` 时默认只查询 `default` 任务；查询 `flex` 任务必须显式传 `filter.service_tier=flex`。

### 5.4 取消或删除

```http
DELETE /api/v3/contents/generations/tasks/{task_id}
```

该接口根据任务状态执行不同操作：

| 当前状态 | 行为 |
| --- | --- |
| `queued` | 请求服务商取消任务；确认取消后结算退款 |
| `running` | 返回 `409 task_running`，不强制取消 |
| `cancelled` | 返回 `409 task_cancelled` |
| `succeeded` / `failed` / `expired` | 删除服务商结果并隐藏本地任务 |

成功返回：

```json
{}
```

取消结果不确定时返回 `503 cancellation_unknown`。客户端应查询原任务状态，不要立即创建重复任务。

## 6. 平台素材扩展

### 6.1 设计边界

素材库只接受 Provider 可以访问的公网 HTTPS URL：

- 平台不接收素材二进制；
- 平台不会主动 GET 或 HEAD 客户 URL；
- 平台不保存完整源 URL；
- 创建素材时立即固定服务商账号、渠道和模型；
- 客户删除素材时，平台删除服务商侧素材与本地映射，不删除客户源对象。

### 6.2 创建普通素材

```http
POST /v1/assets
```

```bash
curl -sS -X POST "$API_BASE/v1/assets" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: $REQUEST_ID" \
  -d '{
    "name": "reference-image",
    "asset_kind": "general",
    "media_type": "image",
    "model": "seedance-model",
    "source": {
      "type": "url",
      "url": "https://cdn.example.com/signed/reference.png?signature=...",
      "expires_at": 1784785200
    }
  }'
```

字段：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `name` | 是 | 1～64 个字符 |
| `asset_kind` | 是 | `general` 或 `real_person` |
| `media_type` | 是 | `image`、`video` 或 `audio` |
| `model` | 二选一 | 绑定到视频模型，可用于视频路由 |
| `target` | 二选一 | 当前仅 `joycreator_library`，只做管理，不参与视频路由 |
| `authorization_id` | 真人素材必填 | 必须是当前用户已生效的授权 |
| `source.type` | 是 | 固定为 `url` |
| `source.url` | 是 | Provider 可访问的公网 HTTPS URL |
| `source.expires_at` | 否 | URL 到期 Unix 秒；签名或临时 URL 强烈建议提供 |

`model` 和 `target` 必须且只能提供一个。

真人素材额外限制：

- `asset_kind` 为 `real_person`；
- `media_type` 只能为 `image`；
- 必须使用 `model`，不能使用管理目标；
- 授权、素材和视频请求必须属于同一用户、模型和 Provider 账号。

成功返回 HTTP `202`：

```json
{
  "asset": {
    "id": "ast_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
    "name": "reference-image",
    "asset_kind": "general",
    "media_type": "image",
    "model": "seedance-model",
    "status": "processing",
    "created_at": 1784778000,
    "updated_at": 1784778000
  }
}
```

状态：

| 状态 | 说明 |
| --- | --- |
| `creating` / `processing` | 创建中 |
| `ready` | 可以在视频请求中引用 |
| `create_unknown` | 上游创建结果暂时未知，不得换 Key 重建 |
| `failed` | 创建失败 |
| `deleting` | 删除中，已经不能创建新引用 |
| `deletion_failed` | 上游删除失败，等待后台重试或人工处理 |
| `deleted` | 已删除 |

### 6.3 URL 约束

URL 必须：

- 使用 HTTPS；
- 使用公网域名或公网 IP；
- 不包含 userinfo 和 fragment；
- 不使用非 443 端口；
- 当前全部 A/AAAA 解析结果均为公网地址；
- 如果提供了 `source.expires_at`，剩余有效时间必须大于渠道配置的最小抓取窗口。

以下地址会被拒绝：

- loopback、private、link-local、multicast、unspecified 和保留地址；
- 云元数据地址；
- 超出配置长度上限的 URL；
- `direct_upload`、`base64`、`temporary_upload` 等非 URL 来源。

TTL 不足响应包含服务端要求：

```json
{
  "error": {
    "type": "asset_error",
    "code": "asset_url_ttl_insufficient",
    "message": "asset URL expires before the Provider fetch window",
    "request_id": "req_xxx",
    "details": {
      "required_min_ttl_seconds": 3600
    }
  }
}
```

### 6.4 查询、改名和删除

列表：

```http
GET /v1/assets?page=1&page_size=20&status=ready&asset_kind=general&media_type=image&name=reference
```

`page_size` 最大为 100。响应：

```json
{
  "data": [],
  "total": 0,
  "page": 1,
  "page_size": 20
}
```

详情：

```http
GET /v1/assets/{asset_id}
```

改名：

```http
PATCH /v1/assets/{asset_id}
Content-Type: application/json

{"name":"new-name"}
```

查询绑定：

```http
GET /v1/assets/{asset_id}/bindings
```

```json
{
  "data": [
    {
      "id": "ab_xxx",
      "asset_id": "ast_xxx",
      "model": "seedance-model",
      "status": "active",
      "created_at": 1784778000,
      "updated_at": 1784778060
    }
  ]
}
```

删除：

```http
DELETE /v1/assets/{asset_id}
```

成功返回 HTTP `204`。事务提交后立即禁止新视频引用，上游清理可异步完成。

### 6.5 素材迁移

渠道密钥、Provider 项目、区域或模型需要变化时，不能修改原 binding，应创建迁移后的新素材：

```http
POST /v1/assets/{asset_id}/migrations
```

```json
{
  "name": "reference-image-v2",
  "model": "seedance-model-v2",
  "source": {
    "type": "url",
    "url": "https://cdn.example.com/signed/reference-v2.png",
    "expires_at": 1784785200
  },
  "migration_batch_id": "batch-20260723-01",
  "migration_reason": "channel credential rotation"
}
```

`migration_reason` 必填，最长 300 个字符。成功返回 HTTP `202` 和一个新的 `ast_...`，原素材不会被原地改写。

迁移规则：

- 只有 `ready` 素材可以迁移；
- `name` 可省略，省略时沿用原素材名称；
- `migration_batch_id` 可省略，省略时由服务端生成，提供时最长 64 个字符；
- 素材种类和媒体类型从原素材继承；
- 真人素材迁移必须提供新的或重新确认有效的 `authorization_id`。

### 6.6 在视频中引用素材

OpenAI Videos：

```json
{
  "model": "seedance-model",
  "prompt": "Animate this image",
  "seconds": "4",
  "size": "1280x720",
  "input_reference": {
    "image_url": "asset://ast_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
  }
}
```

ModelArk：

```json
{
  "model": "seedance-model",
  "content": [
    {
      "type": "image_url",
      "role": "reference_image",
      "image_url": {
        "url": "asset://ast_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
      }
    }
  ]
}
```

服务端会在发送 Provider 前把平台素材 ID 转换为创建时冻结的上游引用。客户端看不到上游引用值。

## 7. 真人素材授权

### 7.1 创建授权

```http
POST /v1/real-person-authorizations
```

```json
{
  "model": "seedance-model",
  "locale": "zh-CN"
}
```

成功返回 HTTP `201`：

```json
{
  "id": "rpa_xxx",
  "status": "awaiting_consent",
  "consent_url": "https://api.example.com/consent/real-person/...",
  "expires_at": 1784781600,
  "created_at": 1784778000,
  "updated_at": 1784778000
}
```

`consent_url` 必须交给照片本人在浏览器打开。客户端不得代替本人提交同意表单。

### 7.2 查询状态

```http
GET /v1/real-person-authorizations/{authorization_id}
```

查询时服务端会同步刷新 Provider 认证结果。只有 `authorized` 状态可以创建真人素材。

常见状态：

```text
awaiting_consent
consent_rejected
awaiting_verification
verifying
authorized
failed
expired
revoked
deleting
deleted
```

如果响应包含 `error_code=real_person_verification_rejected`，不得绕过认证继续创建。

### 7.3 重试和撤回

重试可重试的认证：

```http
POST /v1/real-person-authorizations/{authorization_id}/retry
```

成功响应包含新的 `verification_url`。不可重试时返回 `409 authorization_not_retryable`。

撤回：

```http
POST /v1/real-person-authorizations/{authorization_id}/revoke
```

撤回事务完成后，相关真人素材立即不能用于新视频任务；Provider 清理可在后台继续。

## 8. 存量视频兼容接口

以下接口仍在路由中，但它们保留各 Provider 或历史平台的请求、响应差异，不属于新的统一视频合同。

### 8.1 平台旧视频接口

```text
POST /v1/video/generations
GET  /v1/video/generations/{task_id}
```

创建请求常用字段：

```json
{
  "model": "video-model",
  "prompt": "Create a short video",
  "image": "https://example.com/reference.png",
  "images": [],
  "size": "1280x720",
  "duration": 5,
  "seconds": "5",
  "metadata": {}
}
```

注意：

- 不同 Provider 对字段和创建响应的支持不完全相同；
- 查询响应使用历史 `code/data` 包装，并可能包含平台专用字段；
- 新客户端不要依赖其中的内部数据库编号、渠道字段或 Provider 原始数据；
- 平台素材 `asset://ast_...` 仍受模型、用户和冻结渠道约束；
- 迁移新客户端时，应选择 OpenAI Videos 或 ModelArk v3，并在同一协议内完成创建、查询和删除。

### 8.2 Provider 兼容入口

```text
POST /kling/v1/videos/text2video
POST /kling/v1/videos/image2video
GET  /kling/v1/videos/text2video/{task_id}
GET  /kling/v1/videos/image2video/{task_id}
POST /jimeng/
```

这些入口用于兼容既有 Kling 或即梦客户端，不提供跨 Provider 的稳定统一响应。对接字段应以对应 Provider 协议和当前渠道配置为准。

## 9. 错误处理

### 9.1 OpenAI Videos 错误格式

```json
{
  "error": {
    "message": "Invalid video request (request id: req_xxx)",
    "type": "invalid_request_error",
    "param": null,
    "code": "invalid_request"
  }
}
```

### 9.2 ModelArk 错误格式

```json
{
  "error": {
    "code": "invalid_request",
    "message": "invalid request body (request id: req_xxx)",
    "request_id": "req_xxx"
  }
}
```

### 9.3 素材错误格式

```json
{
  "error": {
    "message": "asset request is invalid",
    "type": "asset_error",
    "code": "invalid_request",
    "request_id": "req_xxx"
  }
}
```

### 9.4 HTTP 状态和客户端动作

| HTTP | 典型错误 | 客户端动作 |
| --- | --- | --- |
| `400` | `invalid_request`、`invalid_seconds`、`unsafe_asset_url` | 修正请求，不自动重试 |
| `401` | `authentication_error` | 检查平台 Token |
| `403` | `permission_denied`、真人授权未生效 | 检查 Token 模型权限或授权状态 |
| `404` | `video_not_found`、`task_not_found`、`asset_not_found` | 停止轮询，核对协议和资源 ID |
| `409` | `idempotency_conflict`、`asset_binding_required`、状态冲突 | 不盲目重试，按错误码处理 |
| `410` | `video_content_expired` | 内容已过期，不能继续下载 |
| `429` | `rate_limit_exceeded` | 指数退避 |
| `502` | `upstream_unavailable`、`upstream_auth_error` | 保留原幂等 Key，稍后重试 |
| `503` | `upstream_unavailable`、`create_outcome_unknown` | 查询原任务；不要换 Key 重建 |

上游服务商返回的 401/403 不会冒充客户端 Token 错误，而会转换为 `502 upstream_auth_error`。

## 10. 对接注意事项

1. 创建成功后只保存平台 `task_...` 和 `ast_...`，不要依赖 Provider ID。
2. OpenAI 与 ModelArk 任务按创建协议隔离：不要用 OpenAI 详情接口查询 ModelArk 任务，反之亦然。
3. 内容下载共用 `/v1/videos/{task_id}/content`，始终携带 Bearer Token。
4. 素材必须等到 `ready` 才能生成视频。
5. 同一个视频请求引用多个平台素材时，它们必须存在共同的冻结渠道。
6. 渠道密钥变化后旧 binding 会失效，应使用素材迁移接口，而不是修改数据库。
7. 不要记录完整签名 URL、Token、真人认证 URL 或响应中的临时凭证。
8. `create_unknown`、`cancellation_unknown` 表示结果未知，不等于失败；应查询原资源并走对账流程。
9. 视频删除不会删除客户原始输入文件；素材删除也只清理 Provider 资源和平台映射。
