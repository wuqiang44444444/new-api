# Synlink 托管素材四图引用真实测试

## 1. 问题与目标

在[Mini 四秒四图 URL 测试](2026-09-08-Synlink渠道Mini四秒四图真实测试.md)之后，用户明确要求真实
测试 asset 方式。本次通过运行中的公开 API 创建具名素材组与四个具名托管素材，再只用这些素材返回的
`asset://fhas_*` 引用，向真实 Synlink 渠道提交一个 Mini 视频任务。

## 2. 当前实际情况

### 2.1 环境与结果

- 日期：2026-09-08，时间均为北京时间；本机网关 `http://127.0.0.1:3501`。
- 渠道 104；`synlink_video_v1` 视频协议，本站托管图片库素材协议。
- 客户模型：`doubao-seedance-2-0-mini-260615-synlink`，映射至
  `doubao-seedance-2-0-mini-260615`。
- 四张图沿用上次已检查的陶瓷杯产品图。素材由本站创建并复制到私有对象存储；视频生成实际发送至
  `https://synlinkai.com`，没有模拟 Provider。
- **结果：四个素材创建及查询成功，asset 引用视频生成成功，客户 Token 结算与差额退款成功。**
- 本次只提交一次视频 POST，没有重发、切换渠道或直接写入 Task／资金结果。

约 **7.042 秒**返回 HTTP 200：

```json

```

已核对本次 Task 的 `hosted_media` 有四条事实，Asset ID 集合与请求完全相同，每条冻结对象位置和大小
均匹配已持久化素材。attempt 为 `complete + transferred`。这些检查没有输出对象私有路径或签名 URL。
结合请求仅含四个 asset 引用及真实生成成功，可确认本次经过了托管引用解析路径。

南向由现有 adapter 把冻结素材签发为临时 URL，再调用 `POST /v1/video/generate`。本记录未导出加密
证据中的完整南向正文，因此不把代码转换说明写成已逐字捕获的报文；平台证据索引已记录南向请求及
HTTP 200 响应。

1. **已完成**：真实素材组创建、四个具名 asset 创建与查询、纯 asset 视频请求、托管事实冻结、

   本次测试 Key 已停用，渠道恢复禁用，价格和 Token 上限保持配置。
3. 本次已取得 `processing` 的真实响应证据，可作为后续补齐状态映射及回归测试的依据。
