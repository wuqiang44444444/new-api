# 产品发布记录

## 2026 年 11 月功能更新

**记录范围：11 月 1 日至 12 日。** 以下功能已实现，部分已用真实图片和视频任务验证。正式开放时间和范围以站点上线公告为准。

### 个人用量与账单

- **按日、周、月查看用量。** 打开「我的用量」，默认查看昨天。可按 API Key 筛选，查看调用次数、Token 用量和净费用，也可以按这些指标查看模型排行。周报和月报可以逐日展开，所选范围可导出为 CSV。
- **看清报表是否齐全。** 页面会标明数据更新时间，并区分「尚未发布」「仅有部分数据」和「当天没有用量」。当天的阶段性数据会标明为估算。「使用日志」默认显示最近一小时，也可用请求 ID 找到单笔记录。
- **查清一笔任务扣了多少、退了多少。** 在「我的账单」按 API Key 或模型查费用，展开明细可核对扣款和退款。跨日退款在账单上记在实际退款入账日，在用量报表中归回原任务完成日。符合条件且超过 24 小时仍未退清的视频任务会显示「待退款」。

### 图片与视频

- **异步图片完成后可以预览和下载。** 对支持异步的图片模型，可先提交任务，稍后查询结果。使用同一个防重复提交标识重试相同请求时，会返回原任务，避免重复生成。支持分项计价的模型可以在用量或费用详情中查看输入、输出等计费项目。
- **试点验证了 MiniMax H3 和 Seedance Mini 的生成与下载。** MiniMax H3 已用真实任务验证文生视频和单图参考场景，支持的画幅随所选模型而异。Nexhina 的 Seedance Mini 已验证使用 HTTPS 图片链接或已入库的普通图片生成视频，并核对了下载与结算。上述验证覆盖试点模型与场景，开放范围以站点模型目录为准。
- **视频任务用量更容易核对。** ModelArk 视频任务的单条查询和任务列表采用同一种用量展示方式。已确认的用量会随任务更新，实际扣费和退款金额在账单查看。

### 管理与运营

- **按客户或渠道查用量、对账。** 「用量统计」可搜索客户，按调用次数、Token 或费用排序，再查看单个客户的模型与 API Key。上游用量和对账可按服务地址、渠道查看，再展开具体模型。导出记录中可查看生成进度并下载对应范围的 CSV。
- **用户可以通过邮箱自助重置密码。** 管理员新建账户时填写有效邮箱。用户在登录页申请找回密码后，通过邮件中的一次性链接设置新密码。管理员可在系统设置中发送测试邮件，检查实际收件情况。
- **把渠道故障、资源告警和日报发给运维。** 渠道持续不可用或出现可处置的异常时，即使没有开启自动停用，也可向指定人员发邮件。CPU、内存和磁盘可分别设置告警阈值。启用运维日报后，每天汇总前一日的主要错误和受影响渠道，最早于北京时间 06:00 发送。

### 开放进度

- 图片任务和部分视频模型已有真实调用验收记录。报表、邮件和新增渠道仍需按目标站点完成上线验收。MiniMax 官方直连的真实调用与账单核对仍待验收。
