# 图片模型官方价格与五折人民币成本

## 调研范围与换算口径

- 查询日期：2026-09-23（Asia/Shanghai）；本文是该日期的外部价格调研快照。
- 覆盖 GPT Image 2、GPT Image 2.5 Sunburst / Flare、Nano Banana 2 Lite / 2 / Pro，以及国内火山方舟 Seedream 5.0 Flash / Pro / Lite。
- 五折是本次成本测算假设，来自“我们的价格大约是官网五折”，不是已核验的供应商合同折扣、采购账单或系统实际配置。
- 美元统一按 **1 USD = 6.70 CNY** 测算，参考查询日约 6.70 的[美元兑人民币行情](https://www.investing.com/currencies/usd-cny-historical-data)。这是固定测算汇率，不是实际结汇价。
- 美元价格换算：**五折人民币成本 = 官方美元价格 × 0.50 × 6.70**；人民币价格换算：**五折成本 = 官方人民币价格 × 0.50**。
- 按未舍入原值计算，人民币结果保留四位小数。以标准在线 API 刊例价为基准，不叠加 Batch、缓存、活动或资源包折扣。
- 表格主体仅统计最终图片输出，不包括输入、文本或思考输出、搜索、流式预览、税费及平台运营成本；附加计费见各节说明。
- 本文不表示上述模型均已接入本站、生产可用，或应直接写入本站计费配置。

## 1. GPT Image 2 与 GPT Image 2.5

### 1.1 尺寸与质量口径

| 本文标签 | 实际输出尺寸 | 比例 |
| -------- | ------------ | ---- |
| 1K       | 1024×1024    | 1:1  |
| 2K       | 2048×2048    | 1:1  |
| 4K       | 3840×2160    | 16:9 |

两代模型均不支持 4096×4096：最长边不得超过 3840，且总像素不得超过 8,294,400。
长宽比例也影响输出 token 估算，因此本表的 4K 宽屏成本可以低于 2K 正方形；不能只按像素总量倍增价格。
官方将超过 2560×1440 的 GPT Image 2.5 输出列为实验性规格。

来源：[OpenAI 图片生成指南](https://developers.openai.com/api/docs/guides/image-generation#size-and-quality-options)。

### 1.3 估算复核方法

查询时[官网计算器脚本](https://developers.openai.com/_astro/GptImageTokenCalculator.react.Z2Zu5XGo.js)使用以下规则：

1. 设宽高为 `W`、`H`，长短边比为 `R = max(W,H) / min(W,H)`。
2. 质量基数 `L`：GPT Image 2 的 low / medium / high 分别为 `16 / 48 / 96`；GPT Image 2.5 的对应值为 `16 / 24 / 48`。
3. `S = round_half_to_even(L / R)`，即四舍六入、恰为半数时取偶数。
4. 输出 token 为 `ceil(L × S × (2,000,000 + W × H) / 4,000,000)`。
5. 官方美元成本为 `输出 token × 30 / 1,000,000`，再应用五折和汇率。

脚本 URL 带版本 hash，未来可能失效；复核新价格时应以官网计算器当前规则为准。
不能把 GPT Image 1 系列的输出 token 表用于 2 或 2.5。

## 4. 比较与使用边界

- 五折数值是采购成本情景估算，不能当作已经发生的供应商成本、客户售价或毛利结论。
- 本文的 GPT Image 4K 是 3840×2160 宽屏，Nano Banana 4K 定价示例是 4096×4096 正方形；同写“4K”不表示总像素一致。
- 模型质量档位、型号定位和实际画质不等价；本文只做价格换算，没有做同提示词、同尺寸的画质或成功率实验。
- 完整单次请求成本须按实际输入、输出、工具调用及账单累计；实际采购折扣和汇率变化后应重新计算。
- 后续采购或定价前应重新核对上文官方来源，并以具体区域、模型快照和合同为准。
