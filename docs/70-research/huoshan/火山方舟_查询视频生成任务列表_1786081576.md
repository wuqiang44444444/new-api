# 查询视频生成任务列表

> 来源：[原始 PDF](火山方舟_查询视频生成任务列表_1786081576.pdf)。本文为 PDF 的 Markdown 转写，接口能力与时效性以火山方舟最新官方文档和实际签署协议为准。

```http
GET https://ark.cn-beijing.volces.com/api/v3/contents/generations/tasks
```

通过筛选参数查询符合条件的视频生成任务。

> **说明**
>
> - 仅支持查询最近 7 天的任务记录，时间区间为 `[T-7 天, T)`，其中 `T` 为请求发起时刻的 UTC 时间戳（精确到秒）。
> - 视频 URL 有效期为 24 小时，请及时下载或转存。
> - Seedance 2.5 模型生成的产物 URL 下载次数上限为 100 次。

## 鉴权

本接口支持 API Key 鉴权。请在 API Key 管理页面获取长效 API Key；详情参见火山方舟的 Base URL 及鉴权文档。

## 请求参数

### Query 参数

参数通过 URL Query String 传入。

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `filter.model` | `string` | - | 按任务使用的推理接入点（Endpoint）ID 精确筛选。 |
| `filter.service_tier` | `string` | `default` | 按服务等级筛选：`default` 为在线推理模式，`flex` 为离线推理模式。 |
| `filter.status` | `string` | - | 按任务状态筛选：`queued`、`running`、`cancelled`、`succeeded`、`failed` 或 `expired`。 |
| `filter.task_ids` | `string[]` | - | 按任务 ID 精确筛选，支持多个 ID。重复传递参数名，例如 `filter.task_ids=id1&filter.task_ids=id2`。 |
| `page_num` | `integer` | `1` | 页码，取值范围 `[1, 500]`。 |
| `page_size` | `integer` | `20` | 每页结果数，取值范围 `[1, 500]`。 |

### 任务状态

| 状态 | 含义 |
| --- | --- |
| `queued` | 排队中的任务。 |
| `running` | 运行中的任务。 |
| `cancelled` | 已取消的任务。 |
| `succeeded` | 成功的任务。 |
| `failed` | 失败的任务。 |
| `expired` | 超时的任务。 |

## 响应参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `items` | `object[]` | 查询到的视频生成任务列表。 |
| `total` | `integer` | 符合筛选条件的任务总数。 |

### `items` 数组元素

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `items.id` | `string` | 视频生成任务 ID。 |
| `items.model` | `string` | 任务使用的模型名称和版本，格式为“模型名称-版本”。 |
| `items.status` | `string` | 任务状态：`queued`、`running`、`cancelled`、`succeeded`、`failed` 或 `expired`。 |
| `items.content` | `object` | 任务完成时返回的输出内容，包括生成视频下载 URL。 |
| `items.created_at` | `integer` | 任务创建时间的 Unix 时间戳（秒）。 |
| `items.draft` | `boolean` | 是否为 Draft 视频。Seedance 1.5 Pro 支持。 |
| `items.draft_task_id` | `string` | Draft 视频任务 ID。基于 Draft 视频生成正式视频时返回。 |
| `items.duration` | `integer` | 生成视频的时长（秒）。与 `frames` 只返回一个；创建任务时未指定 `frames` 则返回 `duration`。 |
| `items.error` | `object` | 错误信息。任务成功时为 `null`，任务失败时返回错误数据。 |
| `items.execution_expires_after` | `integer` | 任务提交后的超时阈值（秒）。超过该时间仍未完成的任务会自动终止并标记为 `expired`。 |
| `items.frames` | `integer` | 生成视频的帧数。与 `duration` 只返回一个；创建任务时指定 `frames` 则返回 `frames`。 |
| `items.framespersecond` | `integer` | 生成视频的帧率。 |
| `items.generate_audio` | `boolean` | 是否包含与画面同步的声音。Seedance 2.5、Seedance 2.0 系列和 Seedance 1.5 Pro 支持。 |
| `items.output_format` | `string` | 实际生成视频的封装容器格式：`mp4` 或 `mov`。Seedance 2.5 支持。 |
| `items.priority` | `integer` | 系统根据账户与模型策略分配的执行优先级；值越大，执行优先级越高。 |
| `items.ratio` | `string` | 生成视频的宽高比。 |
| `items.resolution` | `string` | 生成视频的分辨率。 |
| `items.safety_identifier` | `string` | 终端用户唯一标识。创建任务时设置后，接口原样返回。 |
| `items.seed` | `integer` | 本次请求使用的随机种子整数值。 |
| `items.service_tier` | `string` | 实际处理任务使用的服务等级。 |
| `items.tools` | `object[]` | 本次请求实际使用的工具；未使用工具时不返回。Seedance 2.5 和 Seedance 2.0 系列支持。 |
| `items.updated_at` | `integer` | 任务当前状态更新时间的 Unix 时间戳（秒）。 |
| `items.usage` | `object` | 本次请求的 token 用量。 |

### `items.status` 状态说明

| 状态 | 含义 |
| --- | --- |
| `queued` | 排队中。 |
| `running` | 任务运行中。 |
| `cancelled` | 任务已取消；取消状态 24 小时后自动删除。只支持取消排队中的任务。 |
| `succeeded` | 任务成功。 |
| `failed` | 任务失败。 |
| `expired` | 任务超时。 |

### `items.content` 对象

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `items.content.last_frame_url` | `string` | 尾帧图像 URL。创建任务时设置 `"return_last_frame": true` 才会返回。URL 有效期为 24 小时；Seedance 2.5 产物 URL 下载次数上限为 100 次。 |
| `items.content.video_url` | `string` | 生成视频的 URL。有效期为 24 小时；Seedance 2.5 产物 URL 下载次数上限为 100 次。建议及时下载、转存，或使用 TOS 数据订阅长期保存。 |

`items.draft` 的取值：

- `true`：当前输出为 Draft 视频。
- `false`：当前输出为正常视频。

### `items.error` 对象

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `items.error.code` | `string` | 错误码。 |
| `items.error.message` | `string` | 错误提示信息。 |

> **注意**：Seedance 2.5 模型在特定任务类型中，需要等任务排队并被消费后才会返回非法传参错误。

### `items.tools` 数组元素

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `items.tools.type` | `string` | 实际使用的工具类型。当前可选值为 `web_search`（联网搜索工具）。 |

### `items.usage` 对象

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `items.usage.completion_tokens` | `integer` | 生成视频消耗的 token 数，可作为计费对账依据。 |
| `items.usage.total_tokens` | `integer` | 本次请求消耗的总 token 数。视频生成模型不统计输入 token，因此 `total_tokens = completion_tokens`。 |
| `items.usage.tool_usage` | `object` | 工具用量信息。 |
| `items.usage.tool_usage.web_search` | `integer` | 实际调用联网搜索工具的次数，仅开启联网搜索时返回。 |

> **计费注意**：Seedance 2.0 系列存在最低 token 用量限制。如果实际 token 用量低于最低值，`completion_tokens` 返回最低 token 用量，平台也按最低 token 用量计费。
