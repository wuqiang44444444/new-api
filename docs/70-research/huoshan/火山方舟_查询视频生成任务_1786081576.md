# 查询视频生成任务

> 来源：[原始 PDF](火山方舟_查询视频生成任务_1786081576.pdf)。本文为 PDF 的 Markdown 转写，接口能力与时效性以火山方舟最新官方文档和实际签署协议为准。

```http
GET https://ark.cn-beijing.volces.com/api/v3/contents/generations/tasks/{task_id}
```

查询视频生成任务的状态。

> **说明**
>
> - 仅支持查询最近 7 天的任务记录，时间区间为 `[T-7 天, T)`，其中 `T` 为请求发起时刻的 UTC 时间戳（精确到秒）。
> - 视频 URL 有效期为 24 小时，请及时下载或转存。
> - Seedance 2.5 模型生成的视频 URL 下载次数上限为 100 次。

## 鉴权

本接口支持 API Key 鉴权。请在 API Key 管理页面获取长效 API Key；详情参见火山方舟的 Base URL 及鉴权文档。

## 请求参数

### Path 参数

| 参数 | 类型 | 必选 | 说明 |
| --- | --- | --- | --- |
| `task_id` | `string` | 是 | 需要查询的视频生成任务 ID。 |

## 响应参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `id` | `string` | 视频生成任务 ID。 |
| `model` | `string` | 任务使用的模型名称和版本，格式为“模型名称-版本”。 |
| `status` | `string` | 任务状态：`queued`、`running`、`cancelled`、`succeeded`、`failed` 或 `expired`。 |
| `content` | `object` | 视频生成任务的输出内容。 |
| `created_at` | `integer` | 任务创建时间的 Unix 时间戳（秒）。 |
| `draft` | `boolean` | 是否为 Draft 视频。Seedance 1.5 Pro 支持。 |
| `draft_task_id` | `string` | Draft 视频任务 ID。基于 Draft 视频生成正式视频时返回。 |
| `duration` | `integer` | 生成视频的时长（秒）。与 `frames` 只返回一个；创建任务时未指定 `frames` 则返回 `duration`。 |
| `error` | `object` | 错误信息。任务成功时为 `null`，任务失败时返回错误数据。 |
| `execution_expires_after` | `integer` | 任务提交后的超时阈值（秒）。超过该时间仍未完成的任务会自动终止并标记为 `expired`。 |
| `frames` | `integer` | 生成视频的帧数。与 `duration` 只返回一个；创建任务时指定 `frames` 则返回 `frames`。 |
| `framespersecond` | `integer` | 生成视频的帧率。 |
| `generate_audio` | `boolean` | 是否包含与画面同步的声音。Seedance 2.5、Seedance 2.0 系列和 Seedance 1.5 Pro 支持。 |
| `output_format` | `string` | 实际生成视频的格式：`mp4` 或 `mov`。Seedance 2.5 支持。 |
| `priority` | `integer` | 系统根据账户与模型策略分配的执行优先级；值越大，执行优先级越高。 |
| `ratio` | `string` | 生成视频的宽高比。 |
| `resolution` | `string` | 生成视频的分辨率。 |
| `safety_identifier` | `string` | 终端用户唯一标识。创建任务时设置后，接口原样返回。 |
| `seed` | `integer` | 本次请求使用的随机种子整数值。 |
| `service_tier` | `string` | 实际处理任务使用的服务等级。 |
| `tools` | `object[]` | 本次请求实际使用的工具；未使用工具时不返回。Seedance 2.5 和 Seedance 2.0 系列支持。 |
| `updated_at` | `integer` | 任务当前状态更新时间的 Unix 时间戳（秒）。 |
| `usage` | `object` | 本次请求的 token 用量。 |

### 任务状态

| 状态 | 含义 |
| --- | --- |
| `queued` | 排队中。 |
| `running` | 任务运行中。 |
| `cancelled` | 任务已取消；取消状态 24 小时后自动删除。只支持取消排队中的任务。 |
| `succeeded` | 任务成功。 |
| `failed` | 任务失败。 |
| `expired` | 任务超时。 |

### `content` 对象

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `content.last_frame_url` | `string` | 尾帧图像 URL。创建任务时设置 `"return_last_frame": true` 才会返回。URL 有效期为 24 小时；Seedance 2.5 产物 URL 下载次数上限为 100 次。 |
| `content.video_url` | `string` | 生成视频的 URL。有效期为 24 小时；Seedance 2.5 产物 URL 下载次数上限为 100 次。建议及时下载、转存，或使用 TOS 数据订阅长期保存。 |

### `draft` 字段

- `true`：当前输出为 Draft 视频。
- `false`：当前输出为正常视频。

### `error` 对象

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `error.code` | `string` | 错误码。 |
| `error.message` | `string` | 错误提示信息。 |

> **注意**：Seedance 2.5 模型在特定任务类型中，需要等任务排队并被消费后才会返回非法传参错误。

### `tools` 数组元素

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `tools.type` | `string` | 实际使用的工具类型。当前可选值为 `web_search`（联网搜索工具）。 |

### `usage` 对象

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `usage.completion_tokens` | `integer` | 生成视频消耗的 token 数，可作为计费对账依据。 |
| `usage.total_tokens` | `integer` | 本次请求消耗的总 token 数。视频生成模型不统计输入 token，因此 `total_tokens = completion_tokens`。 |
| `usage.tool_usage` | `object` | 工具用量信息。 |
| `usage.tool_usage.web_search` | `integer` | 实际调用联网搜索工具的次数，仅开启联网搜索时返回。 |

> **计费注意**：Seedance 2.0 系列存在最低 token 用量限制。如果实际 token 用量低于最低值，`completion_tokens` 返回最低 token 用量，平台也按最低 token 用量计费。
