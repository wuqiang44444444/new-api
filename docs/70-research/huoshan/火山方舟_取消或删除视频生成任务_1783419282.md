# 取消或删除视频生成任务

> 来源：[原始 PDF](火山方舟_取消或删除视频生成任务_1783419282.pdf)。本文为 PDF 的 Markdown 转写，接口能力与时效性以火山方舟最新官方文档和实际签署协议为准。

```http
DELETE https://ark.cn-beijing.volces.com/api/v3/contents/generations/tasks/{id}
```

取消排队中的视频生成任务，或者删除视频生成任务记录。

## 鉴权

本接口支持 API Key 鉴权，详情参见火山方舟鉴权认证文档。

## 请求参数

### Path 参数

| 参数 | 类型 | 必选 | 说明 |
| --- | --- | --- | --- |
| `id` | `string` | 是 | 需要取消或删除的视频生成任务 ID。 |

任务状态不同，调用 `DELETE` 接口执行的操作也不同：

| 当前任务状态 | 支持 `DELETE` | 操作含义 | 操作后任务状态 |
| --- | --- | --- | --- |
| `queued` | 是 | 取消任务排队。 | `cancelled` |
| `running` | 否 | - | - |
| `succeeded` | 是 | 删除视频生成任务记录，后续不再支持查询。 | - |
| `failed` | 是 | 删除视频生成任务记录，后续不再支持查询。 | - |
| `cancelled` | 否 | - | - |
| `expired` | 是 | 删除视频生成任务记录，后续不再支持查询。 | - |

## 响应参数

本接口无返回参数。
