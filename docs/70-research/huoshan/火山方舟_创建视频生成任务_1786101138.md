# 创建视频生成任务

> 来源：[原始 PDF](火山方舟_创建视频生成任务_1786101138.pdf)。本文为 PDF 的 Markdown 转写，接口能力、价格与时效性以火山方舟最新官方文档和实际签署协议为准。

```http
POST https://ark.cn-beijing.volces.com/api/v3/contents/generations/tasks
```

本文说明创建视频生成任务 API 的输入输出参数。模型依据传入的图片、视频、音频及文本信息生成视频；生成完成后，可查询任务并获取生成的视频。

> **使用必读**：Seedance 2.5 已全面公开。调用前应查阅火山方舟最新“使用必读”，确认任务类型和参数配置。

## 模型能力

支持有声或无声视频：

- 多模态参考生视频：0-30 张参考图片、0-10 个参考视频、0-10 个参考音频，以及可选文本提示词，生成 1 个目标视频；支持仅传入音频；支持生成全新视频、编辑视频、延长视频及 30 秒视频连贯直出。
- 图生视频-首尾帧：首帧图片、尾帧图片和可选文本提示词生成 1 个目标视频。
- 图生视频-首帧：首帧图片和可选文本提示词生成 1 个目标视频。
- 文生视频：文本提示词生成 1 个目标视频。

### Doubao Seedance 2.0 系列

支持有声或无声视频：

- 多模态参考生视频：0-9 张参考图片、0-3 个参考视频、0-3 个参考音频，以及可选文本提示词，生成 1 个目标视频。不可仅输入音频，至少需要 1 个参考视频或图片；支持生成全新视频、编辑视频和延长视频。
- 图生视频-首尾帧：首帧图片、尾帧图片和可选文本提示词生成 1 个目标视频。
- 图生视频-首帧：首帧图片和可选文本提示词生成 1 个目标视频。
- 文生视频：文本提示词生成 1 个目标视频。

### 其他模型

- Doubao Seedance 1.5 pro：支持有声或无声的图生视频-首尾帧、图生视频-首帧和文生视频。
- Doubao Seedance 1.0 pro：支持图生视频-首尾帧、图生视频-首帧和文生视频。
- Doubao Seedance 1.0 pro fast：支持图生视频-首帧和文生视频。

## 参数传入方式

`resolution`、`ratio`、`duration`、`frames`、`seed`、`camera_fixed` 和 `watermark` 支持两种传入方式：

- 常规方式（推荐）：在 request body 中直接传入。该方式为强校验，参数错误时模型返回错误提示。
- 弱校验方式：在文本提示词后追加 `--[parameters]`。参数错误时可能被忽略，也可能触发报错。

不同模型支持的参数与取值不同，详见下文输出视频格式。所有模型均兼容以上两种传参方式。

### 常规方式示例

```json
{
  "model": "doubao-seedance-1-5-pro-251215",
  "content": [
    {
      "type": "text",
      "text": "小猫对着镜头打哈欠"
    }
  ],
  "resolution": "720p",
  "ratio": "16:9",
  "duration": 5,
  "seed": 11,
  "camera_fixed": false,
  "watermark": true
}
```

### 弱校验方式示例

```json
{
  "model": "doubao-seedance-1-5-pro-251215",
  "content": [
    {
      "type": "text",
      "text": "小猫对着镜头打哈欠 --rs 720p --rt 16:9 --dur 5 --seed 11 --cf false --wm true"
    }
  ]
}
```

## `content` 输入内容

支持以下组合：

- 纯文本；
- 可选文本 + 图片；
- 可选文本 + 视频；
- 可选文本 + 音频（仅 Seedance 2.5 支持单独传入音频）；
- 可选文本 + 图片 + 音频；
- 可选文本 + 图片 + 视频；
- 可选文本 + 视频 + 音频；
- 可选文本 + 图片 + 视频 + 音频；
- 样片任务 ID：使用 Seedance 模型成功生成的样片视频任务 ID，基于样片生成正式视频。

> **真人素材注意**：Seedance 2.5、Seedance 2.0 系列不支持直接上传含真人人脸的参考图或视频。PDF 中给出的替代方案包括：使用部分模型的含人脸原始产物、预置虚拟人像，或已授权真人素材。具体流程以最新官方教程为准。

### 文本信息

| 参数 | 类型 | 必选 | 说明 |
| --- | --- | --- | --- |
| `content.type` | `string` | 是 | 固定为 `text`。 |
| `content.text` | `string` | 是 | 描述期望生成视频的文本提示词。 |

提示词要求与建议：

- 所有模型支持中文、英文提示词。
- Seedance 2.5 额外支持西班牙语、印度尼西亚语、葡萄牙语、日语、马来语、泰语、阿拉伯语、越南语和韩语。
- Seedance 2.0 系列额外支持西班牙语、印度尼西亚语、葡萄牙语和日语。
- 建议中文提示词不超过 500 字，英文提示词不超过 1000 词。内容过长可能分散模型注意力。

### 图片信息

| 参数 | 类型 | 必选 | 说明 |
| --- | --- | --- | --- |
| `content.type` | `string` | 是 | 固定为 `image_url`。 |
| `content.image_url` | `object` | 是 | 图片对象。 |
| `content.image_url.url` | `string` | 是 | 图片公网 URL、Base64 Data URL 或素材 ID。 |
| `content.role` | `string` | 因场景而异 | 图片的位置或用途。 |

图片来源：

- 公网 URL；
- Base64 Data URL，格式为 `data:image/<图片格式>;base64,<Base64 编码>`，图片格式需小写，例如 `data:image/png;base64,{base64_image}`；
- 素材 ID，格式为 `asset://<ASSET_ID>`。

单张图片要求：

- 格式：`jpeg`、`png`、`webp`、`bmp`、`tiff`、`gif`；Seedance 1.5 pro 及以上版本额外支持 `heic`、`heif`。
- 宽高比（宽/高）：`[0.4, 2.5]`。
- 宽、高像素长度：`[300, 6000]`。
- 单张小于 30 MB，请求体不超过 64 MB；大文件不应使用 Base64 编码。
- 图生视频-首帧：1 张。
- 图生视频-首尾帧：2 张。
- Seedance 2.5 多模态参考生视频：1-30 张。
- Seedance 2.0 系列多模态参考生视频：1-9 张。

`role` 规则：

| 场景 | `content.role` 规则 | 模型支持 |
| --- | --- | --- |
| 图生视频-首帧 | 传入 1 个 `image_url` 对象；`role` 为 `first_frame` 或省略。 | Seedance 2.5、2.0 系列、1.5 pro、1.0 pro |
| 图生视频-首尾帧 | 传入 2 个 `image_url` 对象且 `role` 必填；首帧为 `first_frame`，尾帧为 `last_frame`。 | Seedance 2.5、2.0 系列、1.5 pro、1.0 pro |
| 多模态参考生视频 | 每张参考图的 `role` 均为 `reference_image`。 | Seedance 2.5、2.0 系列 |

首尾帧图片可以相同。宽高比不一致时，以首帧为主，尾帧会被自动裁剪适配。

> 图生视频-首帧、图生视频-首尾帧和多模态参考生视频（参考图、视频、音频）是三种互斥场景，不可混用。多模态参考生视频可通过提示词间接指定参考图作为首帧或尾帧；若必须严格保持首尾帧与指定图片一致，应使用 `first_frame` / `last_frame`。

### 视频信息

方舟平台信任 Seedance 2.5、Seedance 2.0 系列生成的含人脸视频；可使用本账号近 30 天内由上述模型生成的含人脸原始视频进行二次创作，具体要求以官方教程为准。

| 参数 | 类型 | 必选 | 说明 |
| --- | --- | --- | --- |
| `content.type` | `string` | 是 | 固定为 `video_url`。 |
| `content.video_url` | `object` | 是 | 视频对象。 |
| `content.video_url.url` | `string` | 是 | 视频公网 URL 或素材 ID（`asset://<ASSET_ID>`）。 |
| `content.role` | `string` | 否 | 固定为 `reference_video`。 |

支持 Seedance 2.5 和 Seedance 2.0 系列。单个视频要求：

- 容器格式：`mp4`、`mov`。
- 分辨率：480p、720p、1080p、4K。
- Seedance 2.5：单个视频 `[2, 30]` 秒，最多 10 个参考视频，全部视频总时长不超过 30 秒。
- Seedance 2.0 系列：单个视频 `[2, 15]` 秒，最多 3 个参考视频，全部视频总时长不超过 15 秒。
- 宽高比（宽/高）：`[0.4, 2.5]`。
- 宽、高像素长度：`[300, 6000]`。
- 总像素数：`[409600, 8295044]`，即从 `640 × 640` 到 `3326 × 2494` 的乘积区间。
- 单个视频不超过 200 MB。
- 帧率：`[24, 60]` FPS。

支持的编码：

| 容器格式 | 常用扩展名 | MIME | 视频编码 | 音频编码 |
| --- | --- | --- | --- | --- |
| MP4 | `.mp4` | `video/mp4` | H.264/AVC、H.265/HEVC | AAC、MP3 |
| QuickTime | `.mov` | `video/quicktime` | H.264/AVC、H.265/HEVC | AAC、MP3 |

### 音频信息

| 参数 | 类型 | 必选 | 说明 |
| --- | --- | --- | --- |
| `content.type` | `string` | 是 | 固定为 `audio_url`。 |
| `content.audio_url` | `object` | 是 | 音频对象。 |
| `content.audio_url.url` | `string` | 是 | 音频公网 URL、Base64 Data URL 或素材 ID。 |
| `content.role` | `string` | 否 | 固定为 `reference_audio`。 |

音频来源：

- 公网 URL；
- Base64 Data URL，格式为 `data:audio/<音频格式>;base64,<Base64 编码>`，音频格式需小写，例如 `data:audio/wav;base64,{base64_audio}`；
- 素材 ID，格式为 `asset://<ASSET_ID>`。

单个音频要求：

- 格式：`wav`、`mp3`。
- Seedance 2.5：单个音频 `[2, 30]` 秒，最多 10 段参考音频，全部音频总时长不超过 30 秒；可仅传入音频，也可搭配图片或视频。
- Seedance 2.0 系列：单个音频 `[2, 15]` 秒，最多 3 段参考音频，全部音频总时长不超过 15 秒；不可仅输入音频，至少需要 1 个参考视频或图片。
- 单个音频不超过 15 MB，请求体不超过 64 MB；大文件不应使用 Base64 编码。

### 样片信息

样片功能仅支持 Seedance 1.5 pro。

| 参数 | 类型 | 必选 | 说明 |
| --- | --- | --- | --- |
| `content.type` | `string` | 是 | 固定为 `draft_task`。 |
| `content.draft_task` | `object` | 是 | 样片任务对象。 |
| `content.draft_task.id` | `string` | 是 | 样片任务 ID。 |

平台复用 Draft 视频使用的 `model`、`content.text`、`content.image_url`、`generate_audio`、`seed`、`ratio`、`duration` 和 `camera_fixed`，生成正式视频；其他参数可以另行指定，未指定时使用模型默认值。

使用步骤：

1. 调用本接口生成 Draft 视频。
2. Draft 视频符合预期后，使用返回的 Draft 任务 ID 再次调用本接口生成正式视频。

## 其他 Body 参数

### `model`

必选字符串。传入要调用模型的 Model ID。开通模型服务后可查询 Model ID；也可使用 Endpoint ID 调用模型，以获得限流、计费类型、运行状态查询、监控和安全等高级能力。

### `callback_url`

可选字符串。视频生成任务状态变化时，方舟向该地址发送 `POST` 请求；请求体结构与“查询视频生成任务”接口的返回体一致。

回调状态包括：

- `queued`：排队中；
- `running`：运行中；
- `succeeded`：任务成功；发送失败（5 秒内未收到成功发送信息）时会回调三次；
- `failed`：任务失败；发送失败（5 秒内未收到成功发送信息）时会回调三次；
- `expired`：任务处于运行中或排队中超过过期时间，可用 `execution_expires_after` 设置。

### `camera_fixed`

可选布尔值，默认 `false`：

- `true`：固定摄像头。平台会在提示词中追加固定摄像头，但不保证实际效果。
- `false`：不固定摄像头。

参考图场景不支持。支持 Seedance 1.5 pro、Seedance 1.0 pro 和 Seedance 1.0 pro fast。

### `draft`

可选布尔值，默认 `false`，仅 Seedance 1.5 pro 支持：

- `true`：开启样片模式，生成低成本预览视频，用于快速验证场景结构、镜头调度、主体动作和 Prompt 意图。
- `false`：关闭样片模式，正常生成视频。

开启样片模式后固定使用 480p；使用其他分辨率会报错，并且不支持返回尾帧或离线推理。

### `duration`

可选整数，单位为秒。`duration` 与 `frames` 二选一，`frames` 优先级更高；生成整数秒视频时建议指定 `duration`。

当 `duration = -1` 时，模型按以下规则适配：

| 模型或任务类型 | `duration = -1` 规则 |
| --- | --- |
| Seedance 2.0 系列、Seedance 1.5 pro | 模型在有效范围内自主选择合适的整数秒长度。 |
| Seedance 2.5 视频编辑任务 | 自动保持输出视频与输入视频时长基本一致，输出可能比输入短约 0.4 秒；不支持另行设置。 |
| Seedance 2.5 其他任务类型 | 模型在有效范围内自主选择合适的整数秒长度。 |

查询接口返回的 `duration` 是视频时长约数，与实际时长可能不同：

```text
返回的 duration = 实际总帧数 / 24（向下取整）
```

例如生成 133 帧，实际时长为 `133 / 24 = 5.54` 秒，接口返回 `duration = 5`。

Seedance 2.5 视频编辑任务仅支持 `duration = -1`，不可指定具体输出时长；待编辑视频必须在 `[4, 30]` 秒内。

| 模型 | 取值 |
| --- | --- |
| Seedance 2.5 | 默认 `-1`；`[4, 30]` 或 `-1`（智能选择）。 |
| Seedance 2.0 系列 | `[4, 15]` 或 `-1`（智能选择）。 |
| Seedance 1.5 pro | `[4, 12]` 或 `-1`（智能选择）。 |
| Seedance 1.0 pro | `[2, 12]`。 |
| Seedance 1.0 pro fast | `[2, 12]`。 |

### `execution_expires_after`

可选整数，默认 `172800` 秒（48 小时），取值范围 `[3600, 259200]`。从 `created_at` 开始计算；超过阈值仍未完成的任务会自动终止并标记为 `expired`。无论使用何种 `service_tier`，都应按业务场景设置合适的超时时间。

### `frames`

可选整数，生成视频的帧数。用于生成小数秒视频；与 `duration` 二选一且优先级更高。

- 计算公式：`帧数 = 时长 × 24`。
- 取值范围：`[29, 289]`。
- 格式约束：范围内满足 `25 + 4n` 的整数，`n` 为正整数。

例如目标时长为 2.4 秒，计算得到 57.6 帧；最接近的合法值为 57 帧，实际时长约 `57 / 24 = 2.375` 秒。

仅 Seedance 1.0 pro 和 Seedance 1.0 pro fast 支持。

### `generate_audio`

可选布尔值，默认 `true`：

- `true`：输出包含同步音频，模型根据提示词和视觉内容生成匹配的人声、音效及背景音乐。建议将对话放在双引号中。
- `false`：输出无声视频。

生成的有声视频均为单声道，与输入音频声道数无关。支持 Seedance 2.5、Seedance 2.0 系列和 Seedance 1.5 pro。

### `output_format`

可选字符串，默认 `mp4`，仅 Seedance 2.5 支持：

- `mp4`：兼容性较好的通用格式，采用标准色彩精度。
- `mov`：面向专业后期场景的高色彩精度格式，适用于调色、抠像和合成；视频编辑、延长场景推荐用作输入和输出格式。

MOV 使用 H.264 视频编码、yuv444p 色度采样和 PCM 音频编码，部分播放器可能不兼容：

| 播放器 | macOS | Windows |
| --- | --- | --- |
| IINA | 支持 | 不支持 |
| VLC | 支持 | 支持 |
| mpv | 支持 | 支持 |
| ffplay | 支持 | 支持 |

### `priority`

可选整数，默认 `0`，取值范围 `[0, 9]`。数值越大，在同一 Endpoint 队列中的执行优先级越高；支持 Seedance 2.5 和 Seedance 2.0 系列。

默认 FIFO 队列：

```text
队列：[任务A: priority=0] -> [任务B: priority=0] -> [任务C: priority=0]
```

提交 `priority=5` 的新请求后：

```text
队列：[新请求: priority=5] -> [任务A: priority=0] -> [任务B: priority=0] -> [任务C: priority=0]
```

规则：

- 相同优先级仍按 FIFO 排序。
- 优先级只影响排队顺序，不中断 `status=running` 的任务。
- 只在同一 Endpoint 内生效。
- 离线推理模式 `service_tier=flex` 不支持配置优先级。

### `ratio`

### `resolution`

- Seedance 2.0 的 4K 视频采用 10bit 位深编码，保留更多色彩层次和渐变信息，适合专业影视制作与 HDR 内容。
- 4K 视频使用 H.265 编码。少数播放环境可能不兼容，可升级系统、更换设备或使用 VLC、MPV、QuickTime Player。

### `return_last_frame`

可选布尔值，默认 `false`：

- `true`：查询任务时返回尾帧图像。图像格式为 PNG，宽高像素值与生成视频一致，无水印。
- `false`：不返回尾帧图像。

可将上一段视频的尾帧作为下一任务的首帧，连续生成多个视频。

### `safety_identifier`

可选字符串。终端用户的唯一标识，用于协助平台识别应用中可能违反使用政策的用户。要求：

- 英文字符串；
- 对单个用户固定且唯一；
- 长度不超过 64 个字符；
- 推荐对用户名、用户 ID 或邮箱进行哈希后传入，避免泄露隐私。

### `seed`

可选整数，默认 `-1`，取值范围 `[-1, 2147483647]`；`-1` 表示使用随机数替代。

- 相同请求使用不同 seed（省略、`-1` 或手动修改）会生成不同结果。
- 相同请求使用相同 seed 会生成相似结果，但不保证完全一致。

支持 Seedance 1.5 pro、Seedance 1.0 pro 和 Seedance 1.0 pro fast。

### `service_tier`

可选字符串，默认 `default`：

- `default`：在线推理模式，RPM 和并发数配额较低，适合时效性要求高的场景。
- `flex`：离线推理模式，TPD 配额更高，价格为在线推理的 50%，适合对时延不敏感的场景。Seedance 2.5、Seedance 2.0 系列暂不支持。

已提交任务的服务等级不可修改。Seedance 1.5 pro、Seedance 1.0 pro 和 Seedance 1.0 pro fast 支持此参数。

### `tools`

可选对象数组。Seedance 2.5 和 Seedance 2.0 系列支持。

| 参数 | 类型 | 必选 | 说明 |
| --- | --- | --- | --- |
| `tools.type` | `string` | 是 | 工具类型。当前可选值为 `web_search`。 |

开启 `web_search` 后，模型根据提示词自行判断是否搜索互联网内容；这可以提升视频内容时效性，也会增加一定时延。实际搜索次数可从查询任务响应的 `usage.tool_usage.web_search` 获取，值为 `0` 表示未搜索。

### `watermark`

可选布尔值，默认 `false`：

- `true`：视频右下角展示“AI 生成”水印。
- `false`：视频不含水印。

## 响应参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `id` | `string` | 视频生成任务 ID。从 `created_at` 开始仅保存 7 天，超时后自动清除。 |

- 设置 `"draft": true` 时，返回 Draft 视频任务 ID。
- 设置 `"draft": false` 时，返回正常视频任务 ID。

创建视频生成任务是异步接口。获取 ID 后，应调用“查询视频生成任务”接口检查状态；任务成功后，响应中会提供 `video_url`。
