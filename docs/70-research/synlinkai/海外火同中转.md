# Seedance 火山中转调用指南（海外站）

## Base URL

- 海外直连：`https://synlinkai.com`
- 国内 GA 加速 url：`https://ga.synlinkai.com`

## Seedance

分组选择「Seedance-火山中转-RMB」，目前支持：

- `doubao-seedance-2-0-260128`
- `doubao-seedance-2-0-fast-260128`
- `doubao-seedance-2-0-mini-260615`
- `doubao-seedance-2-5-260628`

## 创建任务

`POST /v1/video/generate`

### 参数

- 官方参数，参考图/视频/音频直接使用 URL 即可，无法使用素材 ID。
- 支持参数：`model`、`content`、`duration`、`resolution`、`ratio`、`generate_audio`、`watermark`、`callback_url`、`return_last_frame`。
- 参数可参考官方文档：https://ark.volcengine.com/region:cn-beijing/docs/82379/1520757?lang=zh
- 素材无需预先上传：平台会在创建任务时自动拉取并预处理 `content` 中的素材 URL，因此不再需要单独的素材上传与查询步骤。素材 URL 需在任务创建期间保持公网可访问。

### Example

```bash
curl -X POST 'https://synlinkai.com/v1/video/generate' \
  -H 'Authorization: Bearer sk-你的key-xxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "doubao-seedance-2-0-260128",
    "content": [
      {
        "type": "text",
        "text": "这个人在跳舞"
      },
      {
        "type": "image_url",
        "image_url": {
          "url": "https://example.com/your-image.jpg"
        },
        "role": "reference_image"
      }
    ],
    "duration": 5,
    "resolution": "480p",
    "ratio": "1:1",
    "generate_audio": false,
    "watermark": false,
    "return_last_frame": true
  }'
```

### Response

```json
{"task":{"duration_seconds":5,"outputs":[],"created_at":"2026-09-07T12:15:23.552Z","model":"doubao-seedance-2-0-260128","id":"19ee97a7ddc74a489f74da10768d3487","status":"pending"}}
```

## 查询任务

`GET /v1/video/tasks/{taskId}`

直接返回火山 url。

### Example

```bash
curl "https://synlinkai.com/v1/video/tasks/{task_id}" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-你的key-xxx"
```

### Response

```json
{"task":{"completed_at":1788783405,"created_at":1788783323,"duration_seconds":5,"id":"19ee97a7ddc74a489f74da10768d3487","model":"doubao-seedance-2-0-mini-260615-max","outputs":["https://ark-acg-cn-beijing.tos-cn-beijing.volces.com/doubao-seedance-2-0/xxx"],"status":"completed","usage":{"completion_tokens":48400,"total_tokens":48400}}}
```

## 获取任务尾帧

需要请求的时候有设置 `return_last_frame: true`。

`GET /v1/video/files/{taskId}/last-frame`

### Example

```bash
curl 'https://synlinkai.com/v1/video/files/{task_id}/last-frame' \
  -H 'Authorization: Bearer sk-你的key-xxx' \
  --output last-frame.jpg
```
