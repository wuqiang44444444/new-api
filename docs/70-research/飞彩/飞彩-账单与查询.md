# 余额与任务查询接口文档

> **适用场景**：第三方软件 / 脚本通过 API Key 自动查询账户余额、用量和任务情况
> **服务地址**：`http://43.161.200.208`
> **更新日期**：2026-08-03

---

## 一、通用说明

### 1.1 鉴权方式

所有接口均使用 API Key（`sk-` 开头）鉴权，将 Key 放入请求头：

```
Authorization: Bearer sk-xxxxxxxxxxxxxxxx
```

- API Key 在管理后台「令牌」页面创建
- 每个 Key 只能查询**所属账户**的余额和自己的任务，无法查询他人数据
- 未携带 Key 或 Key 无效时，接口返回 HTTP 401

### 1.2 额度单位换算

本平台内部计费单位为 **quota**，换算关系：

```
¥1 = 500,000 quota
```

部分接口返回 quota 原始值，部分接口直接返回元（CNY），下文各接口已分别标注。

### 1.3 接口一览

| #   | 接口                                 | 方法 | 用途                      |
| --- | ------------------------------------ | ---- | ------------------------- |
| 1   | `/v1/dashboard/billing/subscription` | GET  | 查询账户总额度            |
| 2   | `/v1/dashboard/billing/usage`        | GET  | 查询账户已用量            |
| 3   | `/v1/tasks`                          | GET  | 查询任务列表（分页/过滤） |
| 4   | `/v1/videos/{task_id}`               | GET  | 查询单个任务详情          |

**账户余额 = 接口1 总额度 − 接口2 已用量**

## 二、接口详情

### 接口 1：查询账户总额度

```
GET /v1/dashboard/billing/subscription
```

**请求示例（curl）**

```bash
curl -H "Authorization: Bearer sk-xxxxxxxx" \
     http://43.161.200.208/v1/dashboard/billing/subscription
```

**响应示例**

```json
{
  "object": "billing_subscription",
  "has_payment_method": true,
  "soft_limit_usd": 200,
  "hard_limit_usd": 200,
  "system_hard_limit_usd": 200,
  "access_until": 0
}
```

**字段说明**

| 字段             | 类型   | 说明                                                                       |
| ---------------- | ------ | -------------------------------------------------------------------------- |
| `soft_limit_usd` | number | 账户总额度，**单位：元（CNY）**（字段名带 usd 是历史兼容，实际按人民币计） |
| `hard_limit_usd` | number | 同 soft_limit_usd                                                          |
| `access_until`   | number | 令牌过期时间戳（秒），`0` 表示永不过期                                     |

> 注：若该 Key 为「无限额度」，总额度返回固定值 `100000000`，表示无限制。

### 接口 2：查询账户已用量

```
GET /v1/dashboard/billing/usage
```

**请求示例（curl）**

```bash
curl -H "Authorization: Bearer sk-xxxxxxxx" \
     http://43.161.200.208/v1/dashboard/billing/usage
```

**响应示例**

```json
{
  "object": "list",
  "total_usage": 696
}
```

**字段说明**

| 字段          | 类型   | 说明                                                       |
| ------------- | ------ | ---------------------------------------------------------- |
| `total_usage` | number | 累计已用量，**单位：分**（1元 = 100分）。例：`696` = ¥6.96 |

**余额计算示例**

```python
total = 200          # 接口1 soft_limit_usd（元）
used  = 696 / 100    # 接口2 total_usage（分→元）
balance = total - used   # ¥193.04
```

### 接口 3：查询任务列表

```
GET /v1/tasks
```

返回当前 API Key 所属账户的视频任务列表，按提交时间倒序。

**查询参数**（全部可选）

| 参数              | 类型   | 默认 | 说明                                                            |
| ----------------- | ------ | ---- | --------------------------------------------------------------- |
| `p`               | int    | 1    | 页码，从 1 开始                                                 |
| `page_size`       | int    | 20   | 每页条数                                                        |
| `task_id`         | string | -    | 按任务 ID 精确过滤                                              |
| `status`          | string | -    | 按状态过滤：`SUCCESS` / `FAILURE` / `IN_PROGRESS` / `QUEUED` 等 |
| `action`          | string | -    | 按任务类型过滤，如 `textGenerate`                               |
| `start_timestamp` | int    | -    | 提交时间起始（Unix 秒）                                         |
| `end_timestamp`   | int    | -    | 提交时间截止（Unix 秒）                                         |

**请求示例（curl）**

```bash
# 查询最近 5 条任务
curl -H "Authorization: Bearer sk-xxxxxxxx" \
     "http://43.161.200.208/v1/tasks?p=1&page_size=5"

# 只查成功的任务
curl -H "Authorization: Bearer sk-xxxxxxxx" \
     "http://43.161.200.208/v1/tasks?status=SUCCESS"

# 查单个任务
curl -H "Authorization: Bearer sk-xxxxxxxx" \
     "http://43.161.200.208/v1/tasks?task_id=task_4MTVheaujXRADrd663bS3ixXyqBZv63F"
```

**响应示例**

```json
{
  "success": true,
  "message": "",
  "data": {
    "page": 1,
    "page_size": 5,
    "total": 4,
    "items": [
      {
        "task_id": "task_4MTVheaujXRADrd663bS3ixXyqBZv63F",
        "action": "textGenerate",
        "status": "SUCCESS",
        "progress": "100%",
        "quota": 1020000,
        "submit_time": 1785748915,
        "finish_time": 1785749141,
        "video_url": "http://43.161.200.208/v1/videos/task_4MTVheaujXRADrd663bS3ixXyqBZv63F/content"
      },
      {
        "task_id": "task_xzp3AxHPNmbDw5iFAhQKzfwYJ79uDwyP",
        "action": "textGenerate",
        "status": "FAILURE",
        "progress": "0%",
        "quota": 0,
        "submit_time": 1785697166,
        "finish_time": 1785697200,
        "fail_reason": "上游服务繁忙，请稍后重试"
      }
    ]
  }
}
```

**字段说明**

| 字段          | 类型   | 说明                                                                               |
| ------------- | ------ | ---------------------------------------------------------------------------------- |
| `task_id`     | string | 任务 ID                                                                            |
| `action`      | string | 任务类型（textGenerate = 文生视频）                                                |
| `status`      | string | 任务状态：`QUEUED` 排队中 / `IN_PROGRESS` 生成中 / `SUCCESS` 成功 / `FAILURE` 失败 |
| `progress`    | string | 进度百分比，如 `"100%"`                                                            |
| `quota`       | int    | 本次任务实扣额度，**单位：quota**（÷500000 = 元）。例：`1020000` = ¥2.04           |
| `submit_time` | int    | 提交时间（Unix 秒）                                                                |
| `finish_time` | int    | 完成时间（Unix 秒）                                                                |
| `video_url`   | string | 视频下载地址（仅 `SUCCESS` 时返回），**下载时必须携带 Authorization 头**           |
| `fail_reason` | string | 失败原因（仅 `FAILURE` 时返回）                                                    |

**分页字段**

| 字段        | 说明               |
| ----------- | ------------------ |
| `page`      | 当前页码           |
| `page_size` | 每页条数           |
| `total`     | 符合条件的任务总数 |
| `items`     | 任务数组           |

### 接口 4：查询单个任务详情

```
GET /v1/videos/{task_id}
```

**请求示例（curl）**

```bash
curl -H "Authorization: Bearer sk-xxxxxxxx" \
     http://43.161.200.208/v1/videos/task_4MTVheaujXRADrd663bS3ixXyqBZv63F
```

**响应示例（任务完成后）**

```json
{
  "id": "task_4MTVheaujXRADrd663bS3ixXyqBZv63F",
  "status": "completed",
  "task_id": "c52b94e08f1c11f1922e375cbab42bf2",
  "video_url": "http://43.161.200.208/v1/videos/task_4MTVheaujXRADrd663bS3ixXyqBZv63F/content"
}
```

**status 状态值**（与接口3的状态对应关系）

| 接口4 status | 含义                   |
| ------------ | ---------------------- |
| `queued`     | 排队中                 |
| `processing` | 生成中                 |
| `completed`  | 已完成，可取 video_url |
| `failed`     | 失败                   |

> 轮询建议：创建任务后每 5~10 秒查询一次，直到 `completed` 或 `failed`。4 秒 720p 视频实测生成约需 3~4 分钟。

## 三、完整代码示例

### Python

```python
import requests

BASE = "http://43.161.200.208"
KEY = "sk-xxxxxxxxxxxxxxxx"
H = {"Authorization": f"Bearer {KEY}"}

# 1) 查余额
sub = requests.get(f"{BASE}/v1/dashboard/billing/subscription", headers=H).json()
usage = requests.get(f"{BASE}/v1/dashboard/billing/usage", headers=H).json()
total = sub["soft_limit_usd"]          # 总额度（元）
used = usage["total_usage"] / 100      # 已用（分→元）
print(f"总额度: ¥{total:.2f}, 已用: ¥{used:.2f}, 余额: ¥{total-used:.2f}")

# 2) 查任务列表（最近 10 条）
r = requests.get(f"{BASE}/v1/tasks", headers=H, params={"p": 1, "page_size": 10})
data = r.json()["data"]
print(f"共 {data['total']} 个任务")
for t in data["items"]:
    cost = t["quota"] / 500000
    print(f"  [{t['status']}] {t['task_id']}  扣费 ¥{cost:.2f}")
    if t.get("video_url"):
        print(f"    视频: {t['video_url']}")

# 3) 下载视频（必须带 Key）
task_id = data["items"][0]["task_id"]
dl = requests.get(f"{BASE}/v1/videos/{task_id}/content", headers=H)
with open("video.mp4", "wb") as f:
    f.write(dl.content)
print("视频已保存 video.mp4")
```

### Node.js

```javascript
const BASE = 'http://43.161.200.208'
const KEY = 'sk-xxxxxxxxxxxxxxxx'
const H = { Authorization: `Bearer ${KEY}` }

async function main() {
  // 1) 查余额
  const sub = await fetch(`${BASE}/v1/dashboard/billing/subscription`, {
    headers: H,
  }).then((r) => r.json())
  const usage = await fetch(`${BASE}/v1/dashboard/billing/usage`, {
    headers: H,
  }).then((r) => r.json())
  const total = sub.soft_limit_usd
  const used = usage.total_usage / 100
  console.log(
    `总额度: ¥${total.toFixed(2)}, 已用: ¥${used.toFixed(2)}, 余额: ¥${(total - used).toFixed(2)}`,
  )

  // 2) 查任务列表
  const r = await fetch(`${BASE}/v1/tasks?p=1&page_size=10`, {
    headers: H,
  }).then((r) => r.json())
  console.log(`共 ${r.data.total} 个任务`)
  for (const t of r.data.items) {
    console.log(
      `  [${t.status}] ${t.task_id}  扣费 ¥${(t.quota / 500000).toFixed(2)}`,
    )
  }

  // 3) 下载视频
  const taskId = r.data.items[0].task_id
  const resp = await fetch(`${BASE}/v1/videos/${taskId}/content`, {
    headers: H,
  })
  const buf = Buffer.from(await resp.arrayBuffer())
  require('fs').writeFileSync('video.mp4', buf)
  console.log('视频已保存 video.mp4')
}
main()
```

## 四、错误码说明

| HTTP 状态            | 典型响应                             | 原因                             |
| -------------------- | ------------------------------------ | -------------------------------- |
| 401                  | `{"error":{"message":"无效的令牌"}}` | 未带 Key / Key 错误 / Key 已删除 |
| 401                  | `{"error":{"message":"令牌已过期"}}` | Key 已过有效期，需在后台重新生成 |
| 200 但 success=false | `{"success":false,"message":"..."}`  | 参数错误等，按 message 排查      |

**常见问题**

1. **浏览器直接打开 video_url 报"无效的令牌"**
   正常现象。video_url 下载必须在请求头携带 API Key，浏览器地址栏直接访问无法带 header。请用 curl / 代码下载，或在管理后台「任务日志 → 查看详情 → 结果链接」中点击（前端会自动携带登录态）。

2. **total_usage 数值很大？**
   注意单位是「分」，除以 100 才是元。

3. **任务列表里 quota 很大？**
   quota 是内部计费单位，÷500000 是元。例如 1020000 quota = ¥2.04。

## 五、安全建议

- API Key 等同于账户密码，请存放在第三方软件的服务端，**不要硬编码在前端/App 客户端**
- 建议为第三方软件单独创建 Key，并设置额度上限和有效期
- 如怀疑泄露，立即在后台删除该 Key 并重新生成
