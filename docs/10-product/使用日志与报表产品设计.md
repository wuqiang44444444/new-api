# 使用日志与报表产品设计

本文描述控制台已接入的使用日志和报表行为。账单金额、上游折扣与正式月账单以
[客户与上游对账单产品说明](客户与上游对账单产品说明.md)为准。日汇总生产容量、迟到记录覆盖和
核心 API 延迟仍需在目标部署验收。

## 1. 入口与权限

| 侧栏分区 | 页面 | 可查看的范围 |
| --- | --- | --- |
| 通用 | 使用日志 | 当前角色有权查看的最新已入库日志和单笔详情 |
| 个人 | 我的账单 | 当前登录用户的自然月账单 |
| 个人 | 我的用量 | 当前登录用户按日、周、月的用量，可按 API Key 缩小范围 |
| 管理员 | 账单对账 | 客户账单与上游 URL、渠道对账 |
| 管理员 | 用量统计 | 客户用量与上游用量，均支持日、周、月 |

管理员访问个人区时，范围仍是自己的账单与用量。个人视图仅显示客户模型和自己的 API Key，
渠道、上游模型、上游参考费用及管理审计字段仅在对应的授权范围内查看。

## 2. 使用日志

普通日志列表默认读取最近一小时。关系库按游标翻查，ClickHouse 按页码翻查。可按权限允许的条件
筛选，使用 Request ID 定位记录。单笔详情展示可见的用量、计费解释和扩展信息。精确范围统计由用户按需触发。
使用日志反映已入库记录，账单下钻则保留所选账期、身份、模型、计费方式和报表或正式版本范围。

## 3. 发布状态

个人和管理用量默认显示昨天。日、周、月统一使用北京时间，自然周为周一至周日。关系型日志部署
在每天 03:00 后生成昨日汇总，首次自动补齐最近 90 个已结束自然日，当天每三小时生成阶段性统计。
生成受核心 API 流量优先级和资源约束，页面继续提供上一批有效结果。

账单显示已发布天数、应发布天数、覆盖不完整天数及阶段性数据截至时间。用量显示所选周期、快照时间、
未发布及部分数据状态，当日已发布时标明估算。逐日列表区分未到日期、未发布、部分数据及已发布的
无用量日。下钻或申请导出时保留当前报表版本；重新查询后可看到新版本。正式月账单按其独立版本查看。

## 4. 账单与费用明细

个人账单按 API Key 与客户模型查看。管理员客户账单先展示全客户结果，进入单客户后可按 API Key
或渠道核对。上游对账按冻结的 URL × 渠道查看，再进入上游模型和逐笔证据。

客户账单按入账日计费，净额等于已入账扣款减退款。默认明细按发生日与可核验的调用或任务身份合并，
一行显示净额，负值表示净退回。展开费用明细可核对扣款、退回及逐笔事件。无法核验归属的事件独立显示，
已知金额仍计入所属账期。正式月账单从冻结明细读取同样的分组，逐笔 CSV 保留资金事件粒度。

客户用量将可核验的售后退款归到原任务完成日，退款本身不增加调用次数。客户账单与用量各自显示已入账
净费用。视频任务确认应退款超过 24 小时且仍未退清时，授权范围内显示「待退款」。单客户账单读取当前待退款
计数，用量随报表版本刷新。个人用量仅在全 API Key 视图显示该列表。实际退款入账后再冲减净额，
客户退款与上游参考金额各自核对。

例如，任务周一完成并扣费 100 quota，周三退回 30 quota。账单在周一显示净费用 100，周三显示净退回
30，两天合计 70。用量在退款纳入报表后将周一更新为 1 次调用、净费用 70，周三新增调用数为 0。

## 5. 个人与管理用量

我的用量、管理员客户用量和上游用量的模型表均在调用次数后显示失败次数。失败沿用各视角已记录的
结果分类，上游只统计已证实发送的尝试。用量排行和账单列表显示总行数与当前页／总页数，可选择每页
行数、翻页或跳到可见页码。切换每页行数后回到第一页。

- **我的用量**展示调用结果、总 Token 与输入、输出、缓存明细，以及非 Token 计量和客户净费用。
  模型排行可按调用次数、总 Token、净费用查看。所选 API Key 同步限定汇总、模型数据和导出。
  月视图可查看逐日用量。页面可跳到所选月份的「我的账单」。
- **管理员客户用量**默认展示全部客户的总览和模型分布。通过右上角客户筛选按显示名称或 ID 查找并选择
  客户，查看该客户的模型排行和待退款。排行的「总 Token」列展示输入、输出、缓存、已记录的媒体 Token
  和未记录条数。可在导出抽屉选择客户模型。周、月视图展示周期汇总；查看某一天时，在顶部切换到「每日」
  并选择日期。
- **管理员上游用量**按已发布的 URL 和渠道筛选。渠道排行按调用次数、总 Token 或折后参考金额分页，
  可进入单渠道查看上游模型占比。周视图的逐日表可打开已发布日期，返回时保留原周和版本。月视图展示月度汇总。
  上游用量表格行直接展示可用数值，缺项通过未记录或待核算状态提示。
- 用量与报表共用导出记录。CSV 提交固定周期、范围及所读日版本。个人和管理员客户用量的相同有效结果
  可复用，上游用量通过「生成 CSV」提交。已有文件和进度从导出记录查看，单文件直接下载，分片可展开选择。
  所选客户模型没有匹配记录时返回空结果，失败则显示安全的原因分类。

## 6. 用户可观察验收

- 同一账号的个人入口与管理入口遵守各自权限。个人页面和 CSV 只包含可见的客户数据。
- 在相同筛选和报表版本下，汇总、下钻与导出的金额、用量及缺项状态一致。总览覆盖完整匹配范围。
- 同日扣退款可展开为原流水，跨日退款的账单入账日与用量任务完成日分别可核对。
- 没有已发布日、已有但覆盖不完整、以及确认无用量时显示不同状态。已确认月账单可继续查看和下载。
