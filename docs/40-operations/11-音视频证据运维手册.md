# 音视频证据运维手册

## 启用与配置（启动期环境变量）

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `TASK_REQUEST_EVIDENCE_ENABLED` | `false` | 唯一新增采集总开关；只有显式 `true` 开启。未配置或其它值都不采集，单独提供加密密钥不启用。显式开启后仅采集已登记媒体操作；早期方案的 `TASK_REQUEST_EVIDENCE_TYPES` 已移除，不提供 `all` 别名 |
| `TASK_REQUEST_EVIDENCE_STORAGE_DIR` | `data/task-request-evidence` | 加密对象目录（独立命名空间，权限 0700/0600）；装配不创建目录 |
| `TASK_REQUEST_EVIDENCE_ENCRYPTION_KEY` | 无（派生） | 64 位 hex（32 字节 AES-256-GCM 密钥）。未配置时从 CRYPTO_SECRET/SESSION_SECRET 派生；生产环境建议显式配置。密钥是加密参数，不产生采集资格 |
| `TASK_REQUEST_EVIDENCE_MAX_BODY_BYTES` | 8388608 | 北向/南向捕获上限；超限只停止留存，业务正文不截断、不拒绝 |
| `TASK_REQUEST_EVIDENCE_MAX_RESPONSE_BYTES` | 33554432 | 上游响应捕获上限；超出部分不留存，转发不受影响 |
| `TASK_REQUEST_EVIDENCE_WRITE_TIMEOUT_SECONDS` | 5 | 文件写入的有界等待（最多 8 个在途写入）；超时只丢失对应证据，不拒绝发送，也不强制取消底层文件系统操作 |
| `TASK_REQUEST_EVIDENCE_RETENTION_DAYS` | `7` | 只允许整数 1～7；正文与事件明细滚动保留天数，正文回收后物理删除明细，索引七天到期后删除。不再支持 `0` 永久保留或超过七天 |

密钥轮换：更换密钥后旧对象无法解密，读取会返回明确失败；轮换前应先等待保留期清理完成或迁移对象。

## 部署示例与升级

启用请求证据时只新增/调整以下环境项（合并进原有 `environment`，保留现有稳定密钥与数据挂载）：

```yaml
services:
  newapi:
    environment:
      - TASK_REQUEST_EVIDENCE_ENABLED=true
      - TASK_REQUEST_EVIDENCE_RETENTION_DAYS=7
```

`ERROR_LOG_ENABLED` 继续独立控制错误日志，不控制正文采集。环境变量在启动期加载，仅执行
restart 不会更新容器环境；从默认开启的旧版本升级时，必须重建服务并让全部实例升级一致，避免旧
实例继续按旧行为全量落盘。暂不启用时不配置启用变量即可默认关闭；保留历史存储配置供读取与清理。

## 权限与审计

Admin/Root 可查询索引列表与内容目录，目录不读取正文；普通用户无权访问。
选中一条内容后，`GET /api/task_request_evidence/{id}/events/{event_id}/content` 返回原始正文和
捕获元数据；`/object` 下载完整已存对象。上游诊断索引列仍仅 Root 返回。所有接口禁止缓存。
目录、原文查看与下载分别发起 `view/directory`、`view/original`、`download/original` 访问审计。

### 排障时查看实际 HTTP 交换

错误、任务、使用日志和独立查询共用查看入口。先按 Task ID 或平台请求 ID 找到内容目录，再选择
客户请求、最终南向请求、上游响应、轮询或交付内容。目录展示 HTTP 元数据；原始头和查询参数仅在
选中对象后返回。原文可能包含仍有效的凭据、签名 URL 与素材源 URL，不得复制到普通日志或工单。

正文默认 raw 展示，可主动格式化合法 JSON 或预览位图；格式化不修改存储，精确数字以 raw 为准。
破损 JSON、SSE、multipart、空白、截断和二进制均允许保存已有字节。统一提示捕获可能不完整，
不再展示每条内容的完成状态、阶段状态、字节统计或脱敏承诺。二进制不能按文本解释时仍可下载。
关闭弹窗、切换记录或登录身份时取消正文请求并清除缓存。列表和目录不会提前下载所有正文。

本地目录必须使用持久化挂载；多实例共享目录及密钥。单机临时目录不能作为跨实例证据存储。

## 故障与处置

- 取证的配置、索引、采集或存储故障只影响证据，不改变业务响应、Provider 调用次数、Task 或资金。
- `missing`：有事件位置但对象缺失；`expired`：窗口已关闭；`decrypt_failed`：解密或认证失败；
  `storage_unavailable`：存储未装配；`read_failed`：实际读取失败。不把这些状态当作未发送的证明。
- 日志 `evidence save unavailable` 仅包含净化的步骤、内容名称和原因，用于排查存储权限及写入延迟。
- durable attempt 发送资格无法核实仍拒绝发送并保留 unknown/资金语义；不能仅凭 503 补发或退款。
- 删除对象失败不标记回收完成，下次清理重试。历史已脱敏对象不能恢复成原文，也不在升级时重写。
- 正式恢复输入与结果对象不是可丢弃证据；它们的业务可用性仍由各自存储和状态机校验。

## 验收边界

媒体开关覆盖已接入的实际媒体交换，不保证任意 WebSocket 帧或未绑定后台 context 的南向交换。
当前覆盖矩阵和明确缺口见[请求证据架构](../20-architecture/音视频请求证据架构.md#覆盖矩阵与验证边界)。


## 媒体请求证据与手动清理

显式开启后仅采集已登记图片、音频、视频和素材操作，覆盖已接入的后台媒体 Task 执行。
普通聊天、Responses、Gemini 通用多模态、Embedding/Rerank、Batch/通用文件排除；成功、失败
和本地拒绝均留证。管理面和自身查询维护不产生正文；Link 素材 source URL 仅可随原文进入受保护证据。
覆盖边界与缺口见架构文档。

任务受理路径上任务证据会话持有同一交换的证据时，通用观察器不重复落盘；每次实际 HTTP 交换只
保留一份阶段证据。关闭采集（`TASK_REQUEST_EVIDENCE_ENABLED=false`）只停止新增正文；期限内
历史证据继续可读，存量正文仍由每小时系统任务按七天政策自动回收。部署时核对实际目录大小、
磁盘/inode、最旧未清理到期时间与清理失败计数；连续失败或超过两个调度周期没有成功执行说明
清理停摆，需人工介入。

Root 手动清理：系统管理 → 日志维护 →「清理请求证据」。选择截止时间（默认七天前，提供
24 小时/7 天快捷项），确认后创建后台任务；截止时间与操作者持久化在任务上，执行与重试始终
使用原有边界。受理时把任务与当前截止范围的清理申请一并提交；候选严格为索引创建时间早于
截止点，等于截止点保留，不混入其它自然到期记录。申请立即关闭读取与追加；即使任务在扫描前
取消或重启，已接受的范围仍由后续自动任务重试。已有清理任务运行时提交返回忙碌及
当前任务信息；页面展示扫描/清理/删除/失败计数与真实释放字节，中英文均完整。

新对象由 v2 标记行、元数据 JSON 和未改写正文组成，使用事件 ID 定位，不依赖事件 object_key
非空或完成状态。对象不可覆盖；创建行后写入失败允许留下缺失对象的位置，读取时再报告。

普通请求只观察实际读取。鉴权或校验拒绝先交付响应，再在 100ms 读期限内补采输入；超过期限只保留
已有前缀，尚未到达的数据不补造。HTTP server 使用 `APIRequestEvidenceHTTPHandler` 提供读期限。
通用观察器与任务会话对同一交换去重；头、查询和正文只在私有加密对象中原样保存。

清理运行结果查看系统任务历史（`task_request_evidence_retention`）：每轮含开始/结束时间、触发
方式与清理截止、扫描数、成功清理索引数、成功删除文件数、移除对象字节、对象已不存在数、失败数
与未归属文件数量，以及删除事件/索引/访问审计/证据任务历史行数和数据库失败数。字节按实际被移除对象的文件长度统计；缺失对象不计入字节。文件系统空闲空间
还受分配块、打开的文件和在途暂存影响，必须单独核对，不将此计数冒充即时磁盘可用空间。删除失败不标记正文过期，下一轮自动重试；目录不可用
或无存储句柄按失败报告，不伪装清理成功。

## 清理监控与异常残留

日志维护只向 Root 显示证据清理。确认窗口说明截止时间、浏览器时区、包含全部类型的历史证据及不可恢复性；
后台失败仍可查看本轮实际删除结果。刷新恢复最近任务；系统任务历史可按“请求证据清理”筛选并
展开详情，按“证据清理监控”查看独立健康检查。

独立监控每十五分钟运行，即使正文采集关闭仍继续。检查连续两次失败、超过两小时无成功及积压；
同时观察证据根目录所在文件系统的可用字节/inode。磁盘使用率使用既有磁盘告警阈值，inode 使用率
达到 95% 时告警；inode 不可用显示未知。告警写后端 warning 日志和系统任务结果，部署方可将这些
净化类别接入现有日志告警平台；这不代表已配置邮件、Webhook 或生产告警接收渠道。

已到期或已申请清理的证据目录内，未匹配事件的正文及暂存也会被回收；无数据库索引的
孤儿正文按文件修改时间执行保留期限或手动截止，实际删除计入文件数及移除字节。
清理只关闭证据观察窗口。正在创建、执行、轮询或交付的业务继续，正常关闭不会成为发送拒绝或
退款原因；晚到对象仍须经过索引锁检查，不能恢复原文或重新生成索引。真实取证故障输出净化诊断，不改变业务；同时发生清理也不扩大或恢复观察窗口。
`directory_cleanup_failed` 与非零未归属文件数表示本轮仍未成功回收的残留，应核对权限、
异常子目录或文件系统故障，不表示无匹配正文被永久豁免。旧版升级后的 NULL 申请标记
按未申请处理，下一次申请会确认实际落库；不要自行将未成功删除的正文标记完成。

最终对象链接在实际 worker 中与主库清理申请互斥；调用方超时不能绕过这一步。没有共享持久卷的
多个实例不能据此获得跨节点物理存储一致性，部署仍须共享同一正文命名空间和稳定密钥。真实流量
容量、连续周期、文件消失、目录回收及磁盘/inode 余量仍需按生产副本和灰度验收。

## 数据库回收与媒体范围

采集仅纳入已登记图片生成/编辑、音频转写/翻译/TTS/音乐生成、视频及素材操作。普通聊天、
Responses/Gemini 通用多模态、Embedding/Rerank、Batch/通用文件和模型列表排除。历史非媒体
数据仍按到期策略回收，升级不默认提前删除七天内历史证据。

正文和事件明细默认七天（正文配置可缩至 1–7 天），索引七天，访问审计从访问起七天。
手动提前清理会删除正文和事件明细，最小关闭索引保留到七天，防止活动任务恢复取证。
后台复用同一 Task 证据与可信创建时间，不因轮询/查询或索引删除续期；无可靠时间跳过取证。

删除严格为申请关闭 → 分页删对象 → 标记正文完成 → 分批删事件 → 到期删索引。
数据库回收失败不会恢复读取，BodyExpired 行继续进入数据库回收队列。历史 BodyExpired 残留
文件和孤儿事件先删对象再删行；无事件记录的正文独立回收，实际 IO 失败保留定位依据并告警。
只枚举证据专属根目录和数字命名空间，不跟随目录符号链接或进入正式资源目录。所有实例必须升级一致。

证据清理/监控 SystemTask 历史三十天回收，活动与最新调度行保留；报告中其它约七千条/天
系统任务历史需独立治理，不通过本次证据期限通删其它类型。Root 页面显示数据库待回收数量、
最老时间及删除行数；行数不等于物理空间。SQLite 删除后先复用 freelist，缩小数据库文件另行
安排维护窗口，不在小时任务内 VACUUM。生产验证要观察新增/删除速度、积压与数据库页复用，
不能只观察文件目录下降。
