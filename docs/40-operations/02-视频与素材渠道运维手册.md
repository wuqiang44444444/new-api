# 02 视频与素材渠道运维手册

## 1. 先区分两类渠道

- `DoubaoVideo` 是 NEWAPI 原生渠道，客户端使用 `/v1/video/generations`。
- `Seedance Link` 是 Seedance 专用渠道，客户端只使用 ModelArk V3 的 create/get/list/delete 四组
  `/api/v3/contents/generations/tasks` 接口。

不要为了复用已有配置把 Seedance 模型放进 `DoubaoVideo`。一个已启用 Seedance 客户模型只能出现在
一个 Seedance 渠道；不同 Provider 或不同账号必须使用不同客户模型名。

## 2. 新建 Seedance 渠道

1. 新建渠道并选择 `Seedance Link`。
2. `Models` 填客户看到的模型名；`Model Mapping` 明确映射到 Provider 模型或 Endpoint ID。
3. 选择代码内置的“Seedance 视频协议”。管理员不填写创建/查询路径或 JSON 转换规则。
4. 填 Base URL 与单个视频 API Key。Seedance 不支持多 Key。
5. 如需素材库，选择一个素材协议或 `none`，并填写该协议明确要求的普通字段。
6. 配置客户模型价格、Group 和 Ability；先保存为禁用状态。
7. 完成真实创建、查询、删除、下载与账单验收后再启用。

Priority 和 Weight 对 Seedance 无效。系统不会随机选渠，也不会在失败后换到另一个 Provider 重新创建。

## 3. 协议配对

| 视频协议 | 素材协议 | 说明 |
| --- | --- | --- |
| `modelark_v3_volcengine` | `volcengine_assets_action_v2024_01_01` 或 `none` | 国内火山官方；素材另用 AK/SK、Project，Region 固定为 `cn-beijing` |
| `modelark_v3_byteplus` | `byteplus_assets_action_v2024_01_01` 或 `none` | 海外官方；素材另用 AK/SK、Project、Region |
| `media_task_v1` | `relay_assets_v1` 或 `none` | Moxing/TokenSave 类中转协议 |
| `ark_media_v1` | `ark_assets_v1` 或 `none` | Ark 反代协议 |
| `url_media_arrays_v1` | `none` | URL 媒体数组（仅 URL，不支持素材库）；飞彩类线路 |
| `funcloud_seedance_v2` | `none` | FunCloud；Standard/Fast 由 Provider 模型名选择代码路径 |

保存或启用时会拒绝多 Key、未注册协议、错误协议配对、缺少素材 TTL，以及官方素材缺少
Project/Region/AK/SK。国内火山素材 Region 只接受 `cn-beijing`。请求时不会再重复扫描或修复管理员
绕过后台写入的非法配置。

## 4. 素材库配置

素材与视频固定使用同一 Seedance Channel、账号、Region/Project 和协议。一个模型只能选择官方素材、
第三方素材或无素材库三种之一，不能同时配置多套素材线路。

BytePlus 官方素材使用两套凭据：渠道 Key 是视频 API Key；素材 AK/SK 只用于官方 Action。编辑时 AK/SK
同时留空表示保留，同时填写表示轮换。不要把素材 AK/SK 填入渠道视频 Key。

素材源 URL 只用于本次 Provider 创建，平台不保存二进制，也不在创建完成后保存源 URL。素材失败不会
自动迁移、重新物化或换渠道；记录 `request_id` 后交给技术人员分析。

## 5. 真人素材

真人能力通过 `POST /v1/asset-groups` 创建 `real_person` 组。响应返回 Provider 官网认证地址；平台不
采集人脸、不自建认证表单，也没有独立真人授权、撤回或重试后台。认证完成后查询组状态，达到
`ready` 才可向该组创建真人素材。

## 6. 上线与停流

上线至少验证：真实 Provider 凭据、客户模型到 Provider 模型映射、所有收费维度、一次创建、终态状态、
内容下载、素材引用、删除行为和账单。未完成验证的模型保持禁用。

发生模型误路由、重复 Provider POST、价格低于成本、素材账号/Region 不一致、凭据或签名 URL 泄露时，
立即禁用该客户模型所在的唯一渠道。停流不改变在途 Task 的冻结渠道和计费事实。
