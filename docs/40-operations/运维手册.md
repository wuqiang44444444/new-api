# 运维手册

## 1. 适用范围与前置条件

本手册适用于渠道配置、生产灰度与停流。开始前按[环境配置](环境配置.md)确认站点可达性和告警，
按[运维索引](README.md#阅读顺序)选择适用的渠道、素材、合同或数据库专题。用目标账号验证供应商权限，
以实际接口和账单核对模型、费用与交付结果。

## 2. 标准上线顺序

1. 确定公开模型名和审批售价。
2. 配置模型价格、消费分组和测试用户。
3. 新建独立渠道，填写上游地址、凭据、路由和模型映射。
4. 检查异步任务、素材和真人能力所需配置。
5. 先限定在隔离测试范围，按[05 全渠道上线验收手册](05-全渠道上线验收手册.md)完成真实创建、查询、下载和计费核对。
6. 完成失败、超时、退款和“不重发、不换渠”用例。
7. 加入生产分组，小流量观察一个完整结算周期。
8. 记录配置版本、变更人、时间、测试任务 ID和回滚值。

## 3. 通用操作规则

- 价格只配在客户端公开模型名上。
- 渠道 `Models`、公开路由和价格使用客户模型名；`model_mapping` 单独保存客户模型到 Provider 模型的精确转换。
- Seedance ModelArk V3 不接收客户幂等键；结果不明时停止重试并交给技术人员核查。其它原生接口按各自
  合同处理幂等。
- 在途异步任务使用创建时冻结的渠道、凭据和计费快照。
- Seedance 渠道使用单个视频 Key；需要独立素材凭据或本站托管图片时按[渠道配置清单](07-Seedance渠道配置清单.md)操作。
- 不把上游 Key、签名 URL、同意 URL、上游资源 ID或完整响应写入文档、截图、群聊和普通工单。
- 回滚时保留轮询与计费事实，不删除 Task、create attempt 和计费日志。

## 4. 立即停流条件

出现以下任一情况，先停用受影响的入口或渠道，确认新请求已停止：

- 公开模型路由到错误上游模型；
- 动态表达式没有有效 usage；
- 售价低于已确认上游成本；
- 任务进入 `debt`；
- 单次 Seedance 创建产生多个上游任务；
- 失败或超时发生重复退款；
- 素材账号、Project、Region 或凭据指纹不一致；
- 日志或响应泄露 Key、签名 URL、同意 URL或上游 ID。

停流后继续处理在途任务、轮询、退款和删除，完成对账后再恢复。

## 5. 发布检查

- [ ] 公开模型名、模型映射和分组一致。
- [ ] 模型价格和分组倍率已由第二人复核。
- [ ] 真实成功请求和真实失败请求均已验收。
- [ ] 异步任务完成、退款和幂等已验收。
- [ ] 素材或真人能力已执行专项验收。
- [ ] 用量日志与上游账单一致。
- [ ] 监控、告警、变更记录和回滚值齐全。
