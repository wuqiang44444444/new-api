# 04 无状态素材代理验收操作手册

## 1. 准备

准备测试 API Key、一个已启用素材协议的 Seedance 客户模型，以及 Provider 可访问的 HTTPS 测试素材。
真实 Key、完整签名 URL、认证 URL、Provider ID 和原始响应不得进入截图或工单。

## 2. 创建与单项查询

```bash
curl -sS -X POST "$API_BASE/v1/assets" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d "{
    \"name\": \"ops-reference-image\",
    \"asset_kind\": \"general\",
    \"media_type\": \"image\",
    \"model\": \"$TEST_MODEL\",
    \"source\": {\"type\": \"url\", \"url\": \"$SOURCE_URL\"}
  }"
```

通过标准：HTTP 201；`id` 是 Provider opaque ID，`model` 是客户模型；可用时返回
`asset://<opaque-id>`。响应不得包含 source URL、Provider、Channel ID、账号、Region/Project、协议、
凭据或上游原始模型。

调用方保存 `model + id + reference`，并使用以下单项接口查询：

```text
GET /v1/assets/{id}?model={customer_model}
```

不得存在 `GET /v1/assets` 或 `GET /v1/asset-groups` 列表路由。

## 3. 跨模型与视频直通

先查询两个客户模型的 `api.assets.reuse_scope`。只有两个非空值完全相同时，才分别使用每个客户模型查询
同一个 opaque 素材组 ID 和素材 ID；scope 不同或缺失时不得测试跨模型复用。结果只记录为 Provider
当次行为；scope 相同不构成所有权或永久兼容承诺。

在 ModelArk V3 媒体字段中传 `asset://<opaque-id>`。通过标准：请求到达当前客户模型选定的 Provider，
平台不查询素材、不验证所有权、应用、ready、模型、Channel、账号或地域，也不在失败时切换 Provider。

## 4. 错误与不支持

- 使用元数据中 `api.assets.supported=false` 的模型创建素材，应返回 HTTP 422
  `unsupported_asset_operation`，且不产生 Provider 请求。
- 将另一个 Provider 的已知素材 ID 交给当前模型，只允许请求当前模型选定的 Provider；返回脱敏错误，
  不得出现 Provider 名称、上游原始模型、Channel 或 fallback。
- 单项查询成功不是生成前置条件，也不保证稍后的生成一定成功。

## 5. 真人素材组

`POST /v1/asset-groups` 必须包含客户 `model`。普通组返回 Provider opaque 组 ID；真人流程返回 opaque
会话/组 ID 和 Provider 认证 URL。调用方在上游页面完成认证，并使用：

```text
GET /v1/asset-groups/{id}?model={customer_model}
GET /v1/asset-groups/{session_id}?model={customer_model}&verification_session=true
```

平台不得代理或收集人脸、活体、证件或授权表单。

## 6. 删除与验收清单

删除必须携带创建时保存的客户模型和 opaque ID。失败按脱敏普通错误返回，不建立本地 unknown、自动
重试、孤儿扫描或人工修复状态。

- [ ] 单资源 CRUD 均按客户模型执行 Token 模型授权。
- [ ] 不存在素材或素材组列表、平台 Asset/AssetGroup 映射、resolver 或所有权索引。
- [ ] source URL、媒体二进制、Provider 名称和上游原始模型不进入公开响应或普通日志。
- [ ] 视频 `asset://<opaque-id>` 不触发本地素材可用性和作用域校验。
- [ ] 错误 ID 只进入当前 Provider，失败不换渠道、不探测其它 Provider。
- [ ] 不支持的模型和操作明确返回 `unsupported_asset_operation`。
- [ ] `reuse_scope` 相同的模型按同一素材域验收；不同或缺失时不跨模型发送 ID。
- [ ] 真人认证只返回上游地址，不存在平台真人授权、撤回或自建 H5。
