# 用户模型合同管理界面

## 1. 用户列表

用户名旁显示四种合同摘要：

| 状态 | 文案与语义 |
| --- | --- |
| 原生 | 原生模式，无合同约束 |
| 生效 | 合同已生效，并显示规则数 |
| 零权限 | 合同已生效但规则数为零，使用危险状态色 |
| 停用 | 合同已停用，并显示保留规则数 |

行操作菜单提供“管理模型合同”，不把合同字段混入通用用户资料抽屉。

## 2. 合同侧边栏

侧边栏使用宽桌面布局和小屏近全宽布局。头部显示用户名、User ID、模式、规则数和版本；主体包含“合同
配置”和分页“审计历史”两个页签；底部固定取消、启停和保存操作。

配置顺序固定为：

```text
渠道组 -> 多选当前可履约模型 -> 批量折扣 -> 逐规则调整 -> 价格预览 -> 变更原因 -> 保存
```

折扣接受小数、百分比和中文折扣写法，在输入结束后归一为最多八位的小数显示。仅大小写不同的模型不能
同时加入同一合同。新添加但尚未保存的规则也必须立即显示当前价格；tiered 模型显示“阶梯价格 × 折扣”。

## 3. 风险与恢复

- 特殊原生组倍率显示叠加提示。
- 删除最后一条规则显示零模型权限空状态。
- 停用合同和丢弃未保存更改都需要确认。
- 版本冲突不允许盲目重试；界面加载服务端最新版本并提示重新确认。
- 系统设置修改组倍率时，若影响生效合同，保存前显示合同数、规则数和渠道组。

## 4. 普通用户只读区域

API Key 页面只在合同生效时显示用户级合同价格卡片，字段限于公开模型、折扣、当前折后价格和可用状态。
该区域不是单 Key 配置；不展示渠道组、Channel、Provider、上游模型、合同审计或内部错误原因。读取失败
显示明确失败状态，不回退展示原生价格。
