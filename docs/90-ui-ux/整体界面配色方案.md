# TokenAI 整体界面配色方案

五套配色用于比较 TokenAI 的视觉方向。设计稿统一使用「我的用量」、2026 年 10 月账期与同一组虚构统计值，便于对照色彩、排版和首屏信息。公开站、客户控制台与管理后台的组件、权限及状态规则沿用[整体界面重构设计方案](整体界面重构设计方案.md)。

## 青玉绿

![青玉绿设计稿](assets/ui-redesign/theme-jade.png)

白底侧栏配淡青玉选中区，浅绿摘要带串起净费用、调用和计量值。趋势采用绿线，图表下方用带占比条的排行承接模型查询。公开站可延伸到模型分类、价格与接入按钮，控制台使用浅色画布与紧凑表格。成功状态需要独立图标和文字，避免与品牌绿选中态混淆。

## 紫藤

![紫藤设计稿](assets/ui-redesign/theme-wisteria.png)

用顶栏和紫色下划线标记当前页面。将统计摘要放在左列，趋势放在右列，模型表在下方横贯主区。适合让模型目录、API 文档和体验入口共享较开放的顶栏布局。管理页仍可使用同一配色，为密集数据保留独立侧栏。

## 暖纸砖红

![暖纸砖红设计稿](assets/ui-redesign/theme-terracotta.png)

暖白底、棕墨文字和细分隔线，页面以对账单式顺序组织。先读报告范围和净费用，再读模型费用表，趋势作为旁证。模型详情页可沿用这种排版，把价格单位与调用示例排在同一阅读线上。品牌砖红用于入口和当前选择，错误需要醒目的独立文字和图标。

## 石墨琥珀

![石墨琥珀设计稿](assets/ui-redesign/theme-amber.png)

深石墨画布、短标签和紧凑表格，琥珀色只集中在主要操作、当前选择、焦点和主数据系列。首屏让管理员快速扫读模型、失败次数及净费用。可延伸到渠道、审计和任务排障；窄屏需让日期和 Key 筛选可独立操作。预警使用独立的警告图标与状态文字，避免与常规选择混淆。

## 墨灰

![墨灰设计稿](assets/ui-redesign/theme-mono.png)

以黑、白及中性灰建立层次，侧栏使用线性图标，正文通过大字净费用、留白和黑线趋势形成阅读顺序。图表状态用线型、标记与文字区分。适合延伸到文档、Playground 和设置页，风险、成功等业务状态仍可使用语义颜色与文字。

## 实现与验收

- 颜色映射到现有 shadcn/ui 语义变量，覆盖背景、表面、正文、主操作、焦点、选中项和图表。悬停、禁用、焦点与状态文字使用各主题的对应配色，组件结构沿用现有 Base UI。
- 上表的正文与画布、主操作文字与主操作底色两组搭配，在五套配色中均达到 `4.5:1`。落实到组件后，再对次要文字、输入边框、焦点环、图表图例和状态逐项检查。
- 五张图用于桌面静态评审。移动端布局、其他页面及主题样式的实际验证沿用[备选方案](整体界面重构备选方案.md)和[整体方案验收](整体界面重构设计方案.md#4-推广顺序与验收)。
