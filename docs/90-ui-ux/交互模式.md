# 交互模式

## 派生字段

由代码注册事实决定的字段使用只读投影，不让用户自由拼装。投影必须由单一函数全量计算；输入变化、
方案切换或解析失败时同时更新或清空所有受管字段，不能保留上一方案的路径、profile 或 route。

## 敏感变更确认

普通表单保存不得隐式执行合同变更。需要修改稳定 publication 时使用独立确认对话框，固定展示对象、
当前值、目标值和版本，要求填写原因，并只向具备敏感写权限的管理员开放。

## 并发与错误反馈

- 参数或目标 SKU 无效：指出需修正的字段，不建议重试；
- publication 不存在：刷新当前对象并重新检查发布流程；
- 版本或并发冲突：关闭盲目重试，刷新最新版本后重新确认影响；
- 暂不可履约：保留已发布身份，明确它与“模型不存在”不同。
