# 交互模式

## 代码协议字段

管理员选择代码已经注册的视频协议和素材协议，不编写 JSON 映射、响应脚本或状态机。协议变化时，
表单只显示该协议真正需要的普通配置字段；未选择素材库时隐藏素材专用字段。

Seedance 选择非 `none` 素材协议时，表单必须说明“当前 Channel 即素材租户边界”并列出共享模型。已有
素材边界的凭据轮换通过确认弹窗要求管理员声明租户未变化。Base URL、视频/素材协议、Project 或 Region
发生变化时，不跳转页面、不打开新的配置抽屉：在当前渠道编辑界面就地显示“本次保存将替换素材租户”、
精确字段差异和旧/新值；点击原保存按钮后复用现有确认弹窗，要求勾选“旧素材 ID/引用可能不可用”再
提交。Channel Type 变化继续明确拒绝。模型卡片、表格和详情使用从 `reuse_scope` 哈希前缀派生的匿名
“素材共享组”标签；前缀碰撞时增加长度，同组提示只列当前可见客户模型，不显示 Provider、Channel 或
上游模型。

已保存且素材协议支持组创建的 Seedance Channel，在高级设置的“连通性测试”卡片中、只读测试按钮下方
显示“默认素材组”状态与“创建或复用默认素材组”动作。状态加载期间和请求执行期间按钮禁用；存在未保存
协议或凭据变化时提示先保存；成功后就地切换为“已配置”。不支持组创建的协议不显示该动作，页面只显示
固定系统名称 `aigctokenaigeneral`，不展示 Provider opaque group ID。该动作会创建 Provider 资源，因此
每次点击都由管理员主动触发，但不是破坏性操作，不增加确认弹窗。

## 模型命名最小关注面

管理员在渠道配置中只操作客户模型名（`channels.models`）和真实模型名（`model_mapping` 最终目标）。
模型映射沿用 NEWAPI 原生方向，无 mapping 时使用身份翻译，不自动生成自映射。不同 Provider 线路使用
不同客户模型名；完整边界见 [Seedance 专用渠道与 Link 架构](../20-architecture/Seedance专用渠道与Link架构.md)。

## 确定性渠道提示

Seedance 渠道不展示 Priority 和 Weight 编辑项。表单使用普通语言说明：每个客户模型固定使用一个已启用
渠道，任务失败时不会自动换渠道重新创建。模型冲突只在保存或启用时提示，指出冲突模型和已有渠道，
不增加请求时弹窗或自动修复。

## 信息分层可见性

| 角色 | 默认展示 | 默认不展示 |
| --- | --- | --- |
| 客户 | 客户模型名、请求与结果 | Provider 模型、渠道、协议、Provider 路径 |
| 渠道管理员 | 客户模型、Provider 模型、mapping、代码协议、可操作的配置错误 | 冻结任务私有快照和原始 Provider 响应 |
| 技术诊断 | 冻结渠道、协议、连接、素材和计费快照 | 密钥明文、完整签名 URL、原始 Provider 响应 |

不展示不等于不记录；Task 和素材私有事实仍需完整、可追溯，但只在对当前角色任务有实际作用时展示。
