# 页面清单

## 管理后台

| 页面/容器 | 主要用户 | 当前职责 |
| --- | --- | --- |
| 渠道管理列表 | 平台管理员 | 查看渠道状态、类型、分组和基础运行信息，进入新增或编辑抽屉 |
| 渠道新增/编辑抽屉 | 平台管理员 | 配置普通渠道或 Seedance 专用渠道的客户模型、模型映射、代码协议、凭据和运营属性 |
| Seedance 素材管理 | 平台管理员或客户 | 创建、查看和删除固定 Provider 作用域的 Asset/AssetGroup，获取真人认证上游链接 |

渠道抽屉的 Seedance 状态和交互以[交互模式](交互模式.md)为准；渠道和模型边界见
[Seedance 专用渠道与 Link 架构](../20-architecture/Seedance专用渠道与Link架构.md)；运维步骤见
[视频与素材渠道运维手册](../40-operations/02-视频与素材渠道运维手册.md)。
