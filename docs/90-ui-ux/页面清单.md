# 页面清单

## 管理后台

| 页面/容器 | 主要用户 | 当前职责 |
| --- | --- | --- |
| 渠道管理列表 | 平台管理员 | 查看渠道状态、类型、分组和基础运行信息，进入新增或编辑抽屉 |
| 渠道新增/编辑抽屉 | 平台管理员 | 配置普通渠道或 Seedance 专用渠道的客户模型、模型映射、代码协议、凭据和运营属性 |
| Seedance 素材管理 | 平台管理员或客户 | 创建、查看和删除固定 Provider 作用域的 Asset/AssetGroup，获取真人认证上游链接 |
| 用户管理合同侧边栏 | 平台管理员 | 按 User ID 配置精确模型、唯一渠道组和折扣，查看四态摘要与分页审计 |
| 模型定价编辑器 | 平台管理员 | Seedance 归属模型进入任务用量编辑器（u() 字段合同）并独立组合预扣 Token 预算字段；原生任务模型继续使用原生用量编辑器；跨类型同名价格合同冲突时阻止编辑与保存 |

Seedance 定价编辑的字段定义与「预算是否必需」是两个独立事实：预算为空时给出条件提示，说明需要
预算的请求会被拒绝；必需性由后端协议判断，不以表达式字符串写法推断。费用试算值不写入预扣配置。渠道抽屉的 Seedance 状态和交互以[交互模式](交互模式.md)为准；渠道和模型边界见
[Seedance 专用渠道与 Link 架构](../20-architecture/Seedance专用渠道与Link架构.md)；运维步骤见
[视频与素材渠道运维手册](../40-operations/02-视频与素材渠道运维手册.md)。

## 用户控制台

当前主要页面包括模型调用入口、异步 Task、Link 资源、API Key 合同价格、API Key 用量账单和公开 API 文档。客户页面
只使用客户模型名，不展示 Provider 模型、渠道、协议或冻结任务私有数据。
