# 页面清单

## 管理后台

| 页面/容器 | 主要用户 | 当前职责 |
| --- | --- | --- |
| 渠道管理列表 | 平台管理员 | 查看渠道状态、类型、分组和基础运行信息，进入新增或编辑抽屉 |
| 渠道新增/编辑抽屉 | 平台管理员 | 配置普通渠道或选择 Link 接入方案、客户模型、模型映射、凭据和运营属性 |
| Link publication 摘要 | 平台管理员 | 只读展示客户模型、route family、Provider 模型、Link SKU、发布版本和当前可履约状态 |
| Link publication rebind 对话框 | 具备渠道敏感写权限的管理员 | 在普通保存之外显式变更客户模型对应 SKU，填写原因并处理版本竞争 |

渠道抽屉的 Link 状态和交互以
[Link 接入方案与模型发布交互规范](Link接入方案与模型发布交互规范.md)为准；运维步骤见
[视频与素材渠道运维手册](../40-operations/02-视频与素材渠道运维手册.md)。

## 用户控制台

当前主要页面包括模型调用入口、异步 Task、Link 资源、API Key 用量账单和公开 API 文档。客户页面
只使用客户模型名，不展示 Link SKU、implementation、Provider 模型、渠道或 execution binding。
