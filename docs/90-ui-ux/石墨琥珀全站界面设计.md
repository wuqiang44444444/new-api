## 居中弹窗规范

- 所有业务表单、详情、选择器、导出、媒体预览和确认都以居中弹窗显示。桌面宽度按复杂度采用约 460、620 或 860 px，渠道配置使用约 1080 px 的宽弹窗。窄屏保留左右边距，内容区独立滚动，标题和操作区始终可达。
- 弹窗内先定位标题或首个字段，确认弹窗优先聚焦取消。Tab 保持在弹窗范围内，Escape 关闭，关闭后焦点返回触发控件。多字段错误应保留输入并定位到错误字段。
- 一个操作流程保持一个活动弹窗。二次确认以当前弹窗切换内容的形式出现，取消时恢复表单草稿及滚动位置。保存失败在当前弹窗就地反馈。
- 行菜单、日期选择、输入选项、账户菜单和通知继续锚定在触发位置。顶部导航和列表内联详情组成页面结构。
- 主题沿用参考稿的深石墨背景、浅色文字和暖琥珀主操作。琥珀也用于当前选择、焦点与主数据系列。绿、橙、红只编码语义状态。金额、用量和时间优先使用等宽数字。

## 评审口径

用户侧显示客户模型、带单位的结算计量、用量及交付状态。渠道、上游模型和受保护证据依现有权限展示在管理侧。客户账单和上游成本各自呈现。视频创建结果未知、任务失败和制品不可用分别表达。模型、权限、账单及素材合同沿用[页面清单](页面清单.md)、[交互模式](交互模式.md)和产品文档。

图册使用简体中文展示。页面文案进入前端实现时按仓库约定补齐简体中文和英文。离线图册包含 HTML、CSS、示例数据及独立图片。设计参考来自 `assets/graphite-amber`，图标使用项目已安装的 Hugeicons Free（MIT）。
